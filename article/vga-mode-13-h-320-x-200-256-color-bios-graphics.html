VGA Mode 13h: 320x200 256-Color BIOS Graphics

This article examines BIOS Mode 13h, the foundational standard that brought 320x200 resolution and 256 simultaneous colors to IBM-compatible personal computers. It outlines the technical specifications of this video mode, explains how it is initialized via BIOS interrupts, and details why its linear memory architecture made it the primary graphics standard for PC gaming throughout the late 1980s and early 1990s.

The Mode Number: Mode 13h

The BIOS mode number corresponding to the 320x200 256-color Video Graphics Array (VGA) mode is Mode 13h (hexadecimal), which equals Mode 19 in decimal notation.

To initialize this mode on an x86 processor, software issues a BIOS interrupt call using INT 10h with the processor register AH set to 00h (Set Video Mode) and AL set to 13h.

mov ah, 00h
mov al, 13h
int 10h

Technical Specifications

Introduced by IBM in 1987 alongside the PS/2 series, Mode 13h became the de facto standard for graphical computing. Its primary technical characteristics include:

  • Horizontal Resolution: 320 pixels
  • Vertical Resolution: 200 pixels
  • Aspect Ratio: 4:3 (yielding tall, rectangular pixels with an aspect ratio of 1:1.2)
  • Color Depth: 8 bits per pixel (bpp)
  • Simultaneous Colors: 256 colors on-screen at once
  • Color Palette: Selected from an 18-bit RGB color palette (262,144 total possible colors via the VGA Digital-to-Analog Converter)
  • Memory Buffer Address: Linear mapping starting at physical address 0xA0000 (segment 0xA000:0000)

Why Mode 13h Revolutionized PC Gaming

Prior to Mode 13h, standards such as CGA and EGA relied on complex bit-planar memory layouts, requiring multiple processor instructions to modify a single pixel. Mode 13h altered this paradigm through linear addressing and a single-byte-per-pixel design.

Linear Memory Mapping

A resolution of 320x200 contains exactly 64,000 pixels. Because each pixel is represented by a single byte (8 bits), the entire frame buffer requires exactly 64,000 bytes. This fits entirely inside a single 64-kilobyte real-mode memory segment (65,536 bytes).

Programmers did not need to switch memory banks to draw a full screen. Setting or reading a pixel at coordinates (X, Y) required a direct memory offset calculation:

\[\text{Memory Offset} = (Y \times 320) + X\]

Writing a pixel was as simple as placing an 8-bit color index directly into the memory location at 0xA0000 + Offset.

Impact on Software

This straightforward byte-to-pixel mapping enabled rapid software rendering directly in CPU memory or straight to the video buffer. Legendary titles of the MS-DOS era—such as Wolfenstein 3D, DOOM, UFO: Enemy Unknown, and LucasArts adventure games—depended on Mode 13h to achieve high frame rates and vibrant visuals without specialized 3D acceleration hardware. Later, developers learned to tweak the VGA registers to bypass the default 64KB limitation, creating custom "Mode X" variants for page flipping and smooth scrolling.
