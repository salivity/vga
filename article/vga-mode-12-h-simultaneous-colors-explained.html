VGA Mode 12h Simultaneous Colors Explained

VGA Mode 12h is one of the most iconic standard graphics modes introduced with the IBM Video Graphics Array standard in 1987. This article provides a clear overview of the color architecture of Mode 12h, specifically addressing how many colors can appear on the screen at the same time and how those colors are selected from the master hardware palette.

In VGA Mode 12h, a computer can display 16 total colors simultaneously on the screen.

Mode 12h operates at a screen resolution of 640×480 pixels using a 4-bit planar memory layout. Because each pixel is allocated 4 bits of memory, the hardware can index \(2^4\), or exactly 16 unique color registers at any single moment.

Although only 16 colors can be shown at the same time, those 16 slots are fully customizable. They are selected from a master palette of 262,144 colors.

The VGA hardware achieves this through its Color Look-Up Table (CLUT) within the Digital-to-Analog Converter (DAC). The DAC uses 6 bits for each of the three primary color channels (Red, Green, and Blue):

  • Red: 64 intensity levels (\(2^6\))
  • Green: 64 intensity levels (\(2^6\))
  • Blue: 64 intensity levels (\(2^6\))

Multiplying these levels (\(64 \times 64 \times 64\)) results in the 262,144-color space (18-bit color). Software running in Mode 12h assigns 16 specific values from this master space into the active palette registers, allowing developers to tailor the 16 active colors to match the specific needs of an image, user interface, or game scene.

The 16-color simultaneous limit was primarily a result of memory hardware constraints. Standard VGA hardware included 256 kilobytes of Video RAM. A single 640×480 screen buffer with 16 colors (4 bits per pixel) requires 153,600 bytes (approximately 150 KB). Attempting to display 256 simultaneous colors at the same resolution would have required 307,200 bytes (300 KB), exceeding the base 256 KB memory provided on standard VGA adapters.
