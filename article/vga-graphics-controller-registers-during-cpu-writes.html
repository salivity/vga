VGA Graphics Controller Registers During CPU Writes

During CPU write operations, the Video Graphics Array (VGA) Graphics Controller registers act as a hardware data pipeline that dictates how bytes sent from the processor are transformed, expanded, and merged into video memory (VRAM). Because the VGA architecture maps four parallel 64 KB memory planes to a single 64 KB CPU address window, the CPU cannot simply write raw linear bytes directly to individual display pixels. Instead, the Graphics Controller registers intercept the incoming CPU data byte, manipulate it using arithmetic and logic operations, combine it with contents held in temporary 32-bit internal latches, and distribute the result across the four memory planes simultaneously.

The Write Pipeline and Processing Steps

When a CPU executes a write to the VGA memory region, the data passes through several configurable stages within the Graphics Controller before updating the VRAM planes:

  1. Data Rotation: Incoming CPU data is optionally shifted to align with specific pixel positions within a display byte.
  2. Set/Reset Evaluation: The incoming data can be preserved or replaced entirely with predetermined color values on a per-plane basis.
  3. Logical Combination: The rotated or substituted data is combined with the values stored in the Graphics Controller's internal 32-bit latches (loaded during the preceding CPU read operation) using bitwise logic.
  4. Bit Masking: A bit mask selects, on a bit-by-bit basis, whether the newly calculated value or the original latch data is written to the destination planes.

Key Graphics Controller Registers Controlling Writes

Specific registers inside the Graphics Controller (accessed via I/O ports 0x3CE and 0x3CF) define this behavior:

  • Graphics Mode Register (Index 05h): Configures the overarching write mode (Modes 0 through 3), defining how the controller interprets incoming CPU data relative to the internal latches.
  • Data Rotate Register (Index 03h): Specifies a right-rotation count (0 to 7 bits) applied to the CPU write data. It also defines the logical operation (Copy/Replace, AND, OR, or XOR) performed between the rotated CPU data and the internal latch contents.
  • Enable Set/Reset Register (Index 01h): Enables or disables the Set/Reset function independently for each of the four memory planes. When a plane's bit is enabled, the actual CPU byte is ignored for that plane.
  • Set/Reset Register (Index 00h): Specifies the 1-bit or 0-bit value written to an enabled plane. If a plane is enabled via the Enable Set/Reset Register, an 8-bit byte of either all ones (0xFF) or all zeros (0x00) is generated for that plane, allowing fast color fills.
  • Bit Mask Register (Index 08h): Controls write protection at the pixel level across all planes. For every bit set to 1 in this register, the corresponding bit from the ALU output is written to memory. For every bit set to 0, the corresponding bit from the internal latch is preserved, preventing modification of adjacent pixels in the same byte.

Execution Across VGA Write Modes

The Graphics Mode Register establishes four distinct operating modes that alter the role of the other registers during a write:

  • Write Mode 0 (Standard Write): The standard pipeline processes incoming CPU data through the Data Rotate, Set/Reset, Logical Operation, and Bit Mask registers. This mode is typically used for general rendering, drawing lines, and blitting.
  • Write Mode 1 (Latch Transfer): The CPU write data is completely ignored. Instead, the 32 bits currently stored in the internal latches (8 bits from each of the four planes) are written directly back into the VRAM address. This mode allows high-speed VRAM-to-VRAM block copies without requiring data to travel over the CPU system bus.
  • Write Mode 2 (Color Fill): Bits 0 through 3 of the CPU write byte represent an 8-bit color value across planes 0 through 3 (bit 0 maps to plane 0, bit 1 to plane 1, etc.). The controller expands each bit into a full 8-bit byte (0x00 or 0xFF) across its corresponding plane, applies logical operations with the latches, and respects the Bit Mask Register. This mode allows the CPU to write up to eight single-color pixels simultaneously.
  • Write Mode 3 (Bit-Masked Foreground Write): The incoming CPU data byte is rotated and then bitwise ANDed with the value in the Bit Mask Register, effectively acting as an ad-hoc bit mask. The actual color data written to the planes is sourced entirely from the Set/Reset Register. This mode is designed for rapid font rendering and monochrome-to-color pattern expansion.
