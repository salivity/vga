Where Are VGA Text-Mode Fonts Stored in ROM?

Default Video Graphics Array (VGA) text-mode font bitmaps are stored within the VGA adapter’s dedicated Video BIOS ROM, which is mapped into system memory starting at address C000:0000 (0xC0000). While original IBM architecture historically referenced basic character tables in the motherboard's System BIOS ROM at segment F000h, standard VGA hardware relies on its own on-board firmware to supply the 8x8, 8x14, and standard 8x16 pixel font sets. This article explains the exact memory locations, ROM organization, and access mechanisms for these default text-mode bitmaps.

The Video BIOS Adapter ROM Location

Unlike older display standards such as the Color Graphics Adapter (CGA), which used a dedicated, hardwired hardware character generator ROM, VGA integrates font data directly into the Video BIOS software code. The VGA Video BIOS is located physically on the graphics adapter (or integrated within modern system firmware) and is shadowed or mapped into the PC's Upper Memory Area (UMA) at:

  • Base Segment Address: C000h
  • Linear Physical Range: 0x000C0000 through 0x000C7FFF (typically a 32 KB range, though some implementations extend to 64 KB ending at 0x000CFFFF).

The exact offset of the font tables inside the C000h segment varies across different BIOS manufacturers (such as IBM, Phoenix, Award, or modern emulators like SeaBIOS), meaning software should not rely on fixed hardcoded offsets.

Default Font Sets Stored in ROM

The VGA BIOS contains multiple font bitmap tables to support different display resolutions and compatibility modes:

  • 8x16 Font: The primary VGA text font used in standard 80x25 text mode (Mode 03h/07h), which operates at a 720x400 screen resolution using 9x16 character cells (the 9th pixel column is generated dynamically by the hardware).
  • 8x14 Font: Preserved primarily for backward compatibility with Enhanced Graphics Adapter (EGA) text modes.
  • 8x8 Font: Preserved for CGA compatibility, low-resolution graphics modes, or 80x50 text modes (where 400 vertical scan lines are divided into 8-pixel-high rows).

Each character in these tables is stored as a sequential series of 1-byte horizontal scanlines, where a set bit (1) represents a foreground pixel and a clear bit (0) represents a background pixel. For example, a complete 256-character 8x16 font table requires exactly 4,096 bytes (256 characters × 16 bytes) in ROM.

Reading Font Pointers via BIOS Interrupts

Because the internal offsets within the C000h segment vary, software accesses the locations of these ROM font tables through BIOS interrupts:

  • INT 10h, Function 11h, Subfunction 30h (AX=1130h): The primary standard interface to query ROM font locations. By passing the desired font identifier in register BH (e.g., BH=06h for the 8x16 font, BH=02h for the 8x14 font, or BH=03h for the 8x8 font), the BIOS returns the segment and offset address of that table directly in ES:BP.
  • Interrupt Vector 43h (INT 43h): Used on EGA and VGA systems to store the pointer to the currently active character generator graphics table.

Font Deployment to Video RAM Plane 2

While the bitmap tables are permanently stored in the Video BIOS ROM at C000h, the VGA display hardware does not render text characters directly from ROM during active operation.

Instead, during a video mode initialization (via INT 10h, AH=00h), the BIOS routine reads the selected font bitmap from the ROM at C000h and copies it into Plane 2 of the VGA Video RAM (located at base address 0xA0000). The VGA character generator hardware then reads glyph bitmaps directly from Plane 2 memory to render text onto the screen.
