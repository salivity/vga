Standard VGA Pinout and Pin Arrangement

This guide provides an overview of the pin configuration for a standard high-density Video Graphics Array (VGA) connector. Commonly designated as a DE-15 (or HD-15) connector, this analog display interface features 15 pins arranged in three staggered rows of five pins each. Below is the precise breakdown of the signal assignments for each row.

Row 1: Primary Video Signals (Pins 1 to 5)

The top row handles the primary analog color channels along with basic identification:

  • Pin 1 (RED): Carries the red analog video signal (75-ohm termination).
  • Pin 2 (GREEN): Carries the green analog video signal (75-ohm termination).
  • Pin 3 (BLUE): Carries the blue analog video signal (75-ohm termination).
  • Pin 4 (ID2/RES): Originally used for Monitor ID bit 2; reserved or left unconnected on modern systems.
  • Pin 5 (GND): Digital ground return, often used for self-test detection.

Row 2: Ground Lines and Power (Pins 6 to 10)

The middle row primarily provides individual ground returns for the color channels to prevent crosstalk, along with low-voltage power for display data:

  • Pin 6 (RGND): Red signal ground return.
  • Pin 7 (GGND): Green signal ground return.
  • Pin 8 (BGND): Blue signal ground return.
  • Pin 9 (+5V): Supplies +5V DC power from the host to power the Display Data Channel (DDC) EEPROM in the monitor.
  • Pin 10 (SGND): Synchronization signal ground return.

Row 3: Synchronization and Data (Pins 11 to 15)

The bottom row transmits synchronization timings and handles two-way communication between the host and display:

  • Pin 11 (ID0/RES): Originally used for Monitor ID bit 0; typically unused or grounded.
  • Pin 12 (SDA): I²C bidirectional data line used for Display Data Channel (DDC2B) communication to identify display capabilities (EDID).
  • Pin 13 (HSYNC): Horizontal synchronization signal to control line scanning.
  • Pin 14 (VSYNC): Vertical synchronization signal to control frame scanning.
  • Pin 15 (SCL): I²C data clock line used for DDC communication synchronization.
