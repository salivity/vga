How VGA Sequencer Divides the Dot Clock

The Video Graphics Array (VGA) internal timing sequencer controls the video timing pipeline by taking a master clock frequency and dividing it into the necessary timing pulses for rendering. This article details the hardware mechanisms behind this division, focusing on the Sequencer's Clocking Mode Register, how it handles 8-dot and 9-dot text modes, and the method used to halve the pixel frequency for low-resolution graphics modes.

The Master Clock Source

Before the Sequencer performs any division, the hardware selects a primary oscillator. The VGA board features an external clock generator providing standard frequencies—most notably 25.175 MHz (for 640-pixel graphics and standard text) and 28.322 MHz (for 720-pixel wide text modes). Bits 2 and 3 of the Miscellaneous Output Register (port 0x3C2) choose between these input oscillators or an auxiliary clock source. This selected signal serves as the base master clock fed directly into the Sequencer logic.

Dot Clock Division via the Clocking Mode Register

The Sequencer's primary clock-division control resides in the Clocking Mode Register (Index 0x01 of the Sequencer Register block, accessed via index port 0x3C4 and data port 0x3C5). Within this register, two primary bits configure the hardware dividers:

  • Bit 3: Dot Clock Halving (Divide by 2): When set to 0, the dot clock runs at full oscillator speed (1:1 ratio). When set to 1, the sequencer engages a toggle flip-flop divider that divides the master clock frequency by 2. This mode is essential for 320x200 graphics modes (such as standard Mode 13h), where the 25.175 MHz crystal is cut to approximately 12.587 MHz, doubling the duration of each pixel horizontally and allowing 320 pixels to span the entire horizontal active display time.
  • Bit 2 and Bit 4: Shift Load Clocks: These bits configure how often data shifts through the internal serializers (e.g., reloading shift registers every cycle or every other cycle), directly affecting how many pixel values are pushed to the DAC per clock period.

Character Clock Generation

In addition to driving the serial pixel pipeline via the dot clock, the Sequencer generates a secondary, lower-frequency clock known as the Character Clock. The Character Clock coordinates video memory fetching and drives the Cathode Ray Tube Controller (CRTC) timing counters.

The Sequencer divides the dot clock down to the Character Clock using an internal counter controlled by Bit 0 of the Clocking Mode Register:

  • 8-Dot Mode (Bit 0 = 1): The sequencer configures a modulo-8 counter. Every 8 dot clock pulses, the counter resets and outputs one character clock pulse. This is used in standard 640-pixel graphics modes and 80-column text modes on standard displays (where each character cell is 8 pixels wide).
  • 9-Dot Mode (Bit 0 = 0): The sequencer switches to a modulo-9 counter, outputting one character clock pulse every 9 dot clock cycles. Paired with the 28.322 MHz crystal, this allows the system to generate 720-pixel wide text with 9-dot wide character cells while maintaining the standard horizontal scan rate (31.468 kHz).

Synchronization Across the Video Pipeline

Through this division process, the Sequencer outputs two primary derived frequencies:

  1. The Dot Clock: Either equal to the master clock frequency or halved to create stretched pixels. This clock drives the parallel-to-serial shift registers that feed digital attribute data toward the palette DAC.
  2. The Character Clock: Derived by dividing the active Dot Clock by either 8 or 9. This clock dictates memory cycle access timing, memory plane latch loading, and the advancement of the horizontal and vertical display state machines within the CRTC.
