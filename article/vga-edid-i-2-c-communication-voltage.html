VGA EDID I2C Communication Voltage

Reading Extended Display Identification Data (EDID) over a Video Graphics Array (VGA) interface relies on the I2C-based Display Data Channel (DDC), which operates at a nominal voltage of 5 volts (5V DC). This article details the specific operating voltage, the VESA standard definitions, and the underlying pin configuration responsible for transmitting EDID information between a host computer and a display.

The Standard Operating Voltage

When a graphics adapter reads EDID data from a VGA monitor, the I2C communication bus operates at standard 5-volt logic levels (5V TTL). According to the Video Electronics Standards Association (VESA) DDC standard—specifically DDC2B, which implements the I2C serial protocol—both the data line (SDA) and the clock line (SCL) are pulled up to +5V.

High logic levels (binary 1) are held near 5V, while low logic levels (binary 0) are pulled to ground (0V). The host controller and the display's onboard EEPROM must be 5V-tolerant to read and write configuration data safely.

VGA Pinout for EDID Communication

The transfer of EDID information over a standard 15-pin DE-15 (VGA) connector uses dedicated pins defined by the VESA DDC2B standard:

  • Pin 9 (+5V Power): Supplies +5V DC from the host graphics card to the display's EDID EEPROM chip. This allows the host to read the display's capabilities even if the monitor is switched off or unplugged from AC power.
  • Pin 12 (SDA): The bidirectional I2C Serial Data line, pulled up to +5V through a pull-up resistor (typically between 1.5 kΩ and 4.7 kΩ).
  • Pin 15 (SCL): The I2C Serial Clock line, also pulled up to +5V, generated by the host device.
  • Pins 5, 10, or 11 (Ground): Provide the shared electrical ground return for the DDC signals.

Communication Process

During initialization, the host graphics card acts as the I2C bus master, sending a 100 kHz standard-mode clock signal along Pin 15. It queries the 7-bit slave address 0x50 (or 0xA0 in 8-bit read format), where the display's 128-byte or 256-byte EEPROM resides.

Because the entire DDC2B subsystem is energized by the +5V line on Pin 9, all signaling thresholds strictly adhere to standard 5V CMOS/TTL parameters: any input voltage above 3.5V is recognized as a logic high, and any voltage below 1.5V is recognized as a logic low.
