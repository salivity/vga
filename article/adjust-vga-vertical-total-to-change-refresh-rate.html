Adjust VGA Vertical Total to Change Refresh Rate

This article explains how low-level programmers can adjust the Video Graphics Array (VGA) Vertical Total register to alter a monitor's vertical refresh rate. By reprogramming the internal Cathode Ray Tube Controller (CRTC) registers directly through x86 I/O ports, software can change the total scanline count per frame. Altering this value directly changes the frame timing and refresh frequency without necessarily modifying the pixel clock generator.

The Timing Relationship

In standard VGA hardware, the vertical refresh rate (\(F_v\)) depends on the dot clock frequency (\(DotClock\)), the horizontal total character clocks (\(H_{total}\)), and the vertical total scanlines (\(V_{total}\)). The relationship is defined by:

\[F_v = \frac{DotClock}{H_{total} \times V_{total}}\]

When the pixel clock and horizontal timings remain fixed, modifying the total number of vertical scanlines directly changes the refresh rate. Increasing the vertical scanline count lowers the refresh rate, while decreasing the scanline count raises the refresh rate.

VGA CRTC Registers for Vertical Total

The vertical total is a 10-bit value split across two separate CRTC registers:

  1. Vertical Total Register (CRTC Index 0x06): Holds the lower 8 bits (bits 0–7) of the 10-bit value.
  2. Overflow Register (CRTC Index 0x07): Holds the upper 2 bits. Bit 8 of the vertical total is stored at bit 0 of this register, and bit 9 is stored at bit 5.

The hardware counter counts from 0 up to the 10-bit vertical total value. Because internal logic adds an offset, the actual total number of scanlines generated per frame is the programmed 10-bit value plus 2.

Step-by-Step Programming Process

1. Disable CRTC Write Protection

Standard VGA implementations include a write-protect bit to prevent accidental modification of critical timing registers. CRTC registers 0x00 through 0x07 cannot be modified until this protection is disabled.

  • Locate the CRTC I/O ports: 0x3D4 (Address Register) and 0x3D5 (Data Register) for color modes (or 0x3B4/0x3B5 for monochrome modes).
  • Select CRTC Index 0x11 (Vertical Retrace End Register).
  • Clear bit 7 to zero to unlock CRTC registers 0x00 through 0x07.

2. Calculate the Desired Vertical Total Value

Determine the target number of scanlines (\(N\)) required to achieve the desired refresh rate based on your horizontal frequency (\(F_h\)):

\[N = \frac{F_h}{F_v}\]

The 10-bit register value (\(V_{reg}\)) to write is:

\[V_{reg} = N - 2\]

3. Update the Vertical Total (Index 0x06)

Write the lower 8 bits of \(V_{reg}\) into Index 0x06:

  • Output 0x06 to port 0x3D4.
  • Output (V_reg & 0xFF) to port 0x3D5.

4. Update the Overflow Register (Index 0x07)

Because the Overflow Register holds timing bits for other signals (such as Vertical Retrace Start and Vertical Display Enable End), you must perform a read-modify-write operation:

  • Output 0x07 to port 0x3D4.
  • Read the current byte from port 0x3D5.
  • Clear bit 0 and bit 5: value &= ~0x21.
  • Insert bit 8 of \(V_{reg}\) into bit 0: value |= ((V_reg >> 8) & 0x01).
  • Insert bit 9 of \(V_{reg}\) into bit 5: value |= (((V_reg >> 9) & 0x01) << 5).
  • Write the updated byte back to port 0x3D5.

5. Re-enable Write Protection

To prevent unintentional timing alterations by other routines, re-lock the registers by setting bit 7 of CRTC Index 0x11 back to 1.

Operational Constraints

  • Vertical Blanking and Retrace Positioning: The vertical total must always remain greater than the sum of the visible display rows (Index 0x12), the vertical blanking start (Index 0x15), and the vertical retrace start (Index 0x10). Setting the vertical total lower than these values causes video corruption or loss of monitor sync.
  • Monitor Sync Range: Cathode Ray Tube (CRT) and modern flat-panel monitors operate within limited vertical frequency ranges (typically 50 Hz to 75 Hz on legacy analog displays). Exceeding these hardware tolerance limits will trigger an "Out of Range" warning or result in an unstable picture.
