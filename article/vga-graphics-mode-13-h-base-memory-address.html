VGA Graphics Mode 13h Base Memory Address

This article explores the physical base memory address used by standard Video Graphics Array (VGA) graphics modes, with a primary focus on Mode 13h. It covers the specific memory mapping location within the x86 architecture, the structure of the frame buffer, how developers directly accessed video memory in the MS-DOS era, and where this range fits inside the broader IBM PC memory map.

The Physical Base Address: 0xA0000

The physical base memory address for standard VGA graphics modes, including Mode 13h, is 0xA0000 (hexadecimal).

In the 16-bit real-mode segmented memory architecture used by the Intel 8086 family and MS-DOS, memory locations were accessed via a segment:offset pair. Developers accessed this physical address using the segment base address 0xA000 with an offset of 0x0000 (written as A000:0000).

Mode 13h Framebuffer Layout

Mode 13h was introduced with the IBM PS/2 VGA standard in 1987. It quickly became the definitive standard for MS-DOS game developers due to its simple, linear memory architecture.

  • Resolution: 320 horizontal pixels by 200 vertical pixels.
  • Color Depth: 8 bits per pixel (1 byte per pixel), allowing 256 simultaneous colors from a palette of 262,144 colors.
  • Total Framebuffer Size: \(320 \times 200 = 64,000\text{ bytes}\) (roughly 62.5 KB).

Because a single real-mode segment can address up to 65,536 bytes (64 KB), the entire 64,000-byte display buffer fit completely within the single 0xA000 segment without requiring bank switching or complex plane manipulation. The pixel data spans continuously from 0xA0000 to 0xAFAFF.

Plotting a pixel at coordinate \((X, Y)\) required a straightforward formula to find the exact memory offset:

\[\text{Memory Address} = 0\text{xA0000} + (Y \times 320) + X\]

Role in the IBM PC Memory Map

In the original IBM PC architecture, the 1 MB address space of the Intel 8086 processor was divided into conventional memory and the Upper Memory Area (UMA):

  • 0x00000 – 0x9FFFF (640 KB): Conventional system RAM.
  • 0xA0000 – 0xBFFFF (128 KB): Video RAM (VRAM) window.
  • 0xC0000 – 0xFFFFF (256 KB): Video BIOS, expansion ROMs, and system BIOS.

The 128 KB video window was subdivided based on the video standard and display mode:

  • 0xA0000 – 0xAFFFF (64 KB): Dedicated to EGA and VGA bitmapped graphics modes (including Mode 12h and Mode 13h).
  • 0xB0000 – 0xB7FFF (32 KB): Reserved for Monochrome Display Adapter (MDA) text mode.
  • 0xB8000 – 0xBFFFF (32 KB): Reserved for Color Graphics Adapter (CGA) modes and standard 80x25 16-color text mode (Mode 03h).

By utilizing 0xA0000, Mode 13h avoided conflicts with text-mode display buffers and fit directly adjacent to conventional base memory, making it an efficient target for fast direct-memory access.
