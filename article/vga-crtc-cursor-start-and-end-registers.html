VGA CRTC Cursor Start and End Registers

In IBM VGA-compatible hardware, the vertical size, position, and visibility of the hardware text-mode cursor are determined by two dedicated registers within the Cathode Ray Tube Controller (CRTC): the Cursor Start Register (Index 0Ah) and the Cursor End Register (Index 0Bh). This article explains how these two registers work together to define the cursor's starting and ending scan lines, their exact bit layouts, and how to access and modify them using low-level I/O ports.

Accessing CRTC Registers

The CRTC registers are accessed indirectly via an index and data port pair. The exact I/O port addresses depend on whether the display adapter is configured for monochrome or color emulation:

  • Color Mode (Standard): Address/Index port is 0x3D4, and Data port is 0x3D5.
  • Monochrome Mode: Address/Index port is 0x3B4, and Data port is 0x3B5.

To modify either the Cursor Start or Cursor End scan line, the programmer first writes the target index (0x0A or 0x0B) to port 0x3D4 (or 0x3B4), followed by the value byte to port 0x3D5 (or 0x3B5).

Cursor Start Register (Index 0Ah)

The Cursor Start Register controls the top scan line of the cursor within a character cell, as well as cursor visibility. Its bit layout is defined as follows:

  • Bits 0–4 (Cursor Start Scan Line): Specifies the vertical scan line coordinate (from 0 to 31) where the cursor begins drawing within the character cell.
  • Bit 5 (Cursor Disable): Controls cursor visibility. Setting this bit to 1 hides (disables) the cursor entirely, while setting it to 0 enables normal display.
  • Bits 6–7: Reserved.

Cursor End Register (Index 0Bh)

The Cursor End Register defines the bottom scan line of the cursor and cursor skew timing. Its bit layout is:

  • Bits 0–4 (Cursor End Scan Line): Specifies the vertical scan line coordinate (from 0 to 31) where the cursor stops drawing. The line indicated by this value is included in the drawn cursor.
  • Bits 5–6 (Cursor Skew): Controls the delay of the cursor signal in character clock units to compensate for internal display pipeline delays. This is typically set to 00b in standard modes.
  • Bit 7: Reserved.

Scan Line Operation and Shaping

A character matrix in standard VGA text modes (such as 80x25 mode) is typically 16 scan lines high, indexed from scan line 0 (top) to scan line 15 (bottom).

  • Underline Cursor: Setting the Cursor Start scan line to 14 and the Cursor End scan line to 15 produces a standard two-line underline cursor at the bottom of the character block.
  • Full-Block Cursor: Setting the Cursor Start scan line to 0 and the Cursor End scan line to 15 fills the entire character cell.
  • Wrap-Around Behavior: If the Cursor Start value is greater than the Cursor End value, the VGA hardware splits the cursor into two segments—one extending from the start scan line down to the bottom of the character box, and another wrapping around from scan line 0 down to the end scan line.
