VGA Horizontal Pel Panning Register Explained

The Video Graphics Array (VGA) Horizontal Pel Panning register is a critical hardware component used to achieve smooth, pixel-by-pixel horizontal scrolling in legacy PC graphics programming. While standard VGA registers only allow the display window to shift in increments of whole bytes or character blocks, the Horizontal Pel Panning register enables sub-character horizontal shifting. This article details the role of this register, how it operates within the VGA architecture, and why it was essential for fluid animation and game design on classic systems.

Hardware Location and Role

The Horizontal Pel Panning register is part of the VGA Attribute Controller, accessed at index 0x13 (via I/O ports 0x3C0 and 0x3C1). Its primary purpose is to delay the video output by a specified number of pixels (historically called "pels") before the image data reaches the digital-to-analog converter (DAC).

By default, horizontal scrolling achieved via the CRT Controller's Start Address registers (0x0C and 0x0D) shifts memory references in increments of entire bytes. In typical 8-pixel-wide character modes or 16-color planar graphics modes (such as Mode 12h), adjusting the start address shifts the display by 8 pixels at a time, resulting in jerky, stepped movement. The Horizontal Pel Panning register solves this problem by handling the fine offsets between 0 and 7 (or 0 and 8 in 9-dot modes).

How Fine Scrolling Works

To execute fluid horizontal scrolling, a programmer combines coarse scrolling with fine scrolling:

  1. Fine Scrolling (0 to 7 Pixels): As the screen moves, the program increments the Horizontal Pel Panning register frame by frame. The display shifts smoothly by a single pixel each time.
  2. Coarse Reset (At the 8th Pixel): Once the offset reaches 8 pixels, the software resets the Horizontal Pel Panning register back to 0 and simultaneously increments the CRT Controller Start Address by one byte.

This seamless combination allows graphics to scroll continuously across the screen without visual stutter.

Mode-Specific Behavior

The register interprets values differently depending on the active VGA display mode:

  • 9-Dot Text Modes: In 9-pixel-per-character modes, valid panning values range from 0 to 8. A value of 8 displays the character shifted by 8 pixels, with the 9th pixel replicating the 8th.
  • 8-Dot Text and Graphics Modes: In standard 8-dot modes (such as standard 16-color graphics modes), the lower 3 bits specify an offset between 0 and 7 pixels.
  • 256-Color Graphics (Mode 13h / Mode X): In 256-color modes, pixel clocking differs. In standard Mode 13h, pixels are internally doubled, requiring specific offset sequencing. In custom planar arrangements like "Mode X," the register allows single-pixel precision when combined with byte-level latch manipulation.

Without the Horizontal Pel Panning register, the side-scrolling platformers and fluid graphical interfaces that defined late-1980s and early-1990s PC gaming would not have been possible on standard VGA hardware.
