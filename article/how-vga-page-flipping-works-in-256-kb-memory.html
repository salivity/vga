How VGA Page Flipping Works in 256 KB Memory

Page flipping on a standard 256 KB Video Graphics Array (VGA) adapter is a hardware-level double-buffering technique that eliminates visual tearing during animation. By partitioning the available 256 KB of video RAM into distinct display buffers, software can render a subsequent frame into an off-screen region of memory while the monitor displays the current frame. Once rendering is complete, the program instructs the VGA controller to change its display start address during the monitor's vertical blanking interval, instantly presenting the newly drawn frame.

VGA Memory Organization and Capacity

A standard VGA card contains 256 KB of dynamic RAM organized into four parallel 64 KB banks called "planes" (Plane 0 through Plane 3). The total memory footprint of a visual frame depends on the display resolution and color depth:

  • Mode 13h (320x200, 256 colors, chained): Standard Mode 13h uses an address mapping method known as "Chain-4," which interleaves pixels across the four planes. This mode restricts CPU access to a single 64 KB aperture where each screen consumes 64,000 bytes, leaving virtually no room within that window for a secondary back-buffer.
  • Mode X (320x200, 256 colors, unchained): By disabling the Chain-4 bit in the Sequencer and the Underline Location register, developers unlock all 256 KB across the four planes. Because each plane stores every fourth pixel, a single 320x200 screen takes up only 16,000 bytes per plane (64,000 bytes total). Dividing the 65,536 bytes per plane by 16,000 bytes yields enough room for up to four full pages of video data.
  • Mode 0Dh (320x200, 16 colors): In 16-color planar modes, one bit from each of the four planes forms a single pixel's 4-bit color value. A 320x200 frame consumes 8,000 bytes per plane, fitting up to eight distinct pages within 64 KB.
  • Mode 12h (640x480, 16 colors): At this resolution, a single frame consumes 38,400 bytes per plane. Because 38,400 bytes exceeds half of a 64 KB plane, true hardware page flipping is impossible in 256 KB memory without reducing resolution or clipping visible lines.

Manipulating the Display Start Address

The VGA Cathode Ray Tube Controller (CRTC) manages the scanning of memory out to the display. It uses internal pointer registers to determine the linear offset in video memory from which it starts fetching pixels at the top-left corner of the raster scan:

  1. Start Address High Register (CRTC Register 0x0C)
  2. Start Address Low Register (CRTC Register 0x0D)

Together, these two 8-bit registers form a 16-bit word that defines the base memory offset (in words, shifted depending on mode).

To flip pages:

  1. The CPU writes the target page's offset to the CRTC Index Register at I/O port 0x3D4.
  2. The high and low bytes of the offset are written to the CRTC Data Register at I/O port 0x3D5.
  3. The CRTC latches this address and begins reading the pixel stream for the next frame from the new location.

Vertical Retrace Synchronization

Changing the display start address while the CRT electron gun is actively drawing visible scanlines causes visual artifacts known as tearing. To achieve clean page flips, software monitors the VGA's Input Status Register 1 at I/O port 0x3DA:

  • Bit 3 (Vertical Retrace): When set to 1, the electron beam is moving from the bottom of the display back up to the top (the vertical blanking interval).
  • Software loops continuously to wait for Bit 3 to drop to 0 (if currently in a retrace), and then waits for it to become 1.
  • During this blanking period, the CRTC registers are updated with the new start address, guaranteeing that the switch occurs before the electron beam begins drawing the top scanline of the next frame.
