Horizontal Display Enable Skew in VGA Timing

The horizontal display enable skew in Video Graphics Array (VGA) timing generation is a programmable hardware delay mechanism that synchronizes the active video display timing with the internal pixel rendering pipeline. In VGA controllers, processing video data—from reading memory to latching and palette mapping—takes several clock cycles. The horizontal display enable skew compensates for this latency by delaying the internal Display Enable signal by a specified number of character clocks, ensuring that active pixel output perfectly aligns with the monitor's beam timing.

Hardware Role and Location

In standard IBM VGA architectures, the horizontal display enable skew is controlled via the Cathode Ray Tube Controller (CRTC) registers. Specifically, it is programmed using bits 5 and 6 of the Horizontal Blanking End Register (Index 03h).

These two bits dictate how many character clock periods the internal Display Enable signal is delayed relative to the horizontal counter:

  • 00b: No skew (0 character clock delay)
  • 01b: 1 character clock delay
  • 10b: 2 character clocks delay
  • 11b: 3 character clocks delay

Compensating for Video Pipeline Latency

Generating a display output in VGA hardware is not instantaneous. The process requires a sequence of internal stages:

  1. Memory Fetch: The CRTC generates memory addresses to read character or pixel data from video RAM (VRAM).
  2. Data Serialization: The Graphics Controller latches this data and serializes it into individual pixel bit planes.
  3. Attribute Processing: The Attribute Controller translates these bits through the internal palette registers to determine final color indexes.
  4. Digital-to-Analog Conversion: The digital color values are passed to the RAMDAC to produce the analog RGB voltages sent to the display.

Each processing stage introduces propagation delay, typically measured in full character clocks. If the Display Enable signal were asserted simultaneously with the CRTC's initial horizontal counter, the monitor would begin its active scan line before the corresponding pixel data finished traversing the processing pipeline.

Function and Impact on Image Rendering

The primary function of the horizontal display enable skew is to prevent graphical clipping and alignment artifacts.

Without skew adjustment, the video pipeline delay would cause the first few pixels of a scan line to be lost or rendered as black space, while the final pixels would be cut off prematurely when the display signal transitions to horizontal blanking. By programming the skew to match the exact hardware pipeline delay of the active display mode (such as alphanumeric text mode versus graphics modes), the active display window opens exactly when the first serialized pixels exit the Attribute Controller and closes precisely after the final pixel of the scan line is output.
