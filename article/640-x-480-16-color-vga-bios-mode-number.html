640x480 16-Color VGA BIOS Mode Number

This article identifies the specific BIOS video mode number used to initialize the standard 640x480 16-color Video Graphics Array (VGA) display and explains how it is invoked in low-level programming. It details the interrupt routine used to activate the display, the planar memory architecture required to manage the screen buffer, and the technical specifications that made this mode a milestone standard for IBM-compatible personal computers.

The Mode Number: Mode 12h

The BIOS mode number that initializes the 640x480 16-color VGA display is Mode 12h (hexadecimal) or Mode 18 (decimal).

Introduced by IBM in 1987 alongside the PS/2 series, Mode 12h was the flagship graphics mode of the original VGA standard. It delivered the highest resolution available in the original standard BIOS specification for 16-color graphics.

How to Initialize Mode 12h

To initialize Mode 12h, software triggers the BIOS video services interrupt, INT 10h, with the service number for setting the video mode loaded into the CPU's AH register, and the mode number loaded into the AL register.

In x86 assembly language, the initialization sequence is:

mov ah, 00h    ; Function 00h: Set Video Mode
mov al, 12h    ; Mode 12h: 640x480, 16 colors, graphics
int 10h        ; Call BIOS Video Services

Executing this interrupt reconfigures the VGA controller hardware, clears the screen memory, sets up the default 16-color palette, and switches the monitor timing to standard VGA refresh rates (typically 60 Hz).

Technical Specifications of Mode 12h

  • Resolution: 640 horizontal pixels by 480 vertical pixels.
  • Color Depth: 4 bits per pixel (bpp), allowing 16 simultaneous colors on screen.
  • Palette: Colors are chosen from an 18-bit palette (6 bits each for Red, Green, and Blue), providing a total selection of 262,144 colors.
  • Pixel Aspect Ratio: 1:1 (square pixels). Because a 640x480 resolution matches the 4:3 physical aspect ratio of standard CRT monitors, developers could draw circles and geometric figures without applying aspect-ratio correction formulas.
  • Frame Buffer Address: Mapped to segment 0xA000 (linear memory address 0xA0000).

Planar Memory Architecture

Mode 12h uses a planar memory organization rather than a packed-pixel or linear frame buffer. Because 640 × 480 pixels require 307,200 pixels, and each pixel requires 4 bits of color data, a full frame requires 153,600 bytes of video RAM. This exceeds the 64 KB segment limit allocated to standard video buffers (0xA0000 to 0xAFFFF).

To fit within this 64 KB window, VGA hardware divides video memory into four distinct 64 KB memory planes:

  1. Plane 0: Blue component
  2. Plane 1: Green component
  3. Plane 2: Red component
  4. Plane 3: Intensity component

Each byte in the segment 0xA000 represents 8 horizontal pixels across all four planes simultaneously. To write or read specific pixels, programmers manipulate the VGA Graphics Controller Registers (I/O ports 0x3CE and 0x3CF) to select planes, apply bitmasks, and execute boolean write operations.
