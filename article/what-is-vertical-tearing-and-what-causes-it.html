What Is Vertical Tearing and What Causes It?

Vertical tearing, commonly known as screen tearing, is a visual artifact in video displays where a monitor simultaneously shows elements from multiple rendered frames, creating a visible horizontal split across the image. This phenomenon occurs when a graphics processing unit (GPU) updates its frame output out of alignment with the display monitor’s refresh cycle. This article explains the technical mechanics of vertical tearing, focusing on how raster scanning and unsynchronized buffer swaps—historically rooted in architectures like the Video Graphics Array (VGA)—lead to this artifact, and how synchronization methods resolve it.

Understanding Vertical Tearing

Vertical tearing manifests as a sharp, horizontal seam across a screen where the top half of the display does not visually match the bottom half. It is most noticeable during fast-paced motion, such as quick camera pans in video games or high-motion video playback. Despite its name, the tear line itself is oriented horizontally; the term "vertical" refers to the vertical coordinate mismatch between different points along the display's vertical axis.

Display Refresh and Raster Scanning

To understand why tearing happens, it is necessary to examine how display hardware draws an image. Traditional Video Graphics Array (VGA) interfaces, as well as modern digital standards derived from them, use a process called raster scanning.

A display does not update all its pixels simultaneously. Instead, it draws an image one pixel at a time, moving sequentially from left to right along a horizontal scanline, and row by row from the top of the screen to the bottom. Once the display finishes drawing the final bottom row, the drawing mechanism resets to the top-left corner during a brief pause called the Vertical Blanking Interval (VBLANK). The speed at which a monitor completes this entire top-to-bottom cycle is its refresh rate, typically measured in Hertz (Hz).

Frame Buffering and Frame Flipping

To prevent a viewer from watching the GPU draw an image pixel by pixel, computer graphics systems employ a technique known as double buffering:

  1. Front Buffer: The memory space currently being read by the display controller to transmit pixels to the screen.
  2. Back Buffer: The secondary memory space where the GPU renders the next frame off-screen.

Once the GPU finishes rendering a complete frame into the back buffer, the system must make that new image available to the display. This transition is known as a frame flip, where the roles of the front and back buffers are swapped. The back buffer becomes the new front buffer to be read out, and the old front buffer becomes available for the GPU to render the subsequent frame.

The Cause of Tearing: Unsynchronized Flipping

Tearing occurs when a frame flip is executed asynchronously—meaning the swap happens at an arbitrary point in time without checking where the display hardware is in its raster scan cycle.

If the GPU completes a frame and immediately swaps the buffers while the display controller is in the middle of sending an image to the monitor (for example, halfway down the screen):

  1. The display controller reads the first half of the scanlines from the initial frame (Frame A).
  2. The buffer flip takes place mid-scan.
  3. The display controller continues reading the remaining scanlines from the newly swapped buffer (Frame B).

Because objects or camera angles moved between Frame A and Frame B, the geometry on the bottom half of the screen does not align with the geometry on the top half. The line where the buffer swap occurred becomes the visible "tear line." If the GPU renders significantly faster than the display's refresh rate, multiple buffer flips can occur during a single refresh cycle, producing multiple horizontal tears across the screen simultaneously.

Preventing Vertical Tearing

The standard solution to eliminate vertical tearing is Vertical Synchronization (V-Sync). When V-Sync is enabled, the system restricts the frame flip so that it can only occur during the Vertical Blanking Interval (VBLANK). By forcing the buffer swap to happen exclusively while the display is not drawing active pixels, the monitor only ever scans a single, complete frame from top to bottom, completely eliminating the tear artifact.
