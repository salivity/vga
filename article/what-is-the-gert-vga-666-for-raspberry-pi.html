What Is the Gert VGA 666 for Raspberry Pi?

The Gert VGA 666 is a breakout adapter board designed to give modern Raspberry Pi computers native analog VGA video output capabilities. This article details the hardware design of the Gert VGA 666, explains how it converts digital GPIO signals into an analog display format, and highlights its ideal use cases alongside its key technical limitations.

Designed by Gert van Loo—an engineer who contributed to the original Raspberry Pi hardware—the Gert VGA 666 is a passive add-on board compatible with Raspberry Pi models featuring a 40-pin GPIO header (such as the Model B+, Pi 2, Pi 3, Pi 4, and Pi Zero). Rather than relying on active, powered protocol converters or USB-based display drivers, the board connects directly to the Pi's Broadcom System-on-Chip (SoC) using the built-in Display Parallel Interface (DPI).

The "666" in the board's name refers to its color channel configuration: 6 bits for Red, 6 bits for Green, and 6 bits for Blue. This setup provides an 18-bit color depth, delivering up to 262,144 distinct colors. The conversion from digital to analog is achieved through a simple resistor-ladder digital-to-analog converter (DAC). Because the digital signals are handled entirely by the GPU’s parallel display hardware, the video output incurs virtually no CPU overhead.

One of the primary benefits of the Gert VGA 666 is the ability to drive dual-monitor configurations on single-HDMI Raspberry Pi boards. Users can run an HDMI display alongside an analog VGA monitor simultaneously. It can drive standard VGA resolutions, commonly up to 1080p at 60 frames per second. Furthermore, because it outputs a raw analog RGB signal, it has become popular in retro computing and arcade cabinet emulation for connecting directly to legacy CRT monitors and older projectors without display lag.

Using the board requires configuring the Raspberry Pi's boot settings by adding the appropriate device tree overlay (dtoverlay=vga666) to the config.txt file.

The primary trade-off of the Gert VGA 666 is pin utilization. The board consumes almost the entirety of the 40-pin GPIO header—specifically GPIO pins 2 through 27—to handle color data, pixel clocks, and synchronization signals. Consequently, users cannot run other expansion HATs, sensors, or serial communication interfaces that rely on those same pins while the adapter is active. Additionally, standard VGA transmits only video, meaning separate audio connections must be made via the 3.5mm jack, USB, or HDMI.
