VGA Color Don't Care Register Explained

The Video Graphics Array (VGA) Color Don't Care register is a hardware configuration register used during specific memory read operations to selectively ignore color planes during pixel comparisons. Located in the VGA Graphics Controller, this register works in tandem with the Color Compare register when the display hardware is set to Read Mode 1. By defining which of the four memory planes are evaluated and which are disregarded, it enables software to quickly search display memory for specific color combinations, patterns, or boundaries without manually reading and masking all four planes in software.

The Role of Read Mode 1

To understand the Color Don't Care register, it is necessary to examine how VGA organizes memory. VGA graphics memory is arranged into four parallel 64 KB memory planes (Planes 0 through 3). In standard 16-color planar modes, a single byte read from the host CPU cannot retrieve the complete color data for eight pixels simultaneously because the color bits for each pixel are distributed across these four separate planes.

The VGA hardware provides two primary read modes to handle this architecture:

  • Read Mode 0: The CPU reads a raw byte directly from a single plane, chosen by the Read Map Select register.
  • Read Mode 1: The CPU performs a hardware-level color comparison across all four planes simultaneously.

The Color Don't Care register is exclusively utilized during Read Mode 1 operations.

How the Color Don't Care Register Works

The Color Don't Care register is accessed via the Graphics Controller index register (port 0x3CE, index 0x07). Only the lower four bits of this register are active, corresponding directly to the four VGA memory planes:

  • Bit 0: Plane 0 enable/disable
  • Bit 1: Plane 1 enable/disable
  • Bit 2: Plane 2 enable/disable
  • Bit 3: Plane 3 enable/disable
  • Bits 4–7: Unused

When the CPU reads a byte of video memory in Read Mode 1, the VGA hardware evaluates each of the eight horizontal pixels represented by that byte address. For each pixel, the hardware compares the bits across the memory planes against the values programmed into the Color Compare register (index 0x02).

The Color Don't Care register acts as a mask for this operation:

  • Setting a plane's bit to 1 instructs the hardware to include that plane in the comparison. The bit in that plane must match the corresponding bit in the Color Compare register.
  • Setting a plane's bit to 0 marks that plane as a "don't care." The hardware treats the plane as an automatic match, regardless of whether its contents match the Color Compare register.

Result of the Read Operation

After the comparison occurs across the selected planes, the VGA hardware returns a single 8-bit value to the CPU. Each bit in the returned byte represents one of the eight pixels:

  • A bit is set to 1 if the corresponding pixel matched the criteria across all active (care) planes.
  • A bit is set to 0 if the pixel differed from the Color Compare register in any of the active planes.

Practical Applications

By utilizing the Color Don't Care register, software can offload complex bitwise masking operations directly to the VGA hardware. Common use cases include:

  • Collision Detection: Determining if a moving sprite has collided with specific background elements of a particular color, regardless of attributes stored in ignored planes.
  • Fast Boundary Searches: Finding edges in graphics or text modes by checking only the planes that define foreground or background contrast.
  • Color Subsetting: Searching for families of colors (such as any shade of blue) by caring only about the blue plane and ignoring the red and green planes.
