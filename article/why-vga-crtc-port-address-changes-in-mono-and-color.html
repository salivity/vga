Why VGA CRTC Port Address Changes in Mono and Color

The Video Graphics Array (VGA) Cathode Ray Tube Controller (CRTC) shifts its base I/O port addresses between 0x3B4 in monochrome mode and 0x3D4 in color mode to maintain strict hardware backward compatibility with the original IBM PC architecture. In the early days of personal computing, IBM designed systems so monochrome and color video cards could coexist without resource conflicts. When IBM introduced the VGA standard in 1987, it preserved this address splitting to ensure legacy software that bypassed the BIOS and wrote directly to hardware registers could continue running seamlessly.

The Origins: MDA and CGA Coexistence

In 1981, IBM released two distinct display adapters for the IBM PC 5150:

  • Monochrome Display Adapter (MDA): Positioned for text-heavy business tasks, the MDA mapped its video buffer to memory address 0xB0000–0xB7FFF and assigned its Motorola 6845 CRTC registers to I/O ports 0x3B4 (index register) and 0x3B5 (data register).
  • Color Graphics Adapter (CGA): Geared toward color visuals and graphics, the CGA mapped its video memory to 0xB8000–0xBFFFF and assigned its 6845 CRTC to I/O ports 0x3D4 and 0x3D5.

Because the I/O port assignments and memory addresses did not overlap, a single system could host both an MDA card and a CGA card at the same time. Power users often took advantage of this setup to run dual monitors—displaying high-resolution monochrome text on one screen and color charts or graphics on the other.

The Legacy Problem for VGA

When IBM designed the Enhanced Graphics Adapter (EGA) and later the Video Graphics Array (VGA), the goal was to replace both MDA and CGA with a single unified card. However, a significant portion of DOS software—such as Lotus 1-2-3, WordPerfect, and early PC games—ignored system BIOS interrupts for the sake of speed. Instead, these programs directly read from and wrote to the hardcoded I/O port addresses 0x3B4/0x3B5 or 0x3D4/0x3D5.

If the VGA standard had locked the CRTC to a single base address, any legacy software expecting the other address would fail to display video, produce corrupted output, or crash.

How VGA Manages the Port Switch

To resolve this conflict, VGA incorporates a hardware-level steering mechanism controlled by the Miscellaneous Output Register:

  • Port Location: Written via I/O port 0x3C2 and read via 0x3CC.
  • Bit 0 (I/O Address Select):
    • When set to 0, the card configures itself for monochrome emulation. The CRTC index and data registers map to 0x3B4 and 0x3B5, and the Input Status Register 1 maps to 0x3BA.
    • When set to 1, the card configures itself for color emulation. The CRTC index and data registers map to 0x3D4 and 0x3D5, and the Input Status Register 1 maps to 0x3DA.

When an application or the system BIOS requests a monochrome mode (such as BIOS video mode 7), the display system clears Bit 0, relocating the CRTC controls to the 0x3Bx range. When switching to a standard color text or graphics mode (such as BIOS modes 3, 12h, or 13h), the bit is set to 1, shifting the registers back to the 0x3Dx space.

By dynamically relocating the CRTC I/O base address based on the active display mode, VGA guaranteed seamless compatibility with the vast ecosystem of software written for both the MDA and CGA standards.
