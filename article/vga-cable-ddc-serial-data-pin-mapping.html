VGA Cable DDC Serial Data Pin Mapping

This article explains the pin mapping for the Display Data Channel (DDC) serial data line on a standard 15-pin Video Graphics Array (VGA) connector. It covers the specific pin designation required for bidirectional data transfer, the supplementary pins that enable DDC functionality, and how this hardware interface facilitates plug-and-play communication between a display device and a host graphics adapter.

On a modern 15-pin DE-15 VGA cable, the pin assigned to DDC serial data (SDA) is Pin 12.

Under the VESA DDC2B standard, the VGA interface uses an I²C serial bus protocol to enable communication between the graphics card and the monitor. Pin 12 carries the bidirectional serial data signal, which allows the host system to read the monitor's Extended Display Identification Data (EDID). This data provides the computer with critical display capabilities, such as supported resolutions, refresh rates, and color spaces.

To complete the DDC I²C bus circuit, Pin 12 operates alongside a set of complementary pins:

  • Pin 12 (SDA): DDC Serial Data / I²C Data line.
  • Pin 15 (SCL): DDC Serial Clock / I²C Clock line, which synchronizes data transmission.
  • Pin 9 (+5V DC): Provides +5 volts of power from the graphics adapter to power the monitor's EEPROM chip so the computer can read the EDID even if the monitor is powered off.
  • Pin 10 (GND): Sync Ground and DDC Ground, providing the common reference voltage for the digital communication signals.

In legacy VGA implementations prior to DDC2, Pin 12 was designated as an ID line (Monitor ID Bit 1). Modern systems exclusively use Pin 12 for DDC serial data to maintain standardized plug-and-play display configuration.
