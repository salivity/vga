How INT 10h AH=00h Initializes VGA Display Modes

The x86 real-mode interrupt INT 10h, AH=00h serves as the standard BIOS system call used to switch and initialize Video Graphics Array (VGA) display modes. This operation configures both the video adapter hardware and the system software environment by referencing static BIOS parameter tables, programming low-level VGA controller registers, clearing frame buffers, and updating the BIOS Data Area (BDA) with the active display geometry.

Register Calling Convention and Mode Selection

When a program invokes INT 10h with AH set to 00h, the register AL specifies the target video mode. Standard VGA defines several legacy and native modes, including Mode 03h (80x25 text mode), Mode 12h (640x480 16-color graphics), and Mode 13h (320x200 256-color graphics).

The most significant bit of AL (Bit 7) serves as a special control flag. If Bit 7 is set (AL OR 80h), the BIOS suppresses the default clearing of video display memory during the transition. If Bit 7 is cleared, the BIOS clears all relevant video RAM planes.

Looking Up BIOS Parameter Tables

The video BIOS maintains internal parameter tables corresponding to each supported mode number. Once invoked, the routine extracts timing constants, clock selection bits, memory maps, and controller configurations mapped to the requested mode index. If an invalid or unsupported mode number is supplied in AL, the routine generally aborts without modifying the display or falls back to a default configuration.

Programming the VGA Subsystems

VGA hardware consists of multiple discrete internal logic blocks. The BIOS programs each block by writing register indices to base address ports and corresponding parameters to data ports:

  1. Sequencer (I/O Ports 3C4h / 3C5h): The BIOS first places the sequencer into synchronous reset by writing to Index 00h. It then loads configuration values, including clocking mode (character clock rate, dot-clock division), plane write masks, and memory access modes, before releasing the reset.
  2. Miscellaneous Output Register (I/O Port 3C2h): The BIOS programs this write-only register to select the master clock source (25.175 MHz or 28.322 MHz), choose the I/O port address decoding scheme (monochrome at 3Bx vs. color at 3Dx), enable video RAM access, and define horizontal and vertical sync polarities.
  3. Cathode Ray Tube Controller (CRTC, I/O Ports 3D4h / 3D5h for color): Because CRTC registers 00h through 07h are write-protected by bit 7 of register 11h, the BIOS first clears this bit. It then writes values defining horizontal and vertical timings, blanking intervals, sync pulse widths, scanline counts per character, and the start address of display memory. Protection is typically restored afterward.
  4. Graphics Controller (I/O Ports 3CEh / 3CFh): The BIOS configures how the CPU reads and writes video RAM planes. It sets read/write modes, plane latches, color compare values, shift modes (e.g., bit-plane formatting versus packed-pixel byte modes), and the memory map base address (such as segment A000h for graphics or B800h for color text).
  5. Attribute Controller (I/O Ports 3C0h / 3C1h): Accessed via a flip-flop toggle at port 3DAh (Input Status Register 1), this unit routes plane data to the palette. The BIOS writes internal palette mappings, mode control flags (enabling graphics mode or blink/intensity toggles), overscan (border) colors, and color plane enables. Finally, port 3C0h is written with bit 5 set to re-enable video output.

Palette and DAC Configuration

For color graphics modes such as 12h and 13h, the BIOS configures the Digital-to-Analog Converter (RAMDAC) through ports 3C8h (write index) and 3C9h (data). The routine loads default color palettes:

  • In 16-color modes, the 16 Attribute Controller palette registers are set to point to predefined DAC indices.
  • In Mode 13h, the BIOS streams 256 default RGB triplets (covering standard colors, grayscale blocks, and color gradients) directly into the RAMDAC color registers.

Clearing Display Memory and Updating System State

Unless suppressed by bit 7 of AL, the BIOS clears display memory by writing zeroes to video RAM starting at the configured segment (A000h for graphics modes, or filling text modes at B800h with blank space character 20h and standard attribute 07h). In text modes, character fonts stored in ROM are also uploaded to plane 2 using the Sequencer and Graphics Controller.

Finally, the BIOS synchronizes internal state variables inside the BIOS Data Area (segment 0040h):

  • 0040:0049h: Stores the current video mode.
  • 0040:004Ah: Stores the number of character columns (e.g., 40 or 80).
  • 0040:004Ch: Stores the regenerated video buffer size in bytes.
  • 0040:004Eh: Stores the current page offset address.
  • 0040:0050h–005Fh: Resets cursor position registers for up to eight display pages to (0, 0).
  • 0040:0060h–0061h: Sets the cursor scanline shape (start/end lines).
  • 0040:0084h: Stores character rows minus one (e.g., 24 for standard 25-row modes).
  • 0040:0085h: Stores character point size (height in scanlines, e.g., 8, 14, or 16).

Once these memory locations are updated, the BIOS completes execution and executes an IRET instruction, returning control to the caller with the display hardware fully synchronized.
