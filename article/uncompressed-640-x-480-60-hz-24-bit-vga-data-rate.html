Uncompressed 640x480 60Hz 24-Bit VGA Data Rate

This article breaks down the mathematical calculation required to determine the exact bandwidth and data rate for streaming raw, uncompressed 640x480 video at 60 frames per second with a 24-bit color depth. By analyzing the pixel count, color depth per pixel, and refresh rate, you will find the total active payload transfer rate expressed in megabytes per second using standard decimal and binary notations, as well as the transmission rate required when accounting for standard video timing signals.

Step-by-Step Calculation for Active Video Data

To find the raw payload data rate for the visible portion of the screen, multiply the screen resolution, color depth, and refresh rate:

  1. Calculate Total Pixels per Frame: \[640 \text{ (horizontal)} \times 480 \text{ (vertical)} = 307,200 \text{ pixels per frame}\]

  2. Calculate Bytes per Frame: A 24-bit color depth (TrueColor) uses 8 bits per channel (Red, Green, Blue), which equals 3 bytes per pixel: \[307,200 \text{ pixels} \times 3 \text{ bytes} = 921,600 \text{ bytes per frame}\]

  3. Calculate Total Bytes per Second: Multiply the bytes per frame by the 60 Hz refresh rate (60 frames per second): \[921,600 \text{ bytes/frame} \times 60 \text{ frames/second} = 55,296,000 \text{ bytes per second}\]

Final Data Rate in Megabytes per Second

Depending on the measurement standard applied, the total active data rate is:

  • Decimal Megabytes (MB/s): Using the standard SI system (\(1 \text{ MB} = 1,000,000 \text{ bytes}\)): \[\frac{55,296,000 \text{ bytes/s}}{1,000,000} = \mathbf{55.296 \text{ MB/s}}\]

  • Binary Mebibytes (MiB/s): Using the IEC binary system (\(1 \text{ MiB} = 1,048,576 \text{ bytes}\)): \[\frac{55,296,000 \text{ bytes/s}}{1,048,576} \approx \mathbf{52.73 \text{ MiB/s}}\]

In terms of raw network and bus transmission speed, this equates to 442.368 Megabits per second (Mbps).

Total Transmission Rate with Blanking Intervals

When transmitted across a physical display interface (such as analog VGA or DVI/HDMI), the signal includes horizontal and vertical blanking intervals (front porch, sync pulse, and back porch).

Standard 640x480 @ 60Hz video timing requires a total frame dimension of 800 horizontal pixels by 525 vertical lines with a pixel clock frequency of 25.175 MHz:

  • \(25,175,000 \text{ pixels/s} \times 3 \text{ bytes/pixel} = 75,525,000 \text{ bytes per second}\)
  • Total Interface Data Rate: 75.525 MB/s (or ~72.03 MiB/s / 604.2 Mbps)
