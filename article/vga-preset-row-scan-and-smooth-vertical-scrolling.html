VGA Preset Row Scan and Smooth Vertical Scrolling

The Video Graphics Array (VGA) Preset Row Scan register provides the hardware-level mechanism required to scroll the display vertically by single-pixel scanlines rather than abrupt full-row increments. By specifying which internal scanline within a character row or memory block the display hardware should start rendering at the top of the monitor, this register allows software to create fluid, tear-free vertical scrolling across both text and planar graphics modes.

Coarse Scrolling vs. Fine Scrolling

Standard hardware scrolling on the VGA adapter is typically achieved by altering the CRTC (Cathode Ray Tube Controller) Start Address registers (CRTC index 0Ch and 0Dh). These registers define the memory offset where the electron beam begins fetching visual data at the start of a vertical refresh cycle.

However, altering only the Start Address produces "coarse" scrolling. In graphics modes or text modes, changing this memory pointer jumps the screen by an entire memory row (typically multiples of bytes, or entire 8- to 16-pixel-tall character cells). This results in a choppy, jumping effect that moves several physical scanlines per frame. To achieve smooth scrolling, the VGA requires an additional register to control the sub-row vertical offset: the Preset Row Scan register.

The Preset Row Scan Register (CRTC Index 08h)

The Preset Row Scan register is mapped to CRTC index 08h (accessed via I/O port 0x3D4 for index and 0x3D5 for data in standard color modes).

Bits 0 through 4 of this register represent the preset row scan count (values 0–31). When the VGA raster generator begins drawing a screen at the start of an active display cycle, its internal scanline counter normally resets to zero. When a value is written to the Preset Row Scan register, the hardware presets the internal row scan counter to that value for the very first row displayed at the top of the screen.

Because the raster beam skips the scanlines prior to the preset value for that initial row, the entire display output shifts upward by that exact number of individual scanlines. After the first partial row is rendered, the internal row scan counter resets back to zero for all subsequent rows until the frame completes.

Implementation Process for Smooth Vertical Scrolling

Smooth vertical scrolling relies on synchronizing the Preset Row Scan register and the Start Address registers with the vertical retrace interval (VBLANK) to prevent visual tearing. The process operates as follows:

  1. Wait for Vertical Retrace: The software polls input status register 1 (0x3DA) to detect the vertical blanking interval, ensuring register updates do not occur while the beam is actively drawing visible pixels.
  2. Increment Scanlines: To scroll down (moving the viewport down, visual elements up), the programmer increments the Preset Row Scan register value by 1 each frame. The hardware begins the top row at scanline 1, then scanline 2, and so forth, pushing the picture smoothly upward one physical raster line at a time.
  3. Handle Row Boundaries: The maximum value for the register matches the height of the row minus one (defined in the Maximum Scan Line register, CRTC index 09h). When the Preset Row Scan register reaches this limit:
    • The Preset Row Scan value is reset to 0.
    • The CRTC Start Address register is simultaneously increased by the size of one complete row in video memory.
  4. Repeat: The cycle restarts from scanline 0 at the new base memory address, creating a seamless and continuous single-pixel scrolling loop.

By combining the sub-row scanline offset of the Preset Row Scan register with the larger byte jumps of the Start Address registers, VGA programs can scroll through megabytes of virtual display space with per-pixel vertical fluidity.
