How VGA Cards Buffered DAC Writes to Stop Screen Noise

Early Video Graphics Array (VGA) adapters often suffered from visible screen artifacts, commonly referred to as "snow" or jitter, whenever the host processor updated the color palette during active display refresh cycles. To eliminate this distortion, high-end VGA controllers and high-performance RAMDACs (Random Access Memory Digital-to-Analog Converters) moved away from direct-access palette memory. Instead, manufacturers introduced hardware write FIFOs, dual-ported Color Look-Up Tables (CLUT), and blanking-synchronized shadow registers, allowing the central processor to execute color changes at full bus speeds without disrupting the timing-critical raster scanning beam.

The Source of RAMDAC Visual Noise

In standard VGA architecture, the RAMDAC continuously reads pixel values from Video RAM (VRAM) and translates them into analog RGB signals via an internal palette lookup table. In low-cost implementations, this lookup table was built using single-ported SRAM. If the CPU wrote new RGB color values to the palette registers while the RAMDAC was indexing that same memory to generate video output, bus contention occurred. The DAC would momentarily read invalid, floating, or collided data, translating into erratic pixel voltages that manifested on CRT monitors as flickering horizontal specks or lines.

FIFO Write Buffering

To decouple host CPU write cycles from the display refresh pipeline, advanced VGA controllers incorporated First-In, First-Out (FIFO) write queues. When software wrote to the RAMDAC data ports (typically I/O ports 0x3C8 and 0x3C9), the transactions were immediately absorbed by the VGA chipset's internal write buffer rather than touching the palette memory directly.

This FIFO held the target palette address and the three consecutive bytes (Red, Green, Blue) required for a complete color definition. The controller then monitored the display state machine and autonomously drained the FIFO into the actual DAC registers only when the electron beam was turned off, specifically during:

  • Horizontal Blanking (HBLANK): The brief window when the beam reset to the start of the next scanline.
  • Vertical Blanking (VBLANK): The longer period when the beam traveled from the bottom of the screen back to the top.

Because the buffer absorbed writes instantly, the CPU was spared from having to execute wait loops or poll the VGA Status Register (checking for the vertical retrace bit), dramatically increasing game and graphical rendering performance while maintaining clean output.

Dual-Ported Palette Architectures

The most sophisticated VGA and Super VGA (SVGA) cards utilized standalone, high-performance RAMDAC chips (such as those manufactured by Brooktree, Inmos, or Sierra) equipped with true dual-ported SRAM cells for the color palette.

In a dual-ported design, the lookup table possesses two physically independent sets of address and data lines:

  1. The Read Port: Exclusively dedicated to the high-speed pixel pipeline, continuously indexing the palette based on incoming pixel bits from VRAM.
  2. The Write Port: Dedicated to host CPU configuration, interfaced through the bus interface unit.

Because read and write operations operated on isolated silicon pathways, memory read cycles for scanout were never interrupted by incoming CPU modifications. Even if an update coincided with an active pixel draw, the internal memory cells held their read state stable for the DAC conversion cycle, wholly preventing screen snow without requiring the CPU to wait for blanking periods.

Multi-Stage RGB Latching and Atomic Updates

VGA palette updates require a sequential three-byte sequence to represent red, green, and blue color intensities. Without buffering, a partial write (for instance, setting red while green and blue retained previous values) would cause visible color fringing for at least one frame.

High-end cards solved this by implementing three internal staging latches. Incoming bytes were held in temporary registers until the complete 24-bit (or 18-bit) triplet was fully received. The hardware then performed an atomic transfer from the staging latches into the active palette table in a single clock cycle, ensuring color transitions occurred simultaneously across all three analog channels without mid-frame palette corruption.
