What Is the VGA Synchronous Reset Register Bit?

The Video Graphics Array (VGA) Synchronous Reset register bit is a hardware control mechanism designed to safely halt the internal sequencer of a VGA controller without corrupting dynamic RAM or video memory. This article explains the exact location and function of the Synchronous Reset bit, how it contrasts with an asynchronous reset, and its critical role in facilitating clean video mode switching and clock reconfiguration.

Location and Register Layout

The Synchronous Reset bit resides in the VGA Sequencer register group:

  • I/O Port: Indexed via 0x03C4, data accessed via 0x03C5
  • Register Index: 0x00 (Reset Register)
  • Bit Position: Bit 1 (Bit 0 is the Asynchronous Reset bit)

When bit 1 is set to 1, the sequencer runs normally. When bit 1 is cleared to 0, the sequencer initiates a synchronous reset.

Primary Function

The primary function of the Synchronous Reset bit is to halt sequencer operations at the completion of the current memory cycle.

The VGA sequencer is responsible for generating internal timing signals, character clock generation, and arbitrating memory cycles between the display controller and the host CPU. If the sequencer timing is interrupted mid-cycle, dynamic RAM refresh cycles can be truncated, and incomplete read/write operations can cause visible screen artifacts ("snow") or corrupted display memory.

Setting the Synchronous Reset bit to 0 instructs the sequencer to finish its active memory operation and cleanly transition to an idle state. During this synchronous idle state:

  • Sequencer timing outputs are held in a stable, defined state.
  • Video memory arbitration is paused cleanly.
  • Video output to the digital-to-analog converter (DAC) is suppressed, effectively blanking display artifacts.

Synchronous Reset vs. Asynchronous Reset

Register 0x00 provides two reset bits with distinct behaviors:

  • Asynchronous Reset (Bit 0): Clearing this bit forces an immediate halt of the sequencer logic, regardless of where it is within a memory or clock cycle. This can interrupt dynamic RAM refresh cycles and corrupt display memory.
  • Synchronous Reset (Bit 1): Clearing this bit delays the halt until the end of the current cycle, preserving the integrity of the video memory and dynamic RAM refresh sequencing.

Common Use Cases

  1. Video Mode Switching: Software clears bit 1 (along with bit 0) before modifying fundamental video timing registers, such as the Clocking Mode register (0x01) or the Miscellaneous Output Register.
  2. Clock Frequency Selection: Changing dot clocks (such as switching between 25 MHz and 28 MHz) generates transient clock glitches. Putting the sequencer into a synchronous reset state isolates internal logic from these glitches until the new clock stabilizes.
  3. Restoring Normal Operation: Once new configuration parameters are written to the Sequencer and Cathode Ray Tube Controller (CRTC) registers, the software sets both reset bits back to 1 (writing 0x03 to index 0x00), allowing the sequencer to resume normal scanning cleanly from the start of a frame.
