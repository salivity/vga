How VGA Memory Avoids 0xB0000 Legacy Conflicts

The Video Graphics Array (VGA) architecture prevents memory conflicts with legacy monochrome display adapters at address 0xB0000 through dynamic, programmable memory mapping controlled by internal hardware registers. By allowing the system to isolate graphics modes to the 0xA0000 memory range, restrict color text modes to 0xB8000, and selectively enable or disable the 0xB0000 region, the VGA standard ensures backward compatibility while permitting dual-monitor configurations with legacy Monochrome Display Adapter (MDA) hardware.

In the original IBM PC memory architecture, video memory was allocated a 128 KB segment ranging from 0xA0000 to 0xBFFFF. This block was divided among distinct display standards:

  • 0xA0000 – 0xAFFFF (64 KB): Reserved for EGA/VGA bitmapped graphics modes.
  • 0xB0000 – 0xB7FFF (32 KB): Reserved for monochrome text and graphics (MDA and Hercules).
  • 0xB8000 – 0xBFFFF (32 KB): Reserved for color text and CGA-compatible graphics.

VGA manages this address space using the Miscellaneous Register of the Graphics Controller, accessed by writing index 0x06 to port 0x3CE and reading or writing data through port 0x3CF. Bits 3 and 2 of this register configure the Memory Map Select, dictating how VGA video RAM is decoded into the CPU's memory space:

  • Value 00b (128 KB at 0xA0000 – 0xBFFFF): Direct mapping across the entire video window, used in specialized native VGA graphics configurations where no legacy display adapters are present.
  • Value 01b (64 KB at 0xA0000 – 0xAFFFF): Standard VGA graphics modes (such as Mode 12h, 640x480 16-color, or Mode 13h, 320x200 256-color). The entire 0xB0000 to 0xBFFFF block is unmapped by the VGA controller, leaving 0xB0000 accessible to a physical monochrome card.
  • Value 10b (32 KB at 0xB0000 – 0xB7FFF): Dedicated monochrome emulation mode. VGA decodes text directly at the MDA address space when operating as the primary monochrome display.
  • Value 11b (32 KB at 0xB8000 – 0xBFFFF): Standard color text modes (such as 80x25 text Mode 03h). The VGA adapter decodes memory exclusively above 0xB8000, leaving the lower 0xB0000 – 0xB7FFF region floating on the bus for legacy monochrome hardware.

Beyond memory address decoding, VGA addresses I/O port conflicts using bit 0 of the Miscellaneous Output Register (write port 0x3C2, read port 0x3CC). Setting this bit to 1 routes CRT controller registers to color I/O ports (0x3D4 and 0x3D5), while setting it to 0 routes them to monochrome I/O ports (0x3B4 and 0x3B5).

By pairing I/O address remapping with the 64 KB or color-only 32 KB memory map selections, the VGA adapter completely vacates the physical 0xB0000 memory window and the 0x3Bx port range during normal color operations. This hardware separation allows a VGA card and a legacy monochrome card to coexist on the same ISA bus without bus contention.
