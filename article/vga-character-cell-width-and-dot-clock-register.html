VGA Character Cell Width and Dot Clock Register

In Video Graphics Array (VGA) architecture, the Sequencer Clocking Mode Register is the primary register responsible for configuring character cell width and dot duplication behavior. This article explains how this specific hardware register operates, the exact bit flags used to switch between 8-dot and 9-dot character widths, and how clock division enables horizontal dot duplication across various display modes.

The Sequencer Clocking Mode Register

The register controlling both horizontal dot sizing and pixel doubling is the Clocking Mode Register, located at Index 01h within the VGA Sequencer register group.

To access or modify this register:

  1. Write the value 0x01 to the Sequencer Index Port (0x3C4).
  2. Read from or write to the Sequencer Data Port (0x3C5).

Controlling Character Cell Width (Bit 0)

Bit 0 of the Clocking Mode Register specifies the 8/9 Dot Clocks setting. This bit dictates whether characters are rendered using an 8-dot or 9-dot wide matrix:

  • Bit 0 = 0 (9-Dot Mode): The sequencer generates 9 dot clocks per character cell. This mode is typically used in standard alphanumeric modes (such as 80x25 text mode on monochrome and color displays) to achieve a 720-pixel horizontal resolution (80 characters × 9 dots = 720 pixels). In this mode, the ninth column of characters is either blank or duplicated from the eighth column depending on the font configuration.
  • Bit 0 = 1 (8-Dot Mode): The sequencer generates 8 dot clocks per character cell. This is standard for 640-pixel graphics modes (such as Mode 12h) and 40-column text modes (40 characters × 8 dots = 320 pixels).

Controlling Dot Duplication (Bit 3)

Bit 3 of the Clocking Mode Register specifies the Dot Clock Divide (or Halve) behavior, directly controlling dot duplication:

  • Bit 3 = 0 (Normal Dot Clock): Master clock cycles directly advance the video output shift registers at normal speed, drawing one distinct dot per clock cycle.
  • Bit 3 = 1 (Dot Clock Divided by 2): The sequencer divides the dot clock frequency by two before applying it to the display logic. Consequently, each pixel or dot is held on the screen for twice the normal duration. This creates horizontal dot duplication, doubling the effective width of pixels.

This dot duplication feature is critical for standard low-resolution graphics modes, such as Mode 13h (320x200), allowing a 320-pixel horizontal raster to be driven using standard 640-pixel monitor scan timings.
