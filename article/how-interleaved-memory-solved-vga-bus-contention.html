How Interleaved Memory Solved VGA Bus Contention

Interleaved memory architectures on advanced Video Graphics Array (VGA) and Super VGA (SVGA) cards resolved memory bus contention by dividing video memory into independent, alternating banks. In traditional unified architectures, the host CPU and the Cathode Ray Tube Controller (CRTC) constantly fought for access to the same dynamic RAM (DRAM), causing severe processing wait states and screen flicker. By staggering memory access across even and odd banks, interleaved memory allowed the graphics controller to prefetch display data while leaving parallel windows open for the CPU, effectively multiplying available bandwidth and eliminating access bottlenecks without requiring expensive dual-ported VRAM.

The Memory Bus Contention Bottleneck

Standard VGA architectures relied on a single shared pool of DRAM to store frame data. This design created a fundamental conflict between two distinct hardware masters:

  1. The Display Controller (CRTC): Required continuous, predictable, high-priority read access to stream pixel data to the digital-to-analog converter (RAMDAC) in synchronization with the monitor’s raster beam.
  2. The Host CPU: Required write and read access to update frame buffers, render 2D graphics, and execute software instructions.

Because conventional single-bank DRAM could only serve one address at a time, the CRTC claimed priority during active display scans. When the CPU attempted to access video memory during this active period, the graphics chipset was forced to insert CPU wait states, severely degrading system performance. Alternatively, if CPU writes were prioritized, the display controller experienced data starvation, producing visible display artifacts known as "snow."

The Mechanism of Interleaved Memory

Interleaved memory resolved this conflict by splitting physical DRAM into two or more distinct banks (typically an "even" bank and an "odd" bank) mapped to alternating sequential memory addresses. Instead of a single 16-bit or 32-bit bus accessing a single bank, the memory controller managed separate control lines (such as Row Address Strobe and Column Address Strobe) across these parallel banks.

DRAM requires a specific recovery and precharge cycle after every read or write before it can be accessed again. By alternating access between banks:

  • While Bank 0 was actively transferring data, Bank 1 could undergo precharging.
  • While the display controller read sequential pixel data across the alternating banks, it could fetch wide words (e.g., 32-bit or 64-bit blocks) in a single burst by cycling between banks faster than the access cycle time of an individual DRAM chip.

Resolving the Contention

Advanced VGA chipsets (such as the Tseng Labs ET4000 series and Cirrus Logic controllers) leveraged memory interleaving to overcome contention through three specific techniques:

1. Faster Display FIFO Filling

Because the CRTC read contiguous horizontal pixels, sequential raster lines hit alternating memory banks. This allowed the display controller to utilize page-mode or interleaved bursting to fill internal First-In, First-Out (FIFO) buffer queues in roughly half the clock cycles required by a non-interleaved design.

2. Expanded CPU Access Windows

Once the graphics controller rapidly filled its internal FIFOs using interleaved bursts, it released the memory bus. This created extended idle windows on the video memory bus during active display cycles. The memory controller utilized these free cycles to grant the CPU immediate access to RAM, dramatically reducing or entirely removing CPU wait states.

3. Low-Cost Dual-Port Emulation

True dual-ported video RAM (VRAM) physically featured two separate access ports—a serial port for the CRTC and a parallel port for the CPU—allowing simultaneous access without contention. However, VRAM was prohibitively expensive for standard consumer cards. Interleaving dynamic RAM delivered performance comparable to dual-ported VRAM by using fast time-division multiplexing across alternating low-cost DRAM banks.

By eliminating the wait states caused by bus collisions, interleaved memory architectures unlocked the higher resolutions (800x600, 1024x768) and 16-bit or 24-bit color depths that defined the SVGA era, ensuring smooth rendering without starving the display hardware of critical video data.
