Why VGA Text Mode Uses 720x400 Resolution

Standard Video Graphics Array (VGA) text mode operates at a resolution of 720x400 instead of 640x400 because it utilizes a 9x16 pixel character cell rather than an 8x16 cell. When displaying the standard 80 columns and 25 rows of text, an 80-column layout using 9-pixel-wide characters requires precisely 720 horizontal pixels, while 25 rows using 16-pixel-tall characters require 400 vertical scanlines. This hardware configuration was chosen to match the crisp typography of earlier business displays, maintain continuous line-drawing characters, and fit within standard CRT monitor refresh timings.

The Math Behind the Character Grid

Standard DOS text mode specifies an array of 80 text columns across 25 vertical rows. In graphical terms, the screen resolution is determined directly by the size of the character box assigned to each text cell:

  • Horizontal Resolution: 80 columns × 9 pixels per character = 720 pixels
  • Vertical Resolution: 25 rows × 16 scanlines per character = 400 lines

If VGA text mode had used an 8-pixel-wide character box, the resulting resolution would have been 640x400. However, using 8-pixel cells leaves characters cramped, reducing readability during prolonged office work.

Legacy of the IBM Monochrome Display Adapter (MDA)

The decision to adopt a 9-pixel width stemmed from the high standard established by IBM's earlier Monochrome Display Adapter (MDA) in 1981. The MDA paired with IBM's 5151 monochrome monitor used a 9x14 character box at a 720x350 resolution. Business users favored MDA over the Color Graphics Adapter (CGA)—which used narrow 8x8 characters at 640x200—because MDA text was sharp and easy on the eyes.

When IBM designed VGA to replace both MDA and EGA (Enhanced Graphics Adapter), they ensured that VGA text quality met or exceeded MDA standards. By using a 9x16 matrix, VGA achieved sharper vertical definition than MDA (16 scanlines versus 14) while matching MDA’s superior 9-pixel horizontal width.

Hardware Font Duplication and Box Drawing

Although the active character matrix is 9 pixels wide, the character glyphs stored in the VGA font ROM are actually only 8 pixels wide. The VGA hardware sequencer handles the 9th pixel automatically based on the character code:

  1. Standard Characters: For alphanumeric characters (ASCII codes outside the box-drawing range), the hardware automatically inserts an empty 9th pixel column to the right of the glyph. This acts as built-in character spacing without wasting ROM storage space.
  2. Line-Drawing Characters: For IBM code page 437 box-drawing symbols (specifically ASCII characters 192 through 223, or 0xC0 to 0xDF), the hardware automatically replicates the 8th pixel into the 9th pixel position. This duplication ensures that horizontal lines, double borders, and solid blocks seamlessly connect across character boundaries without visible vertical gaps.

Video Timings and the 28.322 MHz Dot Clock

To display 720 pixels horizontally within standard analog monitor limits, IBM included dual crystal oscillators on the VGA board.

Standard VGA graphics modes (such as 640x480) run at a 25.175 MHz dot clock with a 60 Hz vertical refresh rate. To accommodate 720 horizontal pixels within the standard ~31.468 kHz horizontal line frequency of VGA monitors, the card switches to a faster 28.322 MHz dot clock. This higher pixel clock allows the monitor to scan through 720 pixels per line (plus horizontal blanking intervals) at a vertical refresh rate of 70 Hz.

By running 400 scanlines at 70 Hz, VGA matches the exact 31.468 kHz horizontal sync frequency as 480 scanlines at 60 Hz:

\[\frac{31{,}468\text{ Hz}}{449\text{ total lines}} \approx 70.08\text{ Hz}\]

This synchronization allowed analog CRT monitors to display stable 720x400 text alongside 640x480 graphics without requiring internal horizontal deflection adjustments.
