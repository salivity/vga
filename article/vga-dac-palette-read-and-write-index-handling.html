VGA DAC Palette Read and Write Index Handling

The Video Graphics Array (VGA) uses a dedicated color palette system managed by the Color Lookup Table (CLUT) inside the RAMDAC. This article explains how the VGA DACPEL registers coordinate palette read and write operations, detailing how internal address registers maintain separate read and write indexes, handle three-stage RGB byte sequencing, and automatically advance through the 256 available color registers.

DACPEL Port Assignments

The VGA palette interface relies on three primary I/O port addresses to manage color registers:

  • Port 0x3C8 (PEL Address Write Mode Register): Accepts an 8-bit color index (0 to 255) where a palette modification will begin.
  • Port 0x3C7 (PEL Address Read Mode / DAC State Register): When written to, it sets the starting 8-bit color index for reading palette data. When read from, it reports whether the DAC is currently in Read mode, Write mode, or inactive.
  • Port 0x3C9 (PEL Data Register): The bidirectional data port through which Red, Green, and Blue component values are transferred.

The Write Index Operation

To define colors, software writes the starting index (0–255) to I/O port 0x3C8. This action sets the internal Write Index and resets an internal component counter to the Red cycle.

Writing palette data to port 0x3C9 follows a strict sequence:

  1. First byte: Red intensity (standard 6-bit value, 0–63).
  2. Second byte: Green intensity (6-bit value, 0–63).
  3. Third byte: Blue intensity (6-bit value, 0–63).

The hardware maintains an internal modulo-3 counter tracking these components. Once the third byte (Blue) is transferred, the RAMDAC commits the new 18-bit color to the palette RAM, increments the Write Index by one, and resets the component cycle back to Red. This auto-increment feature allows software to update multiple contiguous palette entries by setting the initial index once and then streaming sequential RGB triplets into port 0x3C9.

The Read Index Operation

To inspect existing color definitions, software initiates a read by writing the starting index (0–255) to I/O port 0x3C7. Writing to this port sets the internal Read Index, resets the component counter to Red, and places the DAC into Read mode.

Reading sequentially from port 0x3C9 yields:

  1. First read: Red component.
  2. Second read: Green component.
  3. Third read: Blue component.

As with writing, reading the third component automatically increments the internal Read Index by one and points the component counter back to Red, enabling continuous sequential reading of palette entries without repeatedly reprogramming the index port.

Mode Separation and DAC State

The VGA hardware separates read and write indexes into distinct internal registers. Setting an index on port 0x3C8 prepares the system strictly for writes, while writing to port 0x3C7 prepares it strictly for reads.

Reading directly from port 0x3C7 allows software to determine the current operational mode via bits 0 and 1:

  • 00b: DAC is set to Read mode (ready for data reads on 0x3C9).
  • 11b: DAC is set to Write mode (ready for data writes on 0x3C9).

If a read or write operation is interrupted before completing all three RGB components, writing a new value to either 0x3C7 or 0x3C8 resets the internal component counter, ensuring that subsequent accesses to port 0x3C9 always begin at the Red component of the newly addressed index.
