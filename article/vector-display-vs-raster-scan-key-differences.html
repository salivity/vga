Vector Display vs Raster Scan: Key Differences

This article examines the core architectural and operational differences between vector display systems and the raster scanning method popularized by Video Graphics Array (VGA). While vector displays generate graphics by directly tracing continuous lines between coordinates using an electron beam, raster displays draw an entire scene line-by-line across a predefined pixel grid. Understanding these two display paradigms highlights the evolutionary shift from early wireframe CRT systems to modern pixel-based visual rendering.

Beam Path and Drawing Mechanics

The primary technical distinction lies in how the cathode-ray tube (CRT) electron beam is steered across the screen:

  • Vector Displays (Random Scan): The electron beam is directed only to parts of the screen where an image is to be drawn. It moves directly from one coordinate pair \((X_1, Y_1)\) to another \((X_2, Y_2)\) to trace out lines, text, and geometric shapes. When a line is finished, the beam turns off (blanks) and relocates to the next coordinate set.
  • Raster Scanning (VGA): The electron beam follows a fixed, repetitive path across the entire face of the display regardless of the image content. Starting at the top-left corner, it sweeps horizontally from left to right, shuts off during horizontal blanking to reset to the left of the next line down, and repeats this until reaching the bottom right. A vertical blanking interval resets the beam back to the top left. VGA dynamically modifies the beam's intensity at fixed intervals along this path to activate individual phosphor dots (pixels).

Resolution and Visual Fidelity

Because vector displays do not rely on an underlying grid of discrete pixels, they produce smooth, continuous lines. Diagonals and curves show no aliasing, "stair-stepping," or pixelation, effectively offering resolution limited only by the precision of the deflection circuitry and the beam focus.

In contrast, VGA raster systems are bound by a fixed resolution matrix (typically 640×480 pixels in standard VGA at a 60 Hz refresh rate). Diagonal lines and curved geometries frequently exhibit aliasing artifacts unless processed with software anti-aliasing techniques. However, raster scan technology excels at rendering complex, filled shapes, subtle gradients, and photographic imagery—tasks that are virtually impossible for pure vector hardware.

Memory Architecture and Complexity Limits

Vector and raster systems approach memory and scene complexity from opposing directions:

  • Display Lists vs. Frame Buffers: Vector systems utilize a "display list" or program stored in memory, containing commands that tell the beam where to move next. Raster systems like VGA rely on a dedicated frame buffer in video RAM (VRAM), where every pixel location on the screen corresponds to a specific memory address that holds color and intensity data.
  • Flicker vs. Fixed Refresh Rates: In a vector system, the refresh rate depends on the number of lines being drawn. If an image contains too many vectors, the beam cannot re-trace all lines before the phosphor begins to fade, resulting in visible flickering. In a VGA raster display, the refresh rate remains completely constant (e.g., 60 Hz or 70 Hz), because the beam always travels across every line of the screen regardless of how simple or complex the visual scene is.
