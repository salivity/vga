How VGA Planar Modes Achieve Quad-Pixel Writes

This article explains the hardware mechanism that allows planar Video Graphics Array (VGA) modes to draw four adjacent pixels in a single memory cycle. By configuring VGA memory into an unchained planar layout—commonly known as "Mode X"—and enabling all four memory planes simultaneously through the Sequencer's Map Mask register, a single 8-bit CPU write operation is broadcast to four independent memory banks at once, plotting four contiguous pixels simultaneously.

Planar Memory Architecture

Standard VGA graphics hardware contains 256 KB of video RAM organized into four physical 64 KB memory banks called planes (Plane 0, Plane 1, Plane 2, and Plane 3).

In linear display modes (such as standard Mode 13h, 320x200 with 256 colors), the VGA hardware automatically cycles through these planes behind the scenes so the CPU sees memory as a continuous linear array where one address equals one pixel.

In planar configurations (often termed "unchained" modes or "Mode X"), this linear translation is disabled by modifying the Sequencer Memory Mode register. This unchains the memory architecture and maps all four planes directly to the same 64 KB memory segment starting at address 0xA0000.

Pixel Distribution Across Planes

Once unchained, each consecutive horizontal pixel on the screen resides in a different memory plane at the exact same CPU address offset:

  • Plane 0: Holds pixels 0, 4, 8, 12, ...
  • Plane 1: Holds pixels 1, 5, 9, 13, ...
  • Plane 2: Holds pixels 2, 6, 10, 14, ...
  • Plane 3: Holds pixels 3, 7, 11, 15, ...

Because each plane supplies the 8-bit color index for every fourth pixel, four consecutive pixels horizontally share the exact same byte address in the video buffer.

The Map Mask Register Trick

The hardware trick to writing four pixels in a single cycle lies in the VGA Sequencer's Map Mask Register (I/O Port 0x3C5, Index 0x02).

The lower four bits of the Map Mask register act as hardware write-enable switches for the four individual planes:

  • Bit 0: Enables writes to Plane 0
  • Bit 1: Enables writes to Plane 1
  • Bit 2: Enables writes to Plane 2
  • Bit 3: Enables writes to Plane 3

By writing 0x0F to the Map Mask Register, the developer instructs the VGA hardware to enable all four memory planes simultaneously for write operations.

Executing the Quad-Pixel Write

When the CPU executes a single 8-bit write instruction (e.g., MOV [ES:DI], AL) to a video address while all four plane masks are active:

  1. The single byte value in the CPU register is placed onto the system data bus.
  2. The VGA memory controller intercepts the write cycle.
  3. Instead of routing the data to a single memory plane, the controller broadcasts that identical 8-bit value into Plane 0, Plane 1, Plane 2, and Plane 3 simultaneously in that single cycle.
  4. Because the display hardware reads from each plane sequentially to draw the scanline, the written byte fills four adjacent horizontal pixels on the monitor with the specified color.

Performance Advantage

This hardware parallelization effectively quadruples write bandwidth during bulk operations like solid-color clearing, horizontal line rasterization, and block fills. By turning a serial four-byte operation into a single-byte hardware broadcast, game engines and graphics libraries in the DOS era bypassed the severe throughput limitations of the 8-bit and 16-bit ISA buses.
