How to Move the VGA Hardware Cursor via Ports

This article explains how to reposition the Video Graphics Array (VGA) hardware cursor in standard text mode through direct I/O port manipulation. By interacting directly with the VGA CRT Controller (CRTC) registers, low-level software such as bootloaders and operating system kernels can update the cursor coordinates on screen without relying on BIOS interrupts.

Understanding the VGA Cursor Registers

In standard VGA text mode (such as the default 80x25 display mode), the hardware cursor position is defined as a linear memory offset from the start of video memory. The position is a 16-bit integer calculated using the column (\(X\)) and row (\(Y\)) coordinates:

\[\text{Position} = (Y \times \text{Width}) + X\]

For an 80-column screen, moving the cursor to row 10, column 5 results in an offset of \((10 \times 80) + 5 = 805\).

The VGA hardware splits this 16-bit value across two 8-bit registers managed by the CRT Controller:

  • Register 0x0E: Cursor Location High Register (most significant byte)
  • Register 0x0F: Cursor Location Low Register (least significant byte)

The CRTC I/O Ports

To communicate with these registers, software writes to two specific I/O ports:

  • Index Port (0x3D4): Selects the target internal register.
  • Data Port (0x3D5): Reads from or writes to the selected register.

(Note: On older monochrome adapters, the ports are 0x3B4 and 0x3B5, but standard color VGA systems utilize 0x3D4 and 0x3D5.)

Step-by-Step Procedure

  1. Calculate the 16-bit linear location offset.
  2. Send the index value 0x0F to port 0x3D4 to select the Cursor Location Low Register.
  3. Send the lower 8 bits of the offset to port 0x3D5.
  4. Send the index value 0x0E to port 0x3D4 to select the Cursor Location High Register.
  5. Send the upper 8 bits of the offset to port 0x3D5.

Implementation Example in C

Assuming standard x86 outb port-writing primitives:

void outb(unsigned short port, unsigned char val) {
    __asm__ volatile ("outb %0, %1" : : "a"(val), "Nd"(port));
}

void set_cursor_position(int x, int y) {
    unsigned short position = (y * 80) + x;

    // Send the low byte
    outb(0x3D4, 0x0F);
    outb(0x3D5, (unsigned char)(position & 0xFF));

    // Send the high byte
    outb(0x3D4, 0x0E);
    outb(0x3D5, (unsigned char)((position >> 8) & 0xFF));
}

Implementation Example in x86 Assembly

; Arguments: BL = X (column), BH = Y (row)
set_cursor:
    ; Calculate linear offset: AX = (BH * 80) + BL
    movzx ax, bh
    mov cx, 80
    mul cx
    movzx bx, bl
    add ax, bx
    mov bx, ax          ; Store offset in BX

    ; Send Low Byte
    mov dx, 0x3D4
    mov al, 0x0F
    out dx, al

    mov dx, 0x3D5
    mov al, bl
    out dx, al

    ; Send High Byte
    mov dx, 0x3D4
    mov al, 0x0E
    out dx, al

    mov dx, 0x3D5
    mov al, bh
    out dx, al

    ret

Executing these instructions immediately updates the visible cursor on screen without requiring a video refresh or screen redraw.
