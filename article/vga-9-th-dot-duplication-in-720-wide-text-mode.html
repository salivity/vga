VGA 9th Dot Duplication in 720-Wide Text Mode

This article explores the 9th-dot character duplication mechanism used in 720-wide Video Graphics Array (VGA) text modes, an ingenious hardware feature designed to render legacy 8-pixel-wide font data within a 9-pixel-wide grid. You will learn why this mechanism was necessary, how the VGA hardware differentiates between standard text and pseudographics, and the specific registers and character ranges that govern the replication of the eighth pixel to ensure unbroken line-drawing borders.

The 720-Pixel Architecture and the 8-Bit Font Problem

The standard monochrome and color text modes introduced with the IBM VGA standard—most notably Mode 03h running at a 70 Hz refresh rate—produce a resolution of 720×400 pixels across 80 columns and 25 rows. Dividing 720 horizontal pixels by 80 text columns yields a character cell width of 9 pixels.

However, IBM's font data stored in the VGA BIOS ROM (and in font buffers within video memory) is stored in standard byte-aligned formats: 8 pixels wide by 16 scanlines tall. Each byte in the font table represents one row of 8 horizontal pixels, where a set bit (1) denotes a foreground pixel and a cleared bit (0) denotes a background pixel. To display an 8-pixel glyph within a 9-pixel-wide cell, the video hardware must dynamically generate a 9th pixel for every scanline of every character displayed.

The Default Behavior: The 9th Dot as Spacing

In normal operation, the VGA Sequencer hardware is set to 9-dot character mode via the Clocking Mode Register (Sequencer Index 01h, Bit 0 set to 0). For the vast majority of alphanumeric characters, the sequencer inserts a 9th dot that is forced to the background color.

This automatic padding provides a built-in 1-pixel horizontal space between adjacent characters, preventing letters from touching and maintaining legibility without requiring font designers to waste one of their 8 available pixel columns on blank space.

The Line-Drawing Exception: Codes C0h Through DFh

While inserting a blank 9th pixel works well for text, it causes a noticeable visual defect with box-drawing and pseudographic characters. In IBM Code Page 437, horizontal lines and window borders must span seamlessly from one character cell to the next. If the 9th pixel were always rendered as background space, all horizontal borders would suffer from an ugly 1-pixel gap at every character boundary.

To resolve this, the VGA hardware implements an automatic replication rule:

  • If a character's ASCII/extended code falls outside the range C0h through DFh (192 to 223 in decimal), the 9th dot defaults to the background color.
  • If a character's code falls within the range C0h to DFh, the hardware duplicates the state of the 8th pixel into the 9th pixel position.

If the 8th pixel of a scanline is active (foreground), the 9th pixel is also rendered as foreground. If the 8th pixel is inactive (background), the 9th pixel remains background. Because the box-drawing characters in Code Page 437 are intentionally designed so that horizontal lines extend through the 8th column, this hardware replication creates continuous, uninterrupted lines across the display.

Hardware Control: The Attribute Controller

This duplication mechanism is not permanently hardwired; it can be toggled by software via the VGA Attribute Controller.

The feature is controlled by Bit 2 (Enable Line Graphics Character Codes) of the Attribute Mode Control Register (Index 10h within the Attribute Controller):

  • Bit 2 = 1 (Default in standard text modes): Enables the automatic duplication logic for character codes C0h through DFh.
  • Bit 2 = 0: Disables the duplication logic. All characters, including C0h through DFh, have their 9th pixel set unconditionally to the background color.

Disabling Bit 2 is common when an application or operating system loads a custom 9-dot font or a non-standard character set where the C0h to DFh range contains alphanumeric characters rather than line-drawing glyphs, ensuring that letters in that range do not suffer from distorted, widened right edges.
