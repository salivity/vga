15-Bit vs 16-Bit vs 24-Bit Color in Extended VGA

Extended Video Graphics Array (often referred to as Super VGA or EVGA) dramatically expanded the capabilities of the original IBM VGA standard by supporting higher display resolutions and greater color depths. The fundamental difference between 15-bit, 16-bit, and 24-bit color representations lies in how many binary bits are allocated to define the color of each individual pixel. This bit allocation dictates the total number of simultaneously displayable colors, the distribution of color channels (Red, Green, and Blue), the degree of color banding, and the amount of video memory (VRAM) and bandwidth required by the display adapter.

15-Bit Color (32,768 Colors)

In a 15-bit color setup, often categorized alongside 16-bit as "High Color," each pixel uses two bytes (16 bits) of video memory, but only 15 of those bits define the color values:

  • Channel Distribution: The color channels are split evenly into a 5-5-5 format: 5 bits for Red, 5 bits for Green, and 5 bits for Blue.
  • Unused Bit: Because hardware handles data in byte-sized chunks, the 16th bit is either left unused, ignored, or occasionally reserved for overlay/transparency flags.
  • Color Depth: Each color channel can represent \(2^5 = 32\) intensity levels, yielding a total of \(32 \times 32 \times 32 = 32,768\) possible colors.
  • Performance Impact: 15-bit provided a noticeable leap over 8-bit indexed color without requiring complex palette lookups, but slight color banding remains visible in subtle gradients.

16-Bit Color (65,536 Colors)

Like 15-bit color, 16-bit color consumes exactly two bytes per pixel, but it fully utilizes all 16 bits to maximize visual fidelity:

  • Channel Distribution: It uses a 5-6-5 format: 5 bits for Red, 6 bits for Green, and 5 bits for Blue.
  • The Green Channel Advantage: Human vision is naturally more sensitive to green wavelengths and variations in brightness. Allocating the extra bit to green provides twice as many gradations (\(2^6 = 64\) levels) for green compared to red and blue (\(2^5 = 32\) levels each).
  • Color Depth: The total number of available colors doubles to \(32 \times 64 \times 32 = 65,536\) colors.
  • Performance Impact: 16-bit quickly superseded 15-bit as the industry standard for High Color because it extracted better perceptual quality out of the same 2-byte-per-pixel memory footprint.

24-Bit Color (16,777,216 Colors)

Known universally as "True Color," 24-bit color dedicates a full byte to each additive primary color channel:

  • Channel Distribution: It uses an 8-8-8 format: 8 bits for Red, 8 bits for Green, and 8 bits for Blue.
  • Color Depth: Each channel has \(2^8 = 256\) intensity levels, producing \(256 \times 256 \times 256 = 16,777,216\) distinct colors.
  • Visual Fidelity: The 16.7 million variations exceed the human eye's threshold for distinguishing color transitions, virtually eliminating noticeable banding in photographic imagery and complex shading.
  • Memory and Alignment: 24-bit color requires 3 bytes per pixel. Because unaligned 3-byte structures can create addressing inefficiencies on 32-bit computing architectures, extended graphics hardware often expanded this internally to 32 bits per pixel (8-8-8-8, where the remaining 8 bits are reserved or used for alpha channels), significantly increasing VRAM and bus bandwidth demands.

Summary Comparison

  • 15-Bit (5-5-5): Uses 2 bytes per pixel, renders 32,768 colors, leaves 1 bit unused.
  • 16-Bit (5-6-5): Uses 2 bytes per pixel, renders 65,536 colors, optimizes the extra bit for human green-light sensitivity.
  • 24-Bit (8-8-8): Uses 3 (or 4 aligned) bytes per pixel, renders 16,777,216 colors, delivering photorealistic True Color at the cost of higher memory bandwidth.
