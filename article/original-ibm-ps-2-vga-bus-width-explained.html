Original IBM PS/2 VGA Bus Width Explained

When IBM introduced the Video Graphics Array (VGA) standard alongside the Personal System/2 (PS/2) computer line in 1987, it fundamentally changed PC display standards. This article examines the hardware architecture of the original integrated VGA implementation on the IBM PS/2 planar (motherboard), focusing specifically on its host bus width, internal memory bus configuration, and the performance implications of those architectural choices.

The Host Bus Width: An 8-Bit Interface

The original integrated VGA chip on the IBM PS/2 motherboard utilized an 8-bit bus width to communicate with the host system.

Even though the high-end IBM PS/2 models featured advanced 16-bit or 32-bit Micro Channel Architecture (MCA) system buses, the onboard VGA subsystem was wired to the processor via an 8-bit data path. The decision was rooted in backward compatibility with earlier display standards like the Color Graphics Adapter (CGA) and Enhanced Graphics Adapter (EGA), as well as cost and complexity constraints during the design phase of the original PS/2 planar.

Because the host connection was restricted to 8 bits, the CPU had to transfer graphical data in single-byte chunks. This made host-to-video-memory transfers a notable bottleneck in early PS/2 machines, especially when updating full-screen graphics in real time.

Internal Video Memory Bus Width: 32 Bits

While the host-facing interface was limited to 8 bits, the internal architecture between the VGA controller and its video RAM (VRAM) operated differently:

  • Video Memory Configuration: The standard PS/2 VGA system included 256 KB of dynamic RAM.
  • Plane Organization: This memory was divided into four separate 64 KB memory banks, known as "planes."
  • Internal Data Path: The VGA controller accessed all four planes simultaneously, creating an effective 32-bit internal memory bus width (4 planes × 8 bits).

This 32-bit internal architecture allowed the display circuitry to serialize and output pixels rapidly enough to support 640×480 resolution at 16 colors and 320×200 resolution at 256 colors at a 60 Hz or 70 Hz refresh rate, without starving the digital-to-analog converter (DAC) of bandwidth.

Legacy and Evolution

The 8-bit host limitation of the integrated PS/2 VGA directly influenced the broader graphics market. Third-party add-in card manufacturers quickly recognized that IBM’s 8-bit bottleneck restricted graphics performance. By the late 1980s and early 1990s, clone manufacturers introduced 16-bit ISA VGA cards, followed by 32-bit VESA Local Bus (VLB) and PCI graphics adapters, which finally matched the host bus width to the graphics processor's full capabilities.
