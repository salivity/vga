The Hercules Graphics Card and VGA Compatibility

The Hercules Graphics Card (HGC) was a pioneering third-party video controller that defined high-resolution monochrome graphics for early personal computers, bridging the gap between business text processing and bitmapped display capabilities. While IBM later introduced the Video Graphics Array (VGA) as a new universal standard with native backward compatibility for IBM's own display adapters, compatibility with the Hercules standard was sustained through architectural memory mapping, register-level hardware emulation by third-party chipmakers, and software translation utilities.

What Was the Hercules Graphics Card?

Introduced in 1982 by Hercules Computer Technology, the Hercules Graphics Card was developed by Van Suwannukul to enable him to write his doctoral thesis in the Thai alphabet on an IBM PC. At the time, IBM PC users had to choose between two mutually exclusive display standards: the Monochrome Display Adapter (MDA), which provided crisp, readable 80-column text at 720x350 resolution but lacked graphics capability, and the Color Graphics Adapter (CGA), which supported bitmapped graphics but suffered from low resolution (up to 640x200 monochrome or 320x200 in four colors) and poor text clarity.

The Hercules card solved this dilemma by combining full MDA text compatibility with an addressable bitmapped monochrome graphics mode of 720x348 pixels at a 50 Hz refresh rate. It achieved this by equipping the card with 64 KB of video RAM—four times the memory of MDA—divided into two selectable 32 KB display pages. This resolution allowed users to display sharp, detailed diagrams, technical charts, and complex characters on standard, inexpensive monochrome TTL monitors.

Because of its superior resolution and text quality, the HGC became an overwhelming commercial success and a de facto industry standard. Major business software, including Lotus 1-2-3, AutoCAD, and Microsoft Flight Simulator, quickly integrated dedicated display drivers specifically designed for Hercules graphics.

How VGA Maintained Compatibility with Hercules

In 1987, IBM introduced the Video Graphics Array (VGA) alongside the PS/2 series. VGA introduced color graphics up to 640x480 and enhanced text modes at 720x400. While IBM natively integrated hardware-level compatibility for its own legacy standards (MDA and CGA), it did not formally license or build native 720x348 Hercules graphics modes into the official IBM VGA specification. Despite this, compatibility with Hercules software was maintained across several fronts:

1. Monochrome Memory Mapping and Dual-Display Coexistence

IBM PC architecture designated the memory address range B0000h–B7FFFh for monochrome display buffers and B8000h–BFFFFh for color buffers. VGA preserved this hardware memory division. By default, Hercules used B0000h–B7FFFh for its primary graphics page. Because VGA could be configured to operate strictly in the color memory space, users and developers could install both a VGA card and an original Hercules card simultaneously in the same system without hardware address conflicts, allowing simultaneous dual-monitor workflows common in debugging and CAD.

2. Third-Party Chipset Emulation

While IBM’s official VGA implementation omitted the proprietary 720x348 graphics mode, third-party graphics silicon vendors—such as Tseng Labs (ET3000/ET4000), Paradise Systems, ATI, and Oak Technology—dominated the clone PC market. These manufacturers incorporated register-level Hercules emulation modes directly into their Super VGA (SVGA) chipsets. When Hercules software accessed standard Hercules registers or attempted to switch display pages, the SVGA hardware recognized the commands, adjusted the timing signals to match standard CRT scanning frequencies, and displayed the 720x348 output seamlessly within a 640x480 or 720x400 frame.

3. Software Emulation and Driver Redirection

For systems running standard IBM VGA hardware without proprietary chipset-level Hercules trapping, compatibility was handled at the software layer:

  • BIOS and Software Updates: Popular application developers updated their software suites to include native VGA drivers, migrating user workflows directly to VGA's native 640x480 monochrome or 16-color modes.
  • TSR Emulators: Memory-resident programs (such as SIMCGA, VGAHERC, and later utilities like HGCBIOS) intercepted direct writes to Hercules I/O ports and redirected frame data into VGA-supported graphic modes, automatically scaling or centering the 720x348 canvas onto the VGA display.

Through these combined hardware adaptations and software bridges, users were able to transition from the Hercules standard to the VGA standard without sacrificing access to their existing software library.
