Open-Source FPGA Authentic VGA Cores

This article examines prominent open-source FPGA retro-computing projects that incorporate authentic, register-level Video Graphics Array (VGA) core implementations. Replicating the original IBM VGA standard requires precise hardware recreation of subsystems like the Cathode Ray Tube Controller (CRTC), Sequencer, Graphics Controller, Attribute Controller, and color digital-to-analog converter (RAMDAC). The following hardware description language (HDL) projects provide genuine, open-source implementations of this iconic video standard for vintage PC emulation and hardware reproduction.

ao486 (MiSTer FPGA Project)

The ao486 project, central to the MiSTer FPGA retro-computing platform, contains one of the most mature and authentic open-source VGA cores available. Written in Verilog, the ao486 video subsystem replicates original IBM VGA behavior at the register level rather than merely intercepting high-level BIOS calls. It fully implements standard VGA video memory architecture, including the four-plane organization (Planes 0–3), read/write latch registers, and complex planar manipulation modes such as "Mode X" (unchained 320x240 graphics). The core also faithfully handles hardware panning, splitting screens via the line compare register, and reproduces the standard 18-bit color palette via an integrated RAMDAC model.

Zet x86

Zet is an open-source clone of an IBM PC/AT architecture implemented in Verilog. Its integrated VGA core is designed to be fully compatible with bare-metal x86 software and MS-DOS utilities. The Zet VGA core models the exact modular layout of the original IBM hardware:

  • Sequencer: Controls memory plane access, character clocking, and screen blanking.
  • CRTC (Cathode Ray Tube Controller): Handles horizontal/vertical sync timings and display enable signals.
  • Graphics Controller: Interfaces the CPU to display memory, managing bit masks, data rotation, and logical operations.
  • Attribute Controller: Translates pixel values through palette registers to output color indices.

Because it adheres strictly to legacy hardware specifications, it runs software utilizing low-level register manipulation, custom text-mode fonts, and raster effects without modification.

Next186 SoC

Designed by Nicolae Dumitrache, the Next186 core is an optimized 80186-compatible system-on-chip that features a complete custom VGA controller written in Verilog. Unlike basic frame-buffer implementations, the Next186 VGA controller accurately replicates the dual-port nature of IBM video RAM, standard 80x25 text modes with blinking and custom character generators, standard Mode 13h (320x200 256-color), and high-resolution 640x480 16-color planar modes. Its timing generator accurately reproduces standard 25.175 MHz and 28.322 MHz pixel clocks, allowing real-time retro games to function with authentic horizontal and vertical blanking interrupts.

FPGAPC

FPGAPC is an open-source cycle-accurate PC clone project targeting modern development boards. Its video subsystem provides an authentic IBM VGA reproduction written in VHDL. The core focuses on strict timing accuracy and bus behavior, making it an essential reference for developers needing accurate emulation of hardware wait-states during display-memory access, overscan borders, and palette-cycling behavior critical to early 1990s demoscene productions.
