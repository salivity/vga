VGA Character Clock vs Pixel Clock in 8-Dot Mode

In standard 8-dot Video Graphics Array (VGA) modes, the relationship between the character clock and the pixel clock is defined by a fixed 1:8 frequency ratio. The pixel clock—also referred to as the dot clock—drives the emission of individual pixels on the screen, while the character clock governs the internal timing and memory access cycles of the VGA hardware. Because each character cell in this mode is eight pixels wide, the pixel clock runs exactly eight times faster than the character clock.

The Frequency Relationship

The mathematical formula governing these two signals in an 8-dot configuration is:

\[\text{Pixel Clock Frequency} = \text{Character Clock Frequency} \times 8\]

Conversely:

\[\text{Character Clock Frequency} = \frac{\text{Pixel Clock Frequency}}{8}\]

For example, in standard VGA 640×480 graphics mode at 60 Hz, the master pixel clock runs at approximately 25.175 MHz. Because standard graphics modes treat pixels in 8-dot units, the internal character clock operates at approximately 3.147 MHz (25.175 MHz ÷ 8).

Hardware Implementation and Sequencing

The division between these two clocks occurs inside the VGA Sequencer. The Sequencer accepts the raw pixel clock from the master oscillator and routes it through an internal clock divider controlled by the Clocking Mode Register (Index 0x01, Bit 0). Setting this bit to 1 sets an 8-dot character clock; clearing it to 0 sets a 9-dot character clock commonly used in monochrome emulation and standard 720×400 text modes.

The two clocks serve distinct functional roles within the graphics pipeline:

  • Pixel Clock: Powers the output shift registers and the digital-to-analog converter (DAC). On every rising edge of the pixel clock, a single pixel’s color information is shifted out and displayed on the CRT or flat-panel monitor.
  • Character Clock: Drives the internal Cathode Ray Tube Controller (CRTC) and video memory address counters. On every character clock pulse, the VGA sequencer fetches a byte (or set of plane bytes) from Video RAM (VRAM) and loads it into the parallel-to-serial shift registers.

Impact on Video Timing and Resolution

The CRT Controller tracks scanline progress, blanking intervals, and synchronization pulses using character clock ticks rather than individual pixel clock cycles. In an 8-dot mode, horizontal timing registers (such as Horizontal Total, Horizontal Display End, and Horizontal Sync Start) count in units of 8 pixels.

A standard 640-pixel horizontal display line requires 80 character clocks (\(80 \times 8 = 640\)). When 8 bits of plane data are fetched into the shift registers during one character clock cycle, the shift registers serialize those 8 bits across the next 8 pixel clock cycles, producing a seamless, continuous image without memory bus bottlenecks.
