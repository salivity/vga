VGA Map Mask Register in Memory Writes

The Video Graphics Array (VGA) Map Mask register plays a critical role in controlling how data is written to the display adapter’s video memory in planar graphics modes. Because VGA hardware arranges its video RAM into four parallel memory planes sharing the same CPU address space, standard memory writes require a selection mechanism to determine where data is applied. The Map Mask register provides this mechanism by selectively enabling or masking writes to any combination of these four memory planes during CPU write operations.

VGA Memory Architecture and the Planar Model

In standard VGA planar modes, such as Mode 12h (640x480, 16 colors), the display memory is divided into four 64 KB memory planes: Plane 0, Plane 1, Plane 2, and Plane 3. When the CPU accesses an address in the video memory segment (typically 0xA0000), that single address maps simultaneously to the corresponding byte in all four planes. Without a filtering mechanism, a CPU write would either overwrite all four planes identically or require multiple complex bus cycles. The Map Mask register solves this limitation.

Function of the Map Mask Register

The Map Mask register is part of the VGA Sequencer registers, accessed by setting the Sequencer Index port (0x3C4) to 0x02 and writing the desired bitmask to the Sequencer Data port (0x3C5).

Only the lower four bits of the 8-bit register are functional, with each bit corresponding directly to one of the four memory planes:

  • Bit 0: Enables or disables writes to Plane 0 (typically Blue data in 16-color modes).
  • Bit 1: Enables or disables writes to Plane 1 (typically Green data).
  • Bit 2: Enables or disables writes to Plane 2 (typically Red data).
  • Bit 3: Enables or disables writes to Plane 3 (typically Intensity data).
  • Bits 4–7: Unused and ignored by the hardware.

Setting a bit to 1 enables CPU write access to that plane. Setting a bit to 0 masks the plane, leaving its contents completely unmodified regardless of the data being written by the CPU.

Role During Memory Write Cycles

When the CPU executes a write instruction to VGA video RAM, the data byte presented on the system bus passes through the VGA Graphics Controller and Sequencer before reaching the memory chips. The Map Mask register acts as a hardware gatekeeper during this phase:

  1. Selective Color Plane Updates: If an application needs to draw graphics that only alter specific color components (for example, drawing pure red shapes), it configures the Map Mask register to enable only Plane 2 (0x04). Writes to memory will modify only the red component, leaving the green, blue, and intensity values intact.
  2. Parallel Plane Writing: If multiple bits in the register are set to 1, a single CPU byte-write writes that same byte across all selected planes simultaneously. This allows rapid bulk filling of solid colors using fewer CPU cycles.
  3. Unchained Modes (Mode X): In unchained 256-color modes (popularly known as Mode X), the four planes are arranged so that consecutive horizontal pixels reside in consecutive planes rather than consecutive address offsets. In this configuration, the Map Mask register is used to select which individual pixel (plane) at a given address is being updated, or to write four adjacent pixels at once when drawing repeating patterns or horizontal spans.
