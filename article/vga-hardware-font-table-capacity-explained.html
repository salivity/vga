VGA Hardware Font Table Capacity Explained

Standard Video Graphics Array (VGA) hardware can maintain up to eight 256-character font tables simultaneously in its dedicated font memory, while actively displaying glyphs from up to two of those tables concurrently on screen. This guide explains how VGA memory architecture allocates space for text-mode character sets, the physical constraints of plane memory, and the hardware mechanism that allows systems to render up to 512 distinct characters at the same time.

Font Memory Allocation in VGA Hardware

In text mode, standard VGA hardware does not render raw pixel buffers from system RAM. Instead, it utilizes Plane 2 of its 256 KB video memory exclusively for character generation patterns.

Plane 2 provides 64 KB of addressable storage for character definitions:

  • Glyph Dimensions: Each character slot supports a matrix up to 8 or 9 pixels wide and up to 32 scanlines high.
  • Storage per Character: Each scanline corresponds to one byte of data, requiring 32 bytes per character regardless of the actual visible font height (such as 8x8, 8x14, or 8x16).
  • Storage per Font Table: A standard 256-character font table occupies exactly 8,192 bytes (8 KB), calculated as \(256 \times 32\text{ bytes}\).

Dividing the total 64 KB capacity of Plane 2 by the 8 KB required per table establishes that standard VGA hardware can store and maintain exactly eight complete font tables (often referred to as character maps or blocks 0 through 7) without needing to reload data across the system bus.

Active Fonts on Screen

While eight tables reside in video memory simultaneously, standard character cell attributes normally allocate only 8 bits for the character code, limiting direct addressing to 256 characters. However, VGA hardware features a dedicated register capable of expanding this limitation:

  • Character Map Select Register: Located at Sequencer register 0x03, this register allows the programmer to specify two active font tables—Font Table A and Font Table B—from the eight stored in Plane 2.
  • Dual-Font Selection: When two distinct maps are selected, bit 3 of the character attribute byte (traditionally used for foreground intensity) is repurposed as a font switch bit.
  • 512-Character Mode: If bit 3 is cleared (0), the hardware fetches the glyph from Font Table A; if set (1), it fetches the glyph from Font Table B.

This mechanism enables VGA hardware to actively display two simultaneous font tables (512 unique characters) across the screen at any single moment, chosen dynamically from the eight maintained in memory.
