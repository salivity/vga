Character Clock vs Pixel Clock in 9-Dot VGA Text

In standard 9-dot Video Graphics Array (VGA) text modes, the character clock and pixel clock share a direct, fixed frequency relationship determined by the width of the character cell. This article explains the architectural connection between these two timing signals, how the VGA sequencer derives the character clock, and the mathematical ratio that defines their operation during text rendering.

The Role of the Pixel Clock

The pixel clock (often referred to as the dot clock) is the highest-frequency timing signal in the VGA hardware pipeline. It dictates the rate at which individual pixels are pushed out to the video digital-to-analog converter (DAC) and drawn onto the display.

In standard 80x25 text mode with a 9-dot wide character matrix (such as Mode 07h or standard 720x400 @ 70 Hz text mode), the pixel clock typically runs at 28.322 MHz. Every rising edge of this clock represents the duration of a single horizontal pixel on the screen.

The Role of the Character Clock

The character clock drives the internal display-generation machinery, specifically the Sequencer and the Cathode Ray Tube Controller (CRTC). Instead of processing data pixel by pixel, the CRTC increments horizontal counters, generates horizontal sync pulses, and fetches character data in whole-character increments.

During each cycle of the character clock, the VGA hardware:

  1. Fetches a character byte (ASCII code) and an attribute byte (color data) from video RAM.
  2. Reads the appropriate font scanline bitmap from the character generator.
  3. Loads the 8- or 9-bit pattern into a parallel-to-serial shift register to be serialized at the pixel clock rate.

The 9-to-1 Mathematical Relationship

In standard 9-dot text mode, a single character box spans 9 horizontal pixels. Consequently, one character clock cycle corresponds to exactly nine pixel clock cycles.

  • Character Clock Frequency = Pixel Clock Frequency ÷ 9
  • Pixel Clock Frequency = Character Clock Frequency × 9

Using the standard 28.322 MHz crystal frequency:

  • Pixel Clock: 28.322 MHz
  • Character Clock: 28.322 MHz ÷ 9 ≈ 3.1469 MHz

This means that for every tick of the internal character clock, the shift register outputs nine individual dots to the display stream using the pixel clock.

Hardware Configuration in the Sequencer

This relationship is directly configured in the VGA Sequencer registers:

  • Clocking Mode Register (Index 01h, Bit 0): This bit controls whether the character clock divider is set to 8 or 9 dot clocks. When cleared to 0, the sequencer operates in 9-dot mode, dividing the master dot clock by 9. When set to 1, it operates in 8-dot mode, dividing the dot clock by 8.
  • Font Expansion: Because typical VGA font bitmaps are only 8 pixels wide, the hardware handles the 9th dot automatically. Depending on the character code and attribute settings, the VGA either inserts a blank background pixel for the 9th dot (to provide spacing between characters) or duplicates the 8th pixel (used for continuous line-drawing characters in the ASCII range C0h through DFh).

Regardless of whether the 9th dot is blanked or duplicated, the fundamental timing ratio remains strictly 9:1.
