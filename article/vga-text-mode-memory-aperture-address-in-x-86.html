VGA Text Mode Memory Aperture Address in x86

This article details the exact memory aperture addresses assigned to standard Video Graphics Array (VGA) text mode within the classic x86 system architecture. It outlines the specific physical memory ranges mapped in the Upper Memory Area, the differences between color and monochrome configurations, and how software directly manipulated video memory to display text on screen.

In the classic x86 real-mode memory map, the standard color VGA text mode (specifically BIOS Mode 03h, the standard 80x25 character display) is mapped to physical address 0xB8000. In real-mode segmented addressing notation, this corresponds to segment 0xB800:0000. The aperture spans a 32 KB block from 0xB8000 to 0xBFFFF.

For backward compatibility with the Monochrome Display Adapter (MDA), standard VGA also supported a monochrome text mode (BIOS Mode 07h). When operating in this mode, the hardware remapped the video memory aperture to physical address 0xB0000 (segment 0xB000:0000), covering the range from 0xB0000 to 0xB7FFF.

These ranges formed part of the Upper Memory Area (UMA), a 384 KB region spanning 0xA0000 to 0xFFFFF reserved for hardware devices and system BIOS. Within this layout, VGA graphics modes occupied 0xA0000 to 0xAFFFF, leaving the 0xB0000 to 0xBFFFF window exclusively for text framebuffers.

In standard 80x25 color text mode, each on-screen character cell consumed two consecutive bytes in memory:

  1. Character Code (Offset +0): An 8-bit ASCII or extended ASCII code representing the character glyph stored in the VGA font ROM/RAM.
  2. Attribute Byte (Offset +1): An 8-bit field defining the foreground color (bits 0–3), background color (bits 4–6), and an optional blinking or high-intensity background flag (bit 7).

Because an 80x25 text screen requires 2,000 character cells, a single display page uses exactly 4,000 bytes. The 32 KB aperture at 0xB8000 allowed the VGA card to store up to eight distinct display pages simultaneously, enabling applications to perform instant page-flipping by adjusting the start address registers on the VGA controller without needing to retransmit screen data.
