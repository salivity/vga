Doom DOS VGA Mode 13h Screen Refresh Rate

When running natively in MS-DOS using Video Graphics Array (VGA) Mode 13h—or more specifically, its unchained planar variant often called Mode Y—Doom outputs a video signal with a screen refresh rate of approximately 70 Hz (70.087 Hz). However, the internal game engine is locked to render at exactly 35 frames per second (FPS), syncing its updates to every other vertical refresh cycle of the monitor.

The VGA Standard and 70 Hz Video Output

Standard VGA hardware operating in 320x200 resolution modes (including Mode 13h and Mode Y) generates a cathode-ray tube (CRT) timing standard characterized by:

  • Horizontal Frequency: ~31.469 kHz
  • Vertical Refresh Rate: ~70.087 Hz
  • Pixel Clock: 25.175 MHz
  • Total Vertical Lines: 449 lines (with 400 active scanlines, achieved by vertically double-scanning the 200 source lines)

Because native DOS Doom communicates directly with the VGA hardware without an operating system compositor or abstraction layer, the analog video signal sent to the CRT monitor is permanently locked to this standard ~70 Hz refresh rate.

The 35 FPS Engine Cap

While the physical display refreshes 70 times per second, the game loop does not generate 70 distinct frames per second. id Software engineered Doom to run its simulation logic and rendering pipeline at 35 "tics" per second.

John Carmack chose this limit for two primary reasons:

  1. Hardware Performance: In 1993, mainstream 486 and 386 processors could rarely sustain 70 frames per second when rendering Doom's complex pseudo-3D environments.
  2. Hardware Synchronization: Thirty-five is exactly half of the VGA standard's 70 Hz refresh rate. By polling the VGA status register and waiting for the Vertical Blanking Interval (VBLANK), the game could swap page buffers every second vertical retrace. This eliminated visible screen tearing and provided smooth frame pacing without exceeding system capabilities.

Mode 13h vs. Mode Y

Standard Mode 13h is a linear frame buffer that supports only one visible page in video memory, making tear-free double buffering difficult. Doom uses a customized, unchained variation of Mode 13h (Mode Y). This mode reconfigures the VGA controller's memory planes to allow multiple 320x200 pages inside the 256 KB VGA memory. This allowed the engine to draw the next frame off-screen and cleanly flip the active display pointer during the vertical blank period, executing at 35 FPS within a 70 Hz signal.
