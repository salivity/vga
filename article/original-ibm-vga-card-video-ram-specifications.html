Original IBM VGA Card Video RAM Specifications

This article examines the hardware specifications of the original IBM Video Graphics Array (VGA), focusing specifically on the memory capacity included with its first release. It details the exact amount of video RAM integrated into the hardware, how this memory architecture supported its most famous display modes, and why this standard became a milestone in personal computing graphics history.

The original IBM Video Graphics Array adapter, introduced in 1987 alongside the IBM Personal System/2 (PS/2) line of computers, was equipped with exactly 256 kilobytes (KB) of video RAM. Whether integrated directly into the motherboard of PS/2 systems or delivered via the standalone 8-bit ISA expansion card for IBM PC/XT/AT compatibles, 256 KB was the fixed, non-expandable standard for the original hardware implementation.

This 256 KB memory footprint was divided into four 64 KB memory planes. The arrangement enabled the card to support several distinct display configurations:

  • 320x200 at 256 colors (Mode 13h): This iconic mode allocated one byte per pixel, requiring 64,000 bytes (roughly 62.5 KB) of video memory. It drew colors from an 18-bit palette containing 262,144 possible shades, making it a favorite for MS-DOS gaming.
  • 640x480 at 16 colors: In this mode, each pixel required 4 bits of data. The image occupied 153,600 bytes (150 KB) of memory across the four bit planes, providing crisp resolution for graphical user interfaces and early desktop publishing.
  • 720x400 text mode: Designed for high-clarity terminal emulation, this mode used the available memory to store character codes, attribute bytes, and full character font definitions.

By shipping with a full 256 KB of VRAM as a baseline, IBM effectively doubled the 128 KB standard of the preceding Enhanced Graphics Adapter (EGA). This provided developers with guaranteed hardware specifications, eliminating the need to support multiple memory configurations and solidifying VGA as the universal PC display standard for years to come.
