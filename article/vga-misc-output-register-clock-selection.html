VGA Misc Output Register Clock Selection

The Video Graphics Array (VGA) Miscellaneous Output Register serves as a fundamental hardware control register responsible for configuring core board-level settings, most notably the selection of the master dot clock frequency. By manipulating dedicated clock select bits within this register, the graphics subsystem determines the pixel generation rate, directly governing video display modes, horizontal resolution, and monitor refresh timings.

In the IBM VGA standard and compatible hardware, the Miscellaneous Output Register is accessed at I/O port address 0x3C2 for write operations and 0x3CC for read operations. Bits 2 and 3 of this 8-bit register are collectively designated as the Clock Select bits. These two bits drive an internal multiplexer that routes one of several available hardware oscillator frequencies to the rest of the VGA graphics pipeline.

The Clock Select bit combinations operate as follows:

  • Value 00b (Bit 3 = 0, Bit 2 = 0): Selects the standard 25.175 MHz dot clock. This frequency is primarily used for standard 640-pixel horizontal graphics modes, including the iconic 640x480 graphics mode at a 60 Hz vertical refresh rate.
  • Value 01b (Bit 3 = 0, Bit 2 = 1): Selects the 28.322 MHz dot clock. This frequency provides the higher timing rate required for 720-pixel horizontal modes, most commonly utilized by standard 80-column alphanumeric text modes (such as 720x400 at 70 Hz with 9-dot wide character matrices).
  • Value 10b (Bit 3 = 1, Bit 2 = 0): Historically configured to select an external clock source routed through the VGA feature connector. On modern or Super VGA (SVGA) chipsets, this setting was frequently repurposed to access an auxiliary onboard oscillator or programmable clock synthesizer.
  • Value 11b (Bit 3 = 1, Bit 2 = 1): Reserved on the original IBM VGA hardware, but widely implemented by subsequent SVGA manufacturers to select additional clock synthesizer outputs for higher resolution modes (such as 800x600, 1024x768, and beyond).

The dot clock chosen via the Miscellaneous Output Register establishes the fundamental timebase for the entire video generation system. Once the clock signal is chosen, it is delivered to the VGA Sequencer. The Sequencer's Clocking Mode Register can divide this master clock down (such as halving the clock rate for 320-pixel modes like Mode 13h) or alter the character clock between 8 and 9 dots per character.

Proper configuration of the Miscellaneous Output Register is critical during mode initialization. Because the CRT Controller (CRTC) derives horizontal and vertical sync timings from the chosen pixel clock, programming incorrect values into Bits 2 and 3 leads to out-of-spec sync signals, distorted display output, or an inability for monitors to lock onto the video signal.
