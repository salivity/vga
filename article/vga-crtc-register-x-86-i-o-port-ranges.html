VGA CRTC Register x86 I/O Port Ranges

In the x86 architecture, the Video Graphics Array (VGA) Cathode Ray Tube Controller (CRTC) registers are mapped to specific port address ranges within the processor's I/O space. This article details the primary port ranges used to communicate with the CRTC, explaining how the hardware differentiates between color and monochrome modes and how the index-data register pair operates.

Standard CRTC Port Address Ranges

The VGA CRTC registers do not occupy a continuous block for every individual internal register. Instead, access is mediated through a 2-byte index/data port scheme. Depending on the emulation mode, the reserved port ranges are:

  • Color Mode: 0x3D4 to 0x3D5
  • Monochrome Mode: 0x3B4 to 0x3B5

Color Emulation Mode (0x3D4 – 0x3D5)

Color mode is the default and most widely used configuration in modern x86 environments.

  • Port 0x3D4 (Address/Index Register): Used to specify the index of the internal CRTC register (ranging from 0x00 to 0x18 in standard VGA, with extended registers in SVGA implementations) that software intends to access.
  • Port 0x3D5 (Data Register): Used to read from or write to the specific CRTC register selected via port 0x3D4.

Monochrome Emulation Mode (0x3B4 – 0x3B5)

To maintain backwards compatibility with legacy MDA (Monochrome Display Adapter) hardware, VGA supports remapping the CRTC ports to the monochrome range.

  • Port 0x3B4 (Address/Index Register): Serves the same indexing role as 0x3D4, but within the legacy monochrome space.
  • Port 0x3B5 (Data Register): Serves the same read/write role as 0x3D5 for monochrome configurations.

Mode Switching via the Miscellaneous Output Register

The selection between the 0x3B4–0x3B5 and 0x3D4–0x3D5 port ranges is dynamically controlled by bit 0 of the VGA Miscellaneous Output Register:

  • Write Port: 0x3C2
  • Read Port: 0x3CC

When bit 0 of this register is cleared (0), the CRTC responds to monochrome I/O addresses (0x3B4 and 0x3B5). When bit 0 is set to 1, the CRTC responds to color I/O addresses (0x3D4 and 0x3D5).
