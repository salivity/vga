How VGA Emulates CGA Modes Using BIOS Interrupts

This article explains how the Video Graphics Array (VGA) maintains backward compatibility with the Color Graphics Adapter (CGA) through BIOS interrupts. When legacy software requests a CGA display mode, the VGA BIOS intervenes via Interrupt 10h (INT 10h) to configure the VGA hardware. It accomplishes this compatibility by redirecting video memory addresses, reprogramming the VGA controller registers, doubling scanlines to match modern refresh rates, and translating fixed CGA colors into the programmable VGA palette.

The Role of BIOS Interrupt 10h

Legacy DOS programs do not access display hardware drivers through an operating system abstraction layer; instead, they interact with the hardware directly or issue software interrupts to the system BIOS. The primary video service is INT 10h.

To initialize a display mode, a program places the value 00h (Set Video Mode) into register AH and the desired mode number into register AL, then calls INT 10h. The original CGA modes include:

  • Mode 04h: 320x200 graphics, 4 colors
  • Mode 05h: 320x200 graphics, 4 colors (alternate/monochrome palette)
  • Mode 06h: 640x200 graphics, 2 colors (monochrome)

When a system with a VGA adapter receives this call, the VGA BIOS intercepts the interrupt instead of original CGA firmware, reinterpreting the mode request and translating it into register-level configurations suited for the VGA architecture.

Memory Mapping and Addressing Emulation

CGA hardware mapped video memory to segment B800h (spanning B800:0000 to B800:3FFF). Furthermore, CGA graphics modes arranged display memory in an interlaced structure: even scanlines were stored at offset 0000h, while odd scanlines were stored at offset 2000h (an 8 KB offset).

Because many games and applications bypassed the BIOS to write pixel data directly to segment B800h, the VGA hardware had to replicate this arrangement:

  1. Base Address Routing: The VGA BIOS programs the VGA Graphics Controller Miscellaneous Register to map its physical frame buffer into CPU address space starting at 0xB8000 rather than the default VGA graphics base of 0xA0000.
  2. Odd/Even Addressing: The BIOS enables the VGA's internal odd/even addressing logic. This hardware mechanism automatically routes alternate memory addresses to different physical banks, maintaining complete compatibility with software that relies on CGA's native 8 KB line-interleaving.

Register Configuration and Scan Doubling

CGA operated at a horizontal scan rate of 15.75 kHz to drive composite monitors and 200-line digital RGB displays. VGA monitors, however, require a minimum 31.5 kHz horizontal scan rate and display a standard 400 or 480 lines per frame.

To bridge this physical display gap, the VGA BIOS sets up the VGA Cathode Ray Tube Controller (CRTC):

  • Scan Doubling: The BIOS sets the "Double Scan" bit in the CRTC Maximum Scan Line Register (index 09h). When enabled, the VGA hardware reads each line of pixel data from memory twice before advancing to the next address. This turns a 200-line CGA image into a 400-line display on a VGA monitor, preserving the correct vertical aspect ratio without altering how software interacts with video RAM.
  • Timing Adjustments: The horizontal and vertical sync, blanking, and retrace registers are loaded with values that match the VGA's 31.5 kHz scanning frequency rather than CGA's legacy timings.

Palette and DAC Translation

The original CGA card had a fixed color palette hardwired into its logic circuits, capable of selecting predefined sets of 4 colors from a total of 16 colors. Conversely, VGA uses an Attribute Controller paired with a programmable Digital-to-Analog Converter (DAC) with 256,144 possible colors.

When Mode 04h, 05h, or 06h is set via INT 10h:

  1. The VGA BIOS sets the Attribute Controller registers to route 2-bit (for 4-color modes) or 1-bit (for 2-color modes) pixel values to specific internal palette registers.
  2. The BIOS loads the VGA DAC color registers with exact 18-bit RGB color equivalents matching the original CGA palettes (such as the standard cyan, magenta, and white, or the green, red, and brown palette options).
  3. Subsequent BIOS calls to INT 10h, AH=0Bh (Set Color Palette) change the contents of the Attribute Controller or DAC registers on the fly, replicating the palette-switching behavior of the physical CGA color select register.

Through this combination of BIOS-level interrupt handling, memory remapping, hardware scan-doubling, and DAC palette translation, the VGA architecture executes legacy CGA software without requiring hardware modifications or CPU emulation overhead.
