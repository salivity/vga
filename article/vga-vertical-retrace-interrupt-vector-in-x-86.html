VGA Vertical Retrace Interrupt Vector in x86

This article provides a technical overview of the Video Graphics Array (VGA) vertical retrace interrupt within the x86 hardware architecture. In standard IBM PC-compatible systems, the VGA vertical retrace interrupt is an event generated by the display hardware at the end of each screen refresh cycle. It was primarily designed to synchronize software rendering with the monitor's raster beam, historically routing through interrupt request line IRQ 2 or IRQ 9, which correspond to interrupt vectors 0x0A or 0x71 in the CPU's interrupt vector table.

In the original IBM PC/AT architecture and true IBM VGA adapters, the vertical retrace interrupt (often termed vertical blanking or VBLANK) is tied to the system’s Programmable Interrupt Controller (PIC). On original PC/XT architectures with a single 8259A PIC, this was assigned to IRQ 2, which corresponds to interrupt vector 0x0A (INT 0Ah). On the IBM PC/AT and later architectures, a second PIC was cascaded onto IRQ 2. Because of this cascade, the VGA vertical retrace line was physically redirected to the secondary PIC on IRQ 9, mapping it to interrupt vector 0x71 (INT 71h) in real-mode memory.

The interrupt is triggered when the electron beam of an analog CRT monitor finishes drawing the last visible scanline at the bottom of the screen and begins moving back to the top left. During this brief period—the vertical blanking interval—video memory can be updated without causing visual artifacts such as screen tearing.

To manage this interrupt at the register level, software interacts with the VGA's Cathode Ray Tube Controller (CRTC) registers:

  • Index Port 0x3D4 (Color) / 0x3B4 (Monochrome)
  • Data Port 0x3D5 (Color) / 0x3B5 (Monochrome)

Specifically, register 0x11 of the CRTC (the Vertical Retrace End Register) controls the interrupt:

  • Bit 5 acts as the interrupt disable flag. Setting this bit to 0 enables the generation of the vertical retrace interrupt, while setting it to 1 disables it.
  • Bit 4 serves as the interrupt clear flag. Writing a 0 to this bit clears a pending vertical retrace interrupt signal, while writing a 1 allows future interrupts to be captured.

Although the hardware specification supported interrupt vectors 0x0A and 0x71, the interrupt mechanism was notoriously unreliable across third-party VGA clone cards. Many graphics card manufacturers either left the interrupt line physically disconnected from the ISA/PCI bus or implemented the CRTC registers incompletely to cut production costs.

Because software could not guarantee that the interrupt vector would trigger across different systems, DOS programmers and game developers largely abandoned the vertical retrace interrupt vector. Instead, they relied on polling Input Status Register 1 (Port 0x3DA for color displays or Port 0x3BA for monochrome). By repeatedly reading this port and checking Bit 3 (where a value of 1 indicates vertical retrace is active), software could synchronize frame updates directly in a tight CPU loop without depending on IRQ lines or interrupt vectors.
