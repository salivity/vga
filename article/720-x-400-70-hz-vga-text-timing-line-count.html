720x400 70Hz VGA Text Timing Line Count

In standard 720x400 @ 70Hz Video Graphics Array (VGA) text mode, the total horizontal line count per frame is 449 lines. While the active display region uses 400 visible scanlines, the full frame includes an additional 49 blanking lines composed of front porch, vertical synchronization, and back porch intervals to maintain a stable 70.087 Hz refresh rate.

Vertical Timing Breakdown

The vertical frame structure defines the total number of horizontal scanlines drawn from top to bottom during each complete screen refresh:

  • Active Display: 400 lines (visible text area)
  • Vertical Front Porch: 12 lines
  • Vertical Sync Pulse: 2 lines
  • Vertical Back Porch: 35 lines
  • Total Vertical Lines: 449 lines

Timing Verification and Calculation

VGA 720x400 text mode operates using a standard 28.322 MHz pixel clock (master dot clock):

  1. Horizontal Scanline Width: Each scanline consists of 720 active pixels, an 18-pixel front porch, a 108-pixel horizontal sync, and a 54-pixel back porch, totaling 900 pixels per line.
  2. Horizontal Line Frequency: Dividing the 28.322 MHz dot clock by the 900-pixel total line width yields a horizontal frequency of 31.469 kHz.
  3. Vertical Refresh Rate: Dividing the 31.469 kHz horizontal frequency by the 449 total horizontal lines results in a vertical refresh rate of approximately 70.087 Hz.
