How Many Resistors for a 3-Bit VGA DAC?

A 3-bit, 8-color passive Video Graphics Array (VGA) digital-to-analog converter (DAC) circuit requires exactly three resistors. Because a 3-bit color configuration allocates one digital output pin to each of the three primary color channels—Red, Green, and Blue—only a single inline series resistor is needed per channel. These three resistors work in conjunction with the standard 75-ohm termination resistors built into the VGA display to step down digital logic levels to standard analog video signals.

Understanding the 3-Bit Color Architecture

In a basic 3-bit VGA configuration, each color channel is strictly binary (on or off). This provides \(2^3 = 8\) possible color combinations:

  • Black (0, 0, 0)
  • Blue (0, 0, 1)
  • Green (0, 1, 0)
  • Cyan (0, 1, 1)
  • Red (1, 0, 0)
  • Magenta (1, 0, 1)
  • Yellow (1, 1, 0)
  • White (1, 1, 1)

Because each color channel represents only one bit of depth, an R-2R ladder network is unnecessary. A single resistor per channel is sufficient to form a passive voltage divider.

Calculating Resistor Values

VGA specifications require an analog signal ranging from 0.0V (fully off) to 0.7V (fully on) measured across an internal 75-ohm load resistor located inside the monitor. To scale down digital logic voltages to 0.7V, the external series resistor (\(R_{ext}\)) is calculated using the voltage divider formula:

\[V_{out} = V_{in} \times \frac{75}{R_{ext} + 75}\]

Rearranging for \(R_{ext}\):

\[R_{ext} = 75 \times \left(\frac{V_{in} - 0.7}{0.7}\right)\]

  • For 3.3V Logic (Microcontrollers, FPGAs): \(R_{ext} = 75 \times \frac{3.3 - 0.7}{0.7} \approx 278.6\,\Omega\)
    A standard 270-ohm resistor is commonly used.

  • For 5.0V Logic (Classic TTL, Arduino): \(R_{ext} = 75 \times \frac{5.0 - 0.7}{0.7} \approx 460.7\,\Omega\)
    A standard 470-ohm resistor is commonly used.

Synchronization Signals

The Horizontal Sync (HSync) and Vertical Sync (VSync) lines carry digital timing pulses rather than analog levels. Modern displays accept standard 3.3V or 5V TTL logic levels directly on these pins. Consequently, they do not require DAC conversion, maintaining the total passive DAC resistor count at three.
