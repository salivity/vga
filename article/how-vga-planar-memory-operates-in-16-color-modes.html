How VGA Planar Memory Operates in 16-Color Modes

Standard 16-color Video Graphics Array (VGA) modes utilize a planar memory architecture where 256 KB of video RAM is divided across four parallel 64 KB memory planes. This article explains how planar memory maps color data to screen coordinates, how the CPU interfaces with multiple memory banks sharing a single address space, and how specialized hardware registers and write modes manipulate individual pixels efficiently.

The Four-Plane Structure

In standard 16-color modes (such as 640x480 Mode 12h or 320x200 Mode 0Dh), each pixel is represented by a 4-bit index, allowing for a palette of 16 simultaneous colors. Rather than storing these 4 bits sequentially in a contiguous byte (packed-pixel format), the VGA hardware splits the bits across four distinct hardware memory banks known as planes:

  • Plane 0: Bit 0 (typically Blue)
  • Plane 1: Bit 1 (typically Green)
  • Plane 2: Bit 2 (typically Red)
  • Plane 3: Bit 3 (typically Intensity)

Each plane contains 64 KB of memory, but all four planes occupy the exact same CPU address space, typically mapped from 0xA0000 to 0xAFFFF (a 64 KB window).

Pixel Mapping and Bit Organization

Because each plane provides exactly one bit toward a pixel's color value, a single byte at a given memory address contains 1 bit for 8 horizontal pixels.

When the VGA display controller renders a scanline:

  1. It reads the byte at a specific offset simultaneously from all four planes.
  2. Bit 7 of Plane 0, Plane 1, Plane 2, and Plane 3 are assembled to form the 4-bit color index for the first pixel.
  3. Bit 6 from each of the four planes forms the color index for the second pixel, continuing down to Bit 0 for the eighth pixel.
  4. The resulting 4-bit index is sent to the digital-to-analog converter (DAC) palette registers to output the corresponding color to the monitor.

CPU Memory Access and Internal Latches

Because all four planes exist at the identical CPU address range, a standard CPU read or write operation cannot access all planes independently without hardware arbitration. The VGA Graphics Controller resolves this using an internal 32-bit latch composed of four 8-bit registers (one for each plane).

Whenever the CPU executes a read operation at an address in the video segment (0xA0000–0xAFFFF), the VGA hardware simultaneously reads 1 byte from that address across all four planes into these internal latches. The CPU only receives 1 byte from a single plane (determined by the Read Map Select register), but the remaining planes are captured in the latches for subsequent write operations.

Read and Write Modes

To manipulate pixels without requiring slow read-modify-write cycles over the system bus for every plane, the VGA hardware incorporates dedicated read and write modes configured via the Graphics Controller registers.

Read Modes

  • Read Mode 0: The CPU reads a byte directly from the plane designated by the Read Map Select Register.
  • Read Mode 1: The CPU performs a color comparison. The hardware checks all four planes against a predefined Color Compare Register and returns an 8-bit mask indicating which of the 8 pixels match the target color.

Write Modes

  • Write Mode 0: The default mode. The CPU writes data through the VGA's internal logic, which can apply rotation, logical operations (AND, OR, XOR), and combine the incoming CPU data with data stored in the internal latches.
  • Write Mode 1: Used for rapid memory copying. A CPU write to a destination address automatically copies the contents of all four internal latches directly to all four planes at that address, transferring 32 bits (8 pixels) in a single CPU cycle.
  • Write Mode 2: The lower 4 bits of the CPU data byte represent a single 4-bit color value. The hardware automatically replicates this color across all 8 pixels defined by the Bit Mask Register, significantly speeding up solid color drawing.
  • Write Mode 3: Optimized for font rendering and pattern fills. The CPU byte acts as an 8-bit mask combined with a background color specified in the Set/Reset Register.

Masking Operations

Manipulating individual pixels within an 8-pixel byte boundary requires the coordination of two primary mask registers:

  • Map Mask Register (Sequencer): Controls which of the four planes are enabled for writing. Bits 0 through 3 correspond to Planes 0 through 3. Disabling a plane protects its data from being modified during a write.
  • Bit Mask Register (Graphics Controller): Controls which individual pixel positions (bits 0 through 7) are written. If a bit in this register is set to 0, the data for that pixel is preserved from the internal 32-bit latches rather than overwritten by the CPU data.

By utilizing internal latches alongside the Bit Mask and Map Mask registers, planar VGA memory allows software to update individual pixels and perform bulk graphical operations across 16 colors within a constrained 64 KB memory window.
