Disable VGA Blinking to Unlock 16 Background Colors

In standard Video Graphics Array (VGA) text modes, each character on the screen is defined by a character byte and an attribute byte. By default, the most significant bit (bit 7) of the attribute byte is configured to trigger text blinking rather than background intensity, effectively capping background colors at eight while foreground colors have access to sixteen. Software can disable this hardware-level blinking feature either through a standard BIOS interrupt call or by directly programming the VGA Attribute Controller registers, repurposing bit 7 into a high-intensity background selector to unlock all 16 background colors.

Understanding the VGA Attribute Byte

In standard 80x25 text mode (Mode 03h), the attribute byte controls character appearance using an 8-bit layout:

  • Bits 0–3: Foreground color (16 colors available via Red, Green, Blue, and Intensity components).
  • Bits 4–6: Background color (8 base colors).
  • Bit 7: Blinking toggle by default.

When the blink feature is enabled, setting bit 7 causes the hardware to alternate the foreground character between visible and hidden at a rate governed by the vertical refresh cycle. When blink is disabled, bit 7 functions as the background intensity bit, matching the 16-color palette structure of the foreground.

Method 1: Disabling Blinking via BIOS (INT 10h)

For MS-DOS programs, real-mode applications, and custom bootloaders, the simplest and most portable method is invoking the video BIOS services through Interrupt 10h.

Function 1003h toggles the intensity/blinking state:

  • Set register AX to 1003h (Video Subsystem: Toggle Blink/Intensity).
  • Set register BL to 00h to enable intensity (disable blinking) or 01h to restore blinking.
  • Set register BH to 00h (to prevent compatibility issues on some systems).
  • Trigger interrupt 10h.
mov ax, 1003h
mov bl, 00h
int 10h

Once this routine executes, bit 7 of any text mode attribute byte immediately controls the background intensity.

Method 2: Disabling Blinking via Direct Register Access

In protected-mode environments, bare-metal operating system development, or scenarios where BIOS interrupts are unavailable, software must communicate directly with the VGA hardware via I/O ports.

The blinking behavior is governed by Bit 3 of the Attribute Mode Control Register (Index 10h) inside the VGA Attribute Controller (ATC).

To safely modify this register:

  1. Reset the ATC Address/Data Flip-Flop: Reading from the Input Status #1 Register at I/O port 0x3DA (in color modes) clears the internal flip-flop, ensuring the next write to port 0x3C0 is treated as an index register write.
  2. Select the Attribute Mode Control Register: Write 0x10 (or 0x30 to preserve the video output bit) to I/O port 0x3C0.
  3. Read Current Settings: Read the existing byte from port 0x3C1 (or write to 0x3C0 depending on the VGA implementation).
  4. Clear Bit 3: Clear the fourth bit (mask with 0xF7 / binary 11110111) to disable blinking.
  5. Write the Updated Value: Write the modified value back to I/O port 0x3C0.
  6. Re-enable Video Output: Write 0x20 to port 0x3C0 to restore screen output and unblank the display.
#include <sys/io.h> // For x86 inb/outb support

void disable_vga_blink(void) {
    // 1. Reset flip-flop
    inb(0x3DA);

    // 2. Select register 0x10 with PAS bit set (0x20 | 0x10 = 0x30)
    outb(0x30, 0x3C0);

    // 3. Read current value
    unsigned char mode = inb(0x3C1);

    // 4. Clear bit 3 (Blink Enable)
    mode &= ~0x08;

    // 5. Reset flip-flop before writing
    inb(0x3DA);
    outb(0x10, 0x3C0);
    outb(mode, 0x3C0);

    // 6. Re-enable video output
    outb(0x20, 0x3C0);
}

After modifying the register, bit 7 of all subsequent and existing screen cells directly indexes the high-intensity half of the background palette, giving text applications full access to vibrant 16-color backgrounds.
