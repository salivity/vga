VGA 400-Line Mode CRTC Register Timings

This article details the exact Cathode Ray Tube Controller (CRTC) register values and frame timings required to configure a standard 400-line Video Graphics Array (VGA) mode. It covers the vertical timing breakdown—including active display, overscan borders, blanking intervals, and synchronization pulses—as well as the specific values written to CRTC index registers 0x06 through 0x16 and the Miscellaneous Output Register.

Frame Geometry for Standard 400-Line VGA (70 Hz)

Standard IBM VGA 400-line modes (such as 720×400 text or 640×400 graphics) operate at a vertical refresh rate of 70.08 Hz and a horizontal scan rate of 31.469 kHz. A full vertical frame consists of 449 total scan lines:

  • Active Display: 400 lines (scan lines 0–399)
  • Bottom Border (Overscan): 6 lines (scan lines 400–405)
  • Bottom Blanking (Front Porch): 6 lines (scan lines 406–411)
  • Vertical Sync (Retrace): 2 lines (scan lines 412–413)
  • Top Blanking (Back Porch): 28 lines (scan lines 414–441)
  • Top Border (Overscan): 7 lines (scan lines 442–448)

Miscellaneous Output Register Configuration

Before loading CRTC timings, the vertical sync polarity must be set. Standard 400-line modes use negative vertical sync and positive horizontal sync.

  • Register Port: 0x3C2 (Write)
  • Sync Bits:
    • Bit 7 (V-Sync Polarity): 0 (Negative)
    • Bit 6 (H-Sync Polarity): 1 (Positive)
  • Clock Select:
    • Bits 2–3: 00 selects the 25.175 MHz pixel clock (640-pixel wide modes); 01 selects the 28.322 MHz pixel clock (720-pixel wide text modes).

CRTC Vertical Timing Register Values

The CRTC is accessed via I/O ports 0x3D4 (Address Index) and 0x3D5 (Data) when color emulation is enabled. Before modifying write-protected registers (0x00–0x07), bit 7 of register 0x11 must be cleared to 0.

CRTC Register Index Register Name Hex Value Decimal Value / Timing Function
Index 0x06 Vertical Total 0xBF Programmed as \((\text{Total Lines} - 2) \pmod{256}\). Total lines = 449; \(449 - 2 = 447\) (0x1BF). Lower 8 bits = 0xBF.
Index 0x07 Overflow Register 0x1F Stores bit 8 and bit 9 for various vertical counters:
• Bit 0 (Vertical Total Bit 8): 1
• Bit 1 (Vertical Display End Bit 8): 1
• Bit 2 (V-Sync Start Bit 8): 1
• Bit 3 (Start Vertical Blank Bit 8): 1
• Bit 4 (Line Compare Bit 8): 1
• Bits 5–7 (Bits 9 of VT, VDE, VRS): 000
Index 0x09 Maximum Scan Line 0x40 (Graphics) / 0x4F (Text) Bit 5 is bit 9 of Start Vertical Blank (0). Bit 6 is bit 9 of Line Compare (1). Bits 0–4 set character cell scanline height minus 1 (0x00 for 1-line graphics cell, 0x0F for 16-line text font). Bit 7 controls double-scanning (set to 0 for true 400-line modes).
Index 0x10 Vertical Retrace Start 0x9C Vertical sync pulse start line. Line 412 (0x19C). Lower 8 bits = 0x9C.
Index 0x11 Vertical Retrace End 0x8E Low 4 bits specify the retrace end line modulo 16. Retrace ends at line 414 (\(414 \pmod{16} = 14 = \text{0x0E}\)). Bit 7 is set to 1 to re-enable write protection. Bit 5 is set to 0 to enable vertical interrupts if required.
Index 0x12 Vertical Display End 0x8F Programmed as \((\text{Active Lines} - 1)\). \(400 - 1 = 399\) (0x18F). Lower 8 bits = 0x8F.
Index 0x15 Start Vertical Blank 0x96 Scan line where vertical blanking begins (after the bottom border). Line 406 (0x196). Lower 8 bits = 0x96.
Index 0x16 End Vertical Blank 0xB9 Programmed as \((\text{Blank End Line}) \pmod{256}\). Blanking ends at scan line 441 (0x1B9). Lower 8 bits = 0xB9.

Programming Sequence

  1. Set the clock frequency and sync polarities by writing to the Miscellaneous Output Register (0x3C2).
  2. Write 0x11 to 0x3D4, read 0x3D5, and clear bit 7 (value & 0x7F) to disable write protection on registers 0x00–0x07.
  3. Program registers 0x06, 0x07, 0x09, 0x10, 0x12, 0x15, and 0x16 with the timing values listed above.
  4. Write 0x8E to 0x3D5 at index 0x11 to set the retrace end timing and re-lock write protection on CRTC registers 0x00 through 0x07.
