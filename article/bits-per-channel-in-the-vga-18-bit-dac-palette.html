Bits Per Channel in the VGA 18-Bit DAC Palette

The Video Graphics Array (VGA) standard, introduced by IBM in 1987, relies on an 18-bit digital-to-analog converter (DAC) to produce color video output. This article details the specific bit allocation per color channel in the VGA DAC, explains how the hardware calculates available color shades, and outlines how this architecture functions within standard PC graphics modes.

The Video Graphics Array 18-bit DAC palette uses exactly 6 bits per color channel.

Because computer displays rely on the additive RGB (Red, Green, Blue) color model, the 18 bits of total color data are divided evenly across the three primary channels:

  • Red: 6 bits
  • Green: 6 bits
  • Blue: 6 bits

Total: \(6 + 6 + 6 = 18\text{ bits}\)

Intensity Levels and Color Depth

With 6 bits assigned to each channel, every primary color can represent \(2^6\) (or 64) discrete levels of brightness, scaled from 0 (completely off) to 63 (full intensity).

Multiplying the possible values of the three channels together determines the total size of the VGA color space:

\[64 \times 64 \times 64 = 262,144\text{ possible colors}\]

This total of 262,144 shades constitutes the master hardware palette of standard VGA.

How the 18-Bit DAC Was Implemented

Standard VGA hardware was constrained by video memory bandwidth and typically could not output 18 bits per pixel directly from memory to the screen. Instead, it utilized a Color Look-Up Table (CLUT).

In standard modes such as Mode 13h (320×200 resolution), the video memory allocated 8 bits per pixel, allowing 256 colors to appear on screen simultaneously. Each of these 256 values served as an index pointing to an entry in the internal palette registers. Each entry in that palette contained an 18-bit color definition consisting of three 6-bit RGB values.

The DAC then read these 6-bit values and converted each digital channel into an analog voltage ranging from 0.0V to 0.7V, driving the cathode-ray tube (CRT) monitor to display the chosen color.
