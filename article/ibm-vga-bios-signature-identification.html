IBM VGA BIOS Signature Identification

Identifying an authentic IBM Video Graphics Array (VGA) adapter requires inspecting the adapter's ROM BIOS for proprietary text signatures and specific memory offsets. This article explains the exact signature strings, memory locations, and byte structures used by software to distinguish genuine IBM VGA hardware from third-party clones and compatible graphics cards.

ROM BIOS Location and Standard Header

The ROM BIOS of a standard IBM VGA adapter is mapped to memory segment C000h (specifically physical address C000:0000). Like all standard IBM PC expansion ROMs, it begins with a mandatory two-byte header:

  • Offset 0000h: 55h AAh (ROM validation signature)
  • Offset 0002h: The length of the ROM in 512-byte blocks (typically 30h for a 24 KB ROM)

The Authentic IBM Signature String

An authentic IBM VGA adapter is primarily identified by the ASCII string "IBM" located at offset 001Eh within the video BIOS segment (C000:001E).

In hexadecimal format, the bytes at C000:001E read:

49 42 4D

Software routines that check for authentic IBM video hardware read the three bytes starting at C000:001Eh. If these bytes match "IBM", the card is recognized as genuine IBM hardware. Clones typically omit this exact placement or substitute their own manufacturer identification to avoid copyright infringement.

Copyright and Extended Identifier Strings

In addition to the short identifier at offset 001Eh, authentic IBM VGA adapters contain a formal copyright notice located in the early portion of the ROM, typically immediately following the short signature or starting around offset 0020h to 0023h.

The string reads:

COPR. IBM 1986

or variations such as:

IBM Corp. 1986

The year 1986 corresponds to the original development and internal release of the VGA standard by IBM, prior to its public launch with the IBM Personal System/2 (PS/2) line in April 1987.

Programmatic Detection Summary

To definitively detect an original IBM VGA adapter:

  1. Verify the byte sequence 55 AA at C000:0000.
  2. Inspect offset C000:001E for the string "IBM".
  3. Check the subsequent bytes for the copyright string "COPR. IBM 1986".
