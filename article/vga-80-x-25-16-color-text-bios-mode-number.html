VGA 80x25 16-Color Text BIOS Mode Number

This article covers the standard BIOS mode number used for the default 80x25 16-color Video Graphics Array (VGA) text mode. It explains the specific mode designation, its technical specifications, memory organization, and how it is initialized via x86 interrupt routines.

The BIOS video mode number representing the default 80x25 16-color VGA text mode is Mode 03h (decimal 3). While Mode 02h provides an identical 80x25 text layout originally intended for monitors with color burst disabled, Mode 03h is universally recognized as the default color text mode on IBM-compatible PCs.

Technical Specifications of Mode 03h

When the VGA hardware is configured to Mode 03h, it establishes the following display properties:

  • Text Resolution: 80 columns by 25 rows (2,000 total character cells).
  • Character Cell Size: 9 pixels wide by 16 pixels high.
  • Effective Pixel Resolution: 720x400 pixels at a 70 Hz vertical refresh rate.
  • Color Depth: 16 colors selected from the 256,000-color VGA palette.
  • Memory Buffer Address: Linear physical address 0xB8000.

Memory Organization

In Mode 03h, video RAM is accessed starting at memory address 0xB8000. The screen requires 4,000 bytes of memory because each on-screen character cell is defined by two consecutive bytes:

  1. Character Byte (Even Address): Contains the ASCII (or extended ASCII/Code Page 437) value representing the character to display.
  2. Attribute Byte (Odd Address): Specifies the visual formatting. Bits 0–3 dictate the foreground color (16 possibilities), bits 4–6 define the background color (8 possibilities), and bit 7 functions either as a blinking toggle or as an extension for a 16-color background.

Invocation via BIOS

Software initializes this mode through the BIOS Video Services interrupt, INT 10h. To select Mode 03h, a program sets the register AH to 00h (Set Video Mode function) and AL to 03h, then executes the interrupt:

mov ah, 00h
mov al, 03h
int 10h

Upon execution, the BIOS reconfigures the VGA controller registers, loads the default 8x16 font patterns into memory plane 2, clears the screen buffer at 0xB8000, and sets the hardware cursor to the upper-left corner of the screen.
