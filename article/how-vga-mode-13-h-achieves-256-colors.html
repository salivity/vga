How VGA Mode 13h Achieves 256 Colors

Mode 13h is a standard IBM Video Graphics Array (VGA) graphics mode introduced in 1987 that provides a resolution of 320x200 pixels with 256 simultaneous colors. It achieves its display capability by pairing a linear memory architecture—where exactly one byte corresponds to one pixel—with an internal Color Look-Up Table (CLUT) managed by the VGA Digital-to-Analog Converter (DAC). Rather than storing heavy RGB color values directly inside the framebuffer, Mode 13h stores an 8-bit index for each pixel that points to an entry in a fully customizable 256-color palette drawn from a wider master space of 262,144 colors.

Linear Memory Architecture (Chunky Pixels)

Earlier VGA and EGA modes, such as Mode 12h, relied on planar memory organizations that split bits of pixel data across multiple hardware memory banks. Mode 13h simplified this by implementing a packed-pixel, or "chunky," linear layout.

A screen resolution of 320 pixels wide by 200 pixels high contains exactly 64,000 pixels:

\[\text{Total Pixels} = 320 \times 200 = 64,000\]

Because each pixel is allocated exactly one byte (8 bits), the entire screen buffer requires 64,000 bytes of memory. Under the real-mode x86 memory model, a single segment can address up to 64 kilobytes (65,536 bytes). Mode 13h maps the entire framebuffer seamlessly into a single base segment at address 0xA000:0000.

To plot a pixel at screen coordinates \((x, y)\), a program only needs to calculate a single memory offset:

\[\text{Memory Offset} = (y \times 320) + x\]

Writing an 8-bit value to that offset instantly updates the pixel on the display.

The RAMDAC and Color Look-Up Table (CLUT)

The 8-bit value written to memory does not represent direct color data; it represents an index (from 0 to 255) referencing a palette. The conversion from this index to an analog video signal is handled by the VGA’s RAMDAC (Random Access Memory Digital-to-Analog Converter).

The RAMDAC contains a Color Look-Up Table with 256 entries. Each entry contains three color channels: Red, Green, and Blue. In standard VGA hardware, each color component is assigned 6 bits of precision, allowing values from 0 to 63:

  • Red: 6 bits (\(2^6 = 64\) levels)
  • Green: 6 bits (\(2^6 = 64\) levels)
  • Blue: 6 bits (\(2^6 = 64\) levels)

This 18-bit RGB color depth (RGB666) produces a total hardware color space of:

\[64 \times 64 \times 64 = 262,144 \text{ colors}\]

While only 256 distinct colors can appear on the screen at any single moment, those 256 colors can be chosen freely from the master selection of 262,144 colors.

Palette Programming via Hardware I/O Ports

Software can dynamically alter the active palette by writing directly to the VGA RAMDAC I/O ports:

  1. Port 0x3C8 (DAC Address Write Mode Register): The programmer sends the palette index (0–255) that needs to be modified.
  2. Port 0x3C9 (DAC Data Register): The programmer sequentially writes three consecutive bytes representing the 6-bit Red, Green, and Blue intensity values (each clamped between 0 and 63).

The hardware automatically advances to the next internal register after every three writes to port 0x3C9. This auto-increment feature enables all 256 palette registers (768 bytes of RGB data) to be updated rapidly in a single stream.

Pixel Generation Pipeline

When the display raster scan runs, the hardware executes the following sequence for each pixel clock cycle:

  1. The display controller reads a byte from the framebuffer located at 0xA000:0000 + Offset.
  2. The byte is fed into the RAMDAC as an address index.
  3. The RAMDAC fetches the corresponding 6-bit Red, Green, and Blue values from the internal table.
  4. Three digital-to-analog converters transform those digital values into proportional analog voltage signals.
  5. The analog voltages are transmitted to the monitor via the red, green, and blue pins of the VGA connector to generate the final color on screen.

Through this combination of linear byte-per-pixel memory addressing and indexed 18-bit DAC palette decoding, Mode 13h enabled fast, full-color rendering without exceeding the memory and bandwidth limitations of late-1980s PC hardware.
