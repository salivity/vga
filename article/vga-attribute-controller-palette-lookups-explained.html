VGA Attribute Controller Palette Lookups Explained

The Video Graphics Array (VGA) Attribute Controller serves as the critical intermediary in the display pipeline, bridging the raw pixel data stored in video memory with the digital-to-analog converter (RAMDAC). By utilizing a set of internal palette registers, mode control settings, and color select registers, the Attribute Controller translates multi-plane bit combinations into color indices. This article explains the exact hardware mechanics behind how these registers intercept framebuffer data, apply masking, and assemble final color addresses for DAC lookups.

The Position in the Display Pipeline

In standard 16-color planar modes, the VGA graphics pipeline retrieves data across four parallel bit planes. The serializer converts these planes into continuous pixel streams, producing a 4-bit value per pixel. Rather than sending these 4 bits directly to the RAMDAC, the video subsystem routes them into the Attribute Controller.

The Attribute Controller uses this 4-bit value as an address index into its internal palette memory. This decoupling allows applications to remap colors globally without altering the underlying data in video memory.

The Internal Palette Registers (0x00–0x0F)

The Attribute Controller contains sixteen 6-bit internal palette registers corresponding to indices 0x00 through 0x0F.

  1. Pixel Input: The 4-bit serialized value from the video planes (bits 0 through 3) selects one of the 16 internal palette registers.
  2. Plane Masking: Before reaching the palette index, the signal passes through the Color Plane Enable Register (Index 0x12). If a bit plane is disabled here, its corresponding bit in the 4-bit index is forced to zero, allowing selective plane rendering.
  3. 6-bit Output: The selected internal palette register outputs a 6-bit value (bits 0 through 5).

Constructing the DAC Address

The output from the internal palette registers is not always sent straight to the DAC. Instead, it is combined with values from the Mode Control Register (Index 0x10) and the Color Select Register (Index 0x14) to generate the final 8-bit address sent to the 256-entry RAMDAC.

The 8-bit DAC index (\(P_7–P_0\)) is assembled based on the state of the Attribute Mode Control Register:

  • Lower Bits (\(P_3–P_0\)): Always sourced directly from bits 0–3 of the selected internal palette register.
  • Middle Bits (\(P_5–P_4\)):
    • If Bit 7 of the Mode Control Register is set to 0, bits 4 and 5 originate from the internal palette register.
    • If Bit 7 is set to 1, bits 4 and 5 are supplied by bits 0 and 1 of the Color Select Register (0x14). This allows rapid switching between different 16-color sets without reprogramming the 16 internal palette registers.
  • Upper Bits (\(P_7–P_6\)): Sourced from bits 2 and 3 of the Color Select Register (0x14). In 16-color modes, this extends the address space, enabling full access across the 256-entry RAMDAC by functioning as a color page selector.

256-Color (Mode 13h) Bypass

In 256-color modes like Mode 13h, the Attribute Controller behaves differently:

  • Bit 6 of the Mode Control Register is set to enable 8-bit pixel paths.
  • The internal 16-entry palette registers are bypassed for color indexing.
  • The serialized byte representing the pixel passes through the Attribute Controller directly as an 8-bit index to the RAMDAC, allowing simultaneous access to all 256 colors at the cost of plane-level palette flexibility.

The Final Lookup Stage

Once the Attribute Controller combines the internal palette bits with the Color Select Register bits, it outputs the completed 8-bit color index over the pixel bus. The external RAMDAC receives this byte, uses it to index its internal color look-up table (CLUT), and retrieves the three 6-bit values representing Red, Green, and Blue analog voltages for the display monitor.
