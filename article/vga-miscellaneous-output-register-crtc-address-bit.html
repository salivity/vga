VGA Miscellaneous Output Register CRTC Address Bit

In standard VGA hardware, Bit 0 of the Miscellaneous Output Register controls whether the Cathode Ray Tube Controller (CRTC) I/O ports are mapped to color or monochrome addresses. Setting or clearing this specific bit toggles the CRTC index register between base address 0x3D4 and 0x3B4, ensuring backwards compatibility with legacy display adapters.

The Role of Bit 0 (I/O Address Select)

The Miscellaneous Output Register is accessed via I/O port 0x3C2 for write operations and port 0x3CC for read operations. Bit 0 of this byte is formally designated as the I/O Address Select (IOAS) bit.

The state of Bit 0 directly alters the base addressing scheme of both the CRTC registers and associated status registers:

  • Bit 0 = 0 (Monochrome Emulation):
    The CRTC index register maps to port 0x3B4, and the CRTC data register maps to 0x3B5. Additionally, Input Status Register 1 maps to port 0x3BA. This configuration emulates the legacy IBM Monochrome Display Adapter (MDA).

  • Bit 0 = 1 (Color Emulation):
    The CRTC index register maps to port 0x3D4, and the CRTC data register maps to 0x3D5. Input Status Register 1 maps to port 0x3DA. This configuration emulates the IBM Color Graphics Adapter (CGA) and is the standard setting for modern color VGA modes.

Purpose and Context

IBM introduced this dynamic address switching to prevent hardware port conflicts on early PC architectures. By defaulting to 0x3D4 (Bit 0 set to 1) for color modes and 0x3B4 (Bit 0 set to 0) for monochrome modes, systems could run software tailored to specific display hardware without modifying underlying driver conventions. To safely switch CRTC modes, software reads the current state from port 0x3CC, modifies Bit 0, and writes the updated value back to port 0x3C2.
