How the Gert VGA 666 18-Bit Resistor DAC Works

The Gert VGA 666 is an open-source hardware expansion board for the Raspberry Pi that outputs analog Video Graphics Array (VGA) video using only passive components. By configuring the Raspberry Pi’s digital general-purpose input/output (GPIO) pins into a parallel Display Parallel Interface (DPI), the board routes 18 digital color signals and two synchronization signals directly to a standard VGA connector. Through a series of binary-weighted resistors connected to each color channel, the board creates a passive digital-to-analog converter (DAC) that translates digital pin states into the exact analog voltage levels required by VGA monitors.

The VGA Standard and Signal Requirements

A standard VGA interface requires five primary active signals: Red, Green, Blue, Horizontal Sync (H-Sync), and Vertical Sync (V-Sync). While H-Sync and V-Sync are digital timing pulses that coordinate the monitor’s electron beam or pixel clock, the color signals are purely analog.

Each RGB color line expects an analog voltage ranging from 0.0V (representing total black) to 0.7V (representing maximum color intensity). The input of the monitor on these three color lines contains a standard 75-ohm termination resistor connected to ground. Any DAC driving a VGA port must deliver voltages within this 0.0V to 0.7V range across that 75-ohm load.

GPIO Pin Allocation (6-6-6)

The "666" in the board's name refers to the color bit allocation: 6 bits for Red, 6 bits for Green, and 6 bits for Blue. This adds up to 18-bit color, allowing for \(2^{18}\) or 262,144 unique colors.

To achieve this, the Raspberry Pi's Broadcom system-on-a-chip (SoC) is configured to output its native DPI mode over GPIO pins. This mode dedicates 20 GPIO pins entirely to video transmission:

  • 6 pins for the digital Red channel (representing values from 0 to 63)
  • 6 pins for the digital Green channel (representing values from 0 to 63)
  • 6 pins for the digital Blue channel (representing values from 0 to 63)
  • 1 pin for Horizontal Synchronization
  • 1 pin for Vertical Synchronization

Binary-Weighted Resistor DAC Implementation

The Gert VGA 666 converts the 6-bit digital outputs of each color channel into an analog voltage using a binary-weighted resistor network. Each of the six pins per channel is connected in parallel through a uniquely valued resistor to a shared output line that goes to the VGA connector.

Because the Raspberry Pi GPIO pins output digital logic levels of 0V (LOW) and 3.3V (HIGH), the resistors must be selected so that:

  1. The most significant bit (MSB) contributes the largest proportion of current.
  2. Each subsequent bit down to the least significant bit (LSB) contributes half the current of the preceding bit.
  3. When all 6 bits of a channel are driven HIGH (3.3V), the total voltage developed across the monitor’s 75-ohm termination resistor equals exactly 0.7V.

The network essentially forms a multi-input voltage divider with the monitor’s internal 75-ohm load resistor serving as the lower half of the divider. The values of the six series resistors are approximately doubled for each descending bit:

  • Bit 5 (MSB): ~500 ohms
  • Bit 4: ~1,000 ohms (1 kΩ)
  • Bit 3: ~2,000 ohms (2 kΩ)
  • Bit 2: ~4,000 ohms (4 kΩ)
  • Bit 1: ~8,000 ohms (8 kΩ)
  • Bit 0 (LSB): ~16,000 ohms (16 kΩ)

(Standard commercial E96/E24 resistor values such as 510Ω, 1kΩ, 2kΩ, 4.02kΩ, 8.06kΩ, and 16kΩ are typically used to closely match these theoretical ideals).

Voltage Generation Under Load

When a GPIO pin goes HIGH (3.3V), it injects current through its dedicated resistor into the shared color pin on the VGA connector. This current flows down into the monitor's 75-ohm termination resistor to ground, producing a voltage drop according to Ohm's Law (\(V = I \times R\)).

  • When all pins for a channel are set to 0V (digital 000000), no current flows through the circuit, and the monitor reads 0.0V (black).
  • When only the LSB (Bit 0) is HIGH, current flows through the largest resistor (~16 kΩ), generating a tiny voltage drop across the 75-ohm monitor load, producing the dimmest visible shade of that color.
  • When only the MSB (Bit 5) is HIGH, current flows through the smallest resistor (~500 Ω), creating the single largest incremental step in voltage.
  • When all six pins are driven HIGH simultaneously (digital 111111), the parallel combination of all six resistors allows enough cumulative current to develop the target 0.7V peak across the 75-ohm monitor termination, displaying maximum color intensity.

Because the H-Sync and V-Sync signals are already digital logic levels, they do not require a DAC. Instead, they pass through low-value series current-limiting resistors directly to the monitor's synchronization pins.

Through this design, the Gert VGA 666 achieves hardware-accelerated video output with high refresh rates and minimal latency, completely bypassing the need for active signal processing or specialized display conversion integrated circuits.
