Standard 80x25 VGA Text Mode Character Dimensions

This article examines the standard character cell dimensions utilized in the classic 80x25 Video Graphics Array (VGA) text mode. In its default hardware configuration, VGA text mode displays 80 columns by 25 rows of text using a cell size of 9x16 pixels, producing an effective screen resolution of 720x400 pixels. Below, we break down how these dimensions are structured, how the hardware renders them, and the common 8x16 pixel alternative.

The Standard 9x16 Pixel Matrix

The standard IBM VGA hardware text mode (specifically BIOS Mode 03h) defines a character cell as 9 pixels wide by 16 pixels high.

Multiplying the grid dimensions by this cell size yields the total active display area:

  • Horizontal: 80 characters × 9 pixels = 720 pixels
  • Vertical: 25 characters × 16 scan lines = 400 pixels

This 720x400 resolution runs at a 70 Hz vertical refresh rate using a 28.322 MHz pixel clock.

Font Storage and the 9th Pixel Column

Although the screen allocates a 9-pixel wide box for each character, VGA character generator fonts are actually stored in memory as 8x16 pixel glyphs. To fill the 9-pixel-wide cell, the VGA sequencer hardware dynamically handles the 9th horizontal pixel:

  • Background Padding: For standard alphanumeric characters (ASCII codes 00h through BFh and E0h through FFh), the 9th pixel is simply rendered as the cell's background color, providing visual separation between adjacent letters.
  • Line-Drawing Continuation: For box-drawing characters (ASCII codes C0h through DFh), the hardware automatically duplicates the 8th pixel into the 9th pixel column. This ensures uninterrupted horizontal lines across adjacent character cells.

The 8x16 Pixel Alternative

VGA text mode can also operate with an 8x16 pixel character cell. When switching from the standard 28.322 MHz dot clock down to a 25.175 MHz dot clock, the horizontal resolution drops from 720 to 640 pixels (80 characters × 8 pixels). This configuration results in a total display resolution of 640x400 pixels and eliminates the 9th pixel padding entirely, making it common in systems requiring strict compatibility with older display standards or non-IBM hardware.
