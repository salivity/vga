Standard VGA Color Palette Lookup Table Size

This article examines the memory size and architecture of the color palette lookup table in standard Video Graphics Array (VGA) hardware. It outlines the specific bit depth allocated to color channels, calculates the total effective data capacity of the palette registers, and explains the physical memory footprint within the VGA RAMDAC.

In standard IBM VGA hardware, the color palette lookup table—formally known as the Color Look-Up Table (CLUT) housed within the RAMDAC (Random-Access Memory Digital-to-Analog Converter)—contains 256 color registers. Each register defines a single active color by specifying intensities for three primary color channels: red, green, and blue.

Each color component uses a 6-bit digital-to-analog converter. This provides 64 distinct intensity levels per channel (\(2^6\)), resulting in 18 bits of total color data per palette entry (\(6 \text{ bits} \times 3 \text{ channels}\)). This 18-bit depth enables a master palette of 262,144 possible colors (\(2^{18}\)), from which any 256 can be displayed simultaneously.

The total size of the lookup table can be measured in two ways:

  • Effective Data Size: Calculating strictly the active bits, 256 entries multiplied by 18 bits equals 4,608 bits (or 576 bytes).
  • Hardware Storage Footprint: Because standard computer hardware addresses memory in 8-bit bytes, each 6-bit color component is mapped to an individual byte, leaving the upper two bits unused. Consequently, each palette entry occupies 3 full bytes (24 bits) in the RAMDAC register map. This yields a total hardware storage size of 768 bytes (\(256 \text{ entries} \times 3 \text{ bytes}\), or 6,144 bits).
