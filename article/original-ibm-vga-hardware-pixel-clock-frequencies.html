Original IBM VGA Hardware Pixel Clock Frequencies

When IBM introduced the Video Graphics Array (VGA) standard in 1987 with the PS/2 line of computers, it established a foundational display specification that endured for decades. This article explores the internal timing architecture of the original IBM VGA hardware, specifically examining the two dedicated hardware crystal oscillators that provided its native pixel clock frequencies, how the hardware selected between them, and the iconic display modes each frequency supported.

The original IBM VGA adapter integrated two primary native crystal oscillators to drive its pixel clocks: 25.175 MHz and 28.322 MHz. These fixed frequencies allowed the hardware to maintain standard horizontal scan rates of 31.469 kHz across different horizontal pixel counts while targeting the analog CRT monitors of the era.

The 25.175 MHz Clock: Standard Graphics Modes

The 25.175 MHz pixel clock was designed to support modes with a horizontal resolution of 640 pixels (or 320 pixels using horizontal clock doubling). Operating with a total horizontal line period of 800 pixel clocks, this frequency yields the standard VGA horizontal sync frequency of approximately 31.469 kHz (25.175 MHz ÷ 800 ≈ 31.46875 kHz).

This clock frequency primarily drove:

  • Mode 12h (640×480, 16 colors): The flagship VGA graphics mode, running at a 60 Hz vertical refresh rate with 525 total scanlines.
  • Mode 13h (320×200, 256 colors): A popular standard for PC gaming that used pixel doubling horizontally and scanline doubling vertically to refresh at 70 Hz with 449 total scanlines.
  • Mode 11h (640×480, 2 colors): A monochrome high-resolution fallback mode.

The 28.322 MHz Clock: Enhanced Text Modes

The 28.322 MHz pixel clock was implemented to provide backward compatibility with older text modes while improving readability. IBM designed its standard text display to present 80 columns of characters, each 9 pixels wide, requiring 720 horizontal pixels across the active display area. Running 900 total pixel clocks per line at 28.322 MHz produces the identical horizontal scan rate of 31.469 kHz (28.322 MHz ÷ 900 ≈ 31.46889 kHz).

This clock frequency primarily drove:

  • Mode 03h (720×400, 16 colors text): The default DOS command-line text environment, displaying 80×25 characters within 9×16 character matrix cells at a 70 Hz vertical refresh rate.
  • Mode 07h (720×400 monochrome text): Emulated the high-quality character sharpness of the older Monochrome Display Adapter (MDA).

Hardware Clock Selection

Switching between these two oscillators was managed through software via the VGA Miscellaneous Output Register (located at I/O port 0x3C2 for writes and 0x3CC for reads). Bits 2 and 3 of this register formed the Clock Select field:

  • Setting the bits to 00 selected the 25.175 MHz clock.
  • Setting the bits to 01 selected the 28.322 MHz clock.
  • Setting the bits to 10 was reserved for an external clock source provided through the feature connector, while 11 was unused on original hardware.

By pairing these two precise frequencies to a unified horizontal scan rate, the original IBM VGA hardware delivered sharp 720-pixel text alongside flexible 640-pixel graphics without requiring multi-frequency monitor adjustments.
