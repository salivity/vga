VGA Hardware Registers for Display Timing

In the standard Video Graphics Array (VGA) architecture, dedicated hardware register blocks manage everything from color palettes to memory mapping. This article identifies the specific register block responsible for horizontal and vertical timing, explains how it functions to generate synchronization signals, and details the primary parameters used to synchronize the display with monitor refresh cycles.

The CRT Controller (CRTC)

The Cathode Ray Tube Controller, commonly abbreviated as the CRTC, is the hardware register block that controls horizontal and vertical timing in a VGA system. While the Graphics Controller, Sequencer, Attribute Controller, and DAC handle pixel data and color translation, the CRTC dictates the physical scanning process and raster timing.

The CRTC is accessed through an index-data register pair via I/O ports. In color emulation mode, the index register is at port 0x3D4 and the data register is at 0x3D5. In monochrome compatibility mode, the index register sits at 0x3B4 and the data register is at 0x3B5.

Horizontal Timing Control

The CRTC controls horizontal scanning by counting character clocks. The primary registers governing horizontal timing include:

  • Horizontal Total (Index 0x00): Defines the total number of character clocks per scanline, including active display time, blanking, and retrace intervals.
  • Horizontal Display End (Index 0x01): Specifies the end of the active display portion of the scanline where pixels are visible.
  • Start Horizontal Blanking (Index 0x02): Determines the character clock count where the beam blanks to prevent visual artifacts as it nears the screen edge.
  • End Horizontal Blanking (Index 0x03): Specifies the conclusion of the blanking interval.
  • Start Horizontal Retrace (Index 0x04): Triggers the horizontal synchronization pulse, signaling the monitor's beam to return to the left side of the display.
  • End Horizontal Retrace (Index 0x05): Dictates the width of the horizontal sync pulse.

Vertical Timing Control

Vertical timing operates similarly to horizontal timing but counts complete scanlines rather than individual character clocks. Key vertical timing registers include:

  • Vertical Total (Index 0x06): Dictates the total number of horizontal scanlines comprising a complete frame, including visible lines and blanking periods.
  • Vertical Display End (Index 0x12): Sets the final scanline of active display data.
  • Start Vertical Blanking (Index 0x15): Marks the scanline where the beam is deactivated after drawing the bottom of the image.
  • End Vertical Blanking (Index 0x16): Designates where the vertical blanking period concludes.
  • Vertical Retrace Start (Index 0x10): Sets the scanline at which the vertical synchronization pulse begins, signaling the beam to reposition from bottom to top.
  • Vertical Retrace End (Index 0x11): Controls the pulse width of the vertical sync signal and contains protection bits to prevent software from accidentally overwriting critical timing parameters.

Together, these CRTC registers ensure proper synchronization between the VGA hardware and the connected display monitor.
