Raspberry Pi 240p VGA Retro Gaming Guide

A Raspberry Pi can natively output an authentic 240p video signal over a Video Graphics Array (VGA) interface using its GPIO pins and passive or active digital-to-analog adapters. By utilizing the Raspberry Pi's internal Display Parallel Interface (DPI), users can bypass modern digital scaling and HDMI conversion to send a true 15kHz progressive scan signal directly to CRT monitors, arcade chassis, and consumer televisions. This setup delivers original scanlines, eliminates motion artifacts, and reduces input latency for classic console and arcade emulation.

How 240p Over VGA Works

Standard HDMI ports on modern hardware do not natively support low-frequency analog resolutions like 240p (roughly 320x240 at 60Hz with a 15kHz horizontal scan rate). However, the Raspberry Pi's 40-pin GPIO header can be repurposed into a parallel RGB display interface (DPI).

By attaching an adapter—such as the open-source Gert VGA 666, an RGB-Pi cable, or a Pi2SCART board—the digital color signals from the GPIO pins pass through a resistor ladder digital-to-analog converter (DAC). This produces a standard analog RGBHV signal transmitted through a VGA (D-Sub 15) connector.

Display Compatibility: 15kHz vs. 31kHz

When outputting 240p over a standard VGA port, the display device must support the proper sync frequencies:

  • Consumer CRT TVs and Arcade Monitors (15kHz): Classic 240p requires a 15kHz horizontal refresh rate. Standard consumer PC VGA monitors will not sync to this low frequency (they typically require at least 31kHz for 480p). To display 240p from the Pi's VGA port on a consumer CRT, the signal usually needs to be routed to a display that accepts 15kHz RGB, such as a Sony PVM/BVM (via BNC), an arcade monitor, or a European CRT TV (via a VGA-to-SCART cable).
  • Multisync PC CRT Monitors: Certain rare PC CRT monitors can scan down to 15kHz natively over standard VGA cables.
  • Standard 31kHz PC CRTs: If using a common PC CRT, the Pi can alternatively output 480p at 60Hz or 120Hz with simulated scanlines, or double-scan lines to achieve a similar retro aesthetic.

Hardware Requirements

To set up a 240p VGA configuration, the following hardware is needed:

  1. Raspberry Pi: A model with a 40-pin GPIO header (Raspberry Pi 2, 3, 4, or Zero).
  2. DPI-to-VGA Adapter: A Gert VGA 666 board or a dedicated retro gaming adapter designed for your specific display target.
  3. Target CRT Display: A monitor or television capable of accepting a 15kHz RGB signal.
  4. Appropriate Cabling: A standard VGA cable, VGA-to-BNC breakout cable, or VGA-to-SCART cable depending on the video inputs of the CRT.

Software Configuration

To enable the VGA output and force the 240p resolution, edit the config.txt file located in the boot partition of the Raspberry Pi's operating system (such as RetroPie or Lakka).

Add the following base parameters to enable the DPI interface and load the VGA adapter overlay:

dtoverlay=vga666
enable_dpi_lcd=1
display_default_lcd=1
dpi_group=2
dpi_mode=87

Next, define the custom modeline using the dpi_timings parameter to generate a 320x240 progressive signal at 60Hz with a 15.7kHz horizontal frequency:

dpi_timings=320 1 20 28 36 240 1 3 3 16 0 0 0 60 0 6400000 1

Once configured and rebooted, the Raspberry Pi will route all video through the GPIO pins directly to the VGA port, completely disabling the HDMI output and providing an authentic, zero-scale retro gaming signal.
