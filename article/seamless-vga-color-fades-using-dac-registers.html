Seamless VGA Color Fades Using DAC Registers

Modifying the Video Graphics Array (VGA) Digital-to-Analog Converter (DAC) palette registers strictly during the vertical blanking interval (V-Blank) allows developers to achieve smooth, artifact-free color transitions across the entire screen. By timing updates to occur when the display hardware is not actively drawing pixels to the monitor, software can alter the RGB intensity levels of the palette without introducing visual noise, flicker, or horizontal shearing.

The Role of the VGA Palette and RAMDAC

In standard 256-color VGA modes (such as Mode 13h), screen memory does not store raw RGB values for each pixel. Instead, each byte in video memory acts as an index pointing to one of 256 entries inside the internal RAMDAC (Random Access Memory Digital-to-Analog Converter).

Each DAC palette entry holds three color components: red, green, and blue. On standard VGA hardware, each component is represented by a 6-bit value ranging from 0 to 63, allowing for a total of 262,144 possible colors. When software updates these DAC registers—accessed via I/O port 0x3C8 (write index) and 0x3C9 (data)—any pixel on the screen referencing the modified palette index instantly changes color on the next scan.

The Cause of Video Artifacts ("Snow" and Tearing)

During active video display, the RAMDAC continuously reads its internal color lookup table at high speeds to generate the analog voltages sent to the display. If the CPU attempts to write new color values to the DAC registers while this active scanning takes place, bus contention occurs.

On classic hardware, this concurrent access causes two distinct problems:

  1. Snow/Noise: Read/write collisions inside the RAMDAC disrupt the output signal, causing transient, bright speckles to flicker across the screen.
  2. Color Tearing: If a palette update takes multiple CPU cycles and spans across an active frame, the upper half of the screen renders with the old palette values, while the lower half renders with the new palette values, creating an abrupt horizontal discontinuity.

Utilizing the Vertical Blanking Interval

To prevent these artifacts, palette updates must be deferred to the vertical blanking interval. The vertical blanking interval represents the period of time when the display beam reaches the bottom of the screen, shuts off its electron guns, and retraces back to the top-left corner to begin the next frame.

During this inactive window, the RAMDAC is idle and does not need to look up color values to draw the image. Consequently, the CPU can read and write to the DAC registers with zero hardware contention.

In low-level programming, software synchronizes with this interval by polling the VGA Input Status Register 1 (located at I/O port 0x3DA in color modes):

  1. Poll bit 3 of port 0x3DA until it reads low, confirming any ongoing retrace has finished.
  2. Poll bit 3 until it reads high, signaling the precise start of the new vertical retrace.
  3. Immediately write the updated palette values to ports 0x3C8 and 0x3C9.

Executing the Seamless Fade

To execute a fade to black, software maintains a copy of the target or original palette in system memory. Over a sequence of frames, an algorithm calculates incremental reductions of the 6-bit RGB components toward zero:

  1. Calculate the Step: For each of the 256 colors, decrement the red, green, and blue values by a predetermined step size (or interpolate toward zero).
  2. Wait for V-Blank: The CPU halts and waits for the vertical retrace signal to ensure maximum time availability before the beam begins the next active scan line.
  3. Burst Write the DAC: The software rapidly streams the 768 bytes (256 colors × 3 components) to the DAC data port.
  4. Frame Delay: The software yields execution until the next frame tick to control the fade speed.

Because the entire palette update completes while the display is blanked, the hardware begins the subsequent frame with the new color levels fully established. Every pixel on screen transforms simultaneously and uniformly, yielding a perfectly seamless fade transition.
