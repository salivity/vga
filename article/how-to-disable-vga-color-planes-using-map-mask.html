How to Disable VGA Color Planes Using Map Mask

In Video Graphics Array (VGA) programming, rendering graphics efficiently in planar display modes requires controlling how CPU writes affect video memory. This guide explains how a programmer can selectively disable specific color planes using the VGA Sequencer's Map Mask register, detailing the register architecture, bit definitions, and practical I/O port programming techniques in C and x86 Assembly.

VGA Planar Architecture Overview

In standard 16-color planar modes (such as Mode 12h: 640×480) and unchained 256-color modes (such as Mode X: 320×240), VGA video memory at address 0xA0000 is divided into four parallel 64 KB memory banks known as planes (Planes 0 through 3). In typical 16-color modes, these planes correspond to the primary color components:

  • Plane 0: Blue
  • Plane 1: Green
  • Plane 2: Red
  • Plane 3: Intensity

When the CPU writes a single byte to an address in the 0xA0000 memory segment, the hardware can simultaneously write that data across all four planes. To isolate or disable writes to specific color planes, you must configure the Map Mask register located inside the VGA Sequencer.

The Sequencer Registers

Access to the Map Mask register is mediated by two I/O ports associated with the VGA Sequencer:

  • Sequencer Address Register (Index Port): 0x03C4
  • Sequencer Data Register: 0x03C5
  • Map Mask Index: 0x02

The Map Mask register is designated as Sequencer Index 0x02. Writing to this register modifies which memory planes accept CPU write operations.

Map Mask Register Bit Layout

The Map Mask register uses the lower four bits of an 8-bit value to control write access. Setting a bit to 1 enables writes to that plane, while setting a bit to 0 disables (masks) the plane, leaving its existing data preserved during memory writes.

Bit Target Plane Default Mapping Value = 1 Value = 0
Bit 0 Plane 0 Blue Write Enabled Write Disabled
Bit 1 Plane 1 Green Write Enabled Write Disabled
Bit 2 Plane 2 Red Write Enabled Write Disabled
Bit 3 Plane 3 Intensity Write Enabled Write Disabled
Bits 4–7 Reserved N/A Ignored Ignored

Programming the Register

To disable color planes, follow this process:

  1. Identify the planes to retain and construct the bitmask (e.g., to disable the Red and Intensity planes, leave Bits 0 and 1 active: binary 00000011 or 0x03).
  2. Select the Map Mask register by writing index 0x02 to port 0x03C4.
  3. Send the plane mask value to port 0x03C5.

Example in C (Using 8-bit Port I/O)

#include <dos.h>

void set_active_planes(unsigned char mask) {
    /* Select Sequencer Register 0x02 (Map Mask) */
    outp(0x03C4, 0x02);
    /* Write the plane mask (Bits 0-3 correspond to Planes 0-3) */
    outp(0x03C5, mask & 0x0F);
}

void disable_red_and_intensity(void) {
    /* Enable Plane 0 (Blue) and Plane 1 (Green); Disable Planes 2 and 3 */
    set_active_planes(0x03); 
}

Optimized 16-Bit Word Write

Because the Sequencer Address port (0x03C4) and Data port (0x03C5) are adjacent byte registers, modern x86 CPU architectures permit combining both operations into a single 16-bit word write to port 0x03C4. The index occupies the lower byte, and the mask data occupies the upper byte:

void set_active_planes_fast(unsigned char mask) {
    /* (mask << 8) places the data at 0x03C5, 0x02 directs to 0x03C4 */
    outpw(0x03C4, ((mask & 0x0F) << 8) | 0x02);
}

Example in x86 Assembly

; Function: set_map_mask
; Input: AL = Bitmask of planes to enable (Bits 0-3)
set_map_mask:
    mov     dx, 0x03C4      ; DX = Sequencer Index Register
    mov     ah, al          ; AH = Plane mask
    mov     al, 0x02        ; AL = Register 0x02 (Map Mask)
    out     dx, ax          ; Send AL to 0x03C4 and AH to 0x03C5 simultaneously
    ret

Writing to Video Memory

Once the Map Mask register is updated, all subsequent standard writes to the VGA memory buffer (0xA0000 to 0xAFFFF) will modify only the enabled planes. Disabled planes remain unaltered, regardless of the data values sent across the CPU bus. When finished with targeted plane modifications, restore the register to 0x0F to re-enable write operations across all four planes.
