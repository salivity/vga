Enable VGA Output in Raspberry Pi config.txt

Enabling direct Video Graphics Array (VGA) output on a Raspberry Pi requires configuring the Display Parallel Interface (DPI) via the config.txt file, typically using a passive adapter board such as the Gert VGA 666. This article details the specific parameters, device tree overlays, and display timings needed to activate direct RGB-to-VGA signal generation without an active HDMI converter.

Required Software Directives

To output a native VGA signal, the Raspberry Pi repurposes its GPIO pins into a parallel display bus. Edit the boot configuration file (located at /boot/firmware/config.txt on newer Raspberry Pi OS releases, or /boot/config.txt on legacy versions) and add the following core directives:

dtoverlay=vga666
enable_dpi_lcd=1
display_default_lcd=1
dpi_group=2
dpi_mode=16

Parameter Breakdown

  • dtoverlay=vga666: Loads the Device Tree overlay that maps the GPIO pins to the 6-bit RGB parallel bus (RGB666 mode) and assigns horizontal/vertical synchronization signals.
  • enable_dpi_lcd=1: Tells the VideoCore firmware to enable the internal DPI display hardware block.
  • display_default_lcd=1: Sets the parallel LCD/DPI output as the primary display target instead of the default HDMI interface.
  • dpi_group=2: Specifies the standard timing group. Group 2 corresponds to DMT (Display Monitor Timings), which is the standard format used by computer monitors and VGA displays.
  • dpi_mode=16: Selects the specific screen resolution and refresh rate from the DMT specification. Mode 16 sets a standard resolution of 1024x768 at a 60 Hz refresh rate.

Common Resolution Modes

You can change the dpi_mode value to match the native resolution of your VGA monitor:

  • dpi_mode=4: 640x480 @ 60 Hz
  • dpi_mode=9: 800x600 @ 60 Hz
  • dpi_mode=16: 1024x768 @ 60 Hz
  • dpi_mode=35: 1280x1024 @ 60 Hz
  • dpi_mode=82: 1920x1080 @ 60 Hz

Custom DPI Timings

For retro displays, arcade monitors, or CRT screens with non-standard resolutions, use dpi_group=2 with dpi_mode=87 (custom mode), and define a precise dpi_timings string:

dpi_group=2
dpi_mode=87
dpi_timings=640 0 16 96 48 480 0 10 2 33 0 0 0 60 0 25175000 1

Once the configuration file is saved, reboot the system with sudo reboot to apply the changes and initialize the direct VGA output.
