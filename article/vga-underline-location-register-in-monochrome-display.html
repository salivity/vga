VGA Underline Location Register in Monochrome Display

The Video Graphics Array (VGA) Underline Location Register dictates the vertical positioning of the underline attribute within character cells during monochrome text operations. In monochrome text modes, such as the hardware-emulated MDA Mode 07h, standard color attributes are replaced with special display properties like inverse video, blinking, and underlining. This article explains how the CRT Controller's Underline Location Register specifies the exact scanline for this effect, how it interacts with monochrome character generation, and the visual consequences of its configuration.

Register Function and Architecture

The Underline Location Register is an internal component of the VGA CRT Controller (CRTC), accessed via I/O port 0x3B5 (in monochrome emulation) or 0x3D5 (in color modes) after indexing register 0x14 through port 0x3B4 or 0x3D4.

Bits 0 through 4 of this register represent the underline scanline position:

  • Bits 0–4 (Underline Scanline): A 5-bit value (0–31) designating the zero-indexed horizontal scanline within the character cell where the underline appears.
  • Bit 5 (Count by 4): Dictates whether the CRTC memory address counter advances every four character clocks.
  • Bit 6 (Doubleword Mode): Dictates whether memory addressing functions in doubleword mode.
  • Bit 7: Reserved.

Role in Monochrome Text Mode

In standard color text modes (such as Mode 03h), the attribute byte accompanying each ASCII character code controls foreground and background colors (4 bits each). In monochrome mode (Mode 07h), the hardware reinterprets these bits to mirror the capabilities of the original IBM Monochrome Display Adapter (MDA).

An attribute byte with a foreground value of 001b (e.g., attribute 0x01 or 0x09 for intense) triggers the hardware underline signal instead of rendering a specific color. When the character generator reaches a character tagged with this attribute, the VGA raster hardware checks the value in bits 0–4 of the Underline Location Register.

Impact on Display Output

The value programmed into bits 0–4 alters monochrome text output in the following ways:

  • Vertical Placement: Standard VGA text uses a character matrix of 9×16 pixels. By default, the BIOS sets the underline location to scanline 13 or 14 (values 0x0D or 0x0E), placing a continuous horizontal stroke directly beneath the primary character glyphs. Modifying this register shifts the line higher or lower within the cell matrix.
  • Glyph Collision: If the register is configured to a scanline occupied by active font data (such as scanlines 4 through 10), the underline draws across the middle of the character glyphs, effectively creating a strikethrough effect rather than a traditional underline.
  • Suppression and Clipping: The character cell height is governed by the Maximum Scan Line Register (CRTC Index 0x09). If the Underline Location Register is set to an index higher than the maximum scan line defined for the active font (for instance, setting the underline to scanline 15 on an 8×8 font), the hardware never encounters the target scanline during cell rendering, effectively disabling the underline attribute entirely.
