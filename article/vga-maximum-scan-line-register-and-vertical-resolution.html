VGA Maximum Scan Line Register and Vertical Resolution

The Video Graphics Array (VGA) Maximum Scan Line Register plays a critical role in managing how display data is drawn on a screen, particularly through its ability to control scan-line replication and vertical line counts. By manipulating this register—specifically located within the VGA Cathode Ray Tube Controller (CRTC)—programmers and hardware controllers can execute scan-doubling. This mechanism enables legacy 200-line graphics to display correctly on 400-line monitors and allows developers to alternate between line-doubled rendering and true high-resolution custom display modes.

Location and Structure of the Register

The Maximum Scan Line Register is part of the VGA CRTC register block, accessible via I/O port 0x3D5 (color mode) or 0x3B5 (monochrome mode) after indexing 0x09 on port 0x3D4 or 0x3B4.

While bits 0 through 4 specify the maximum scan line number per character row (predominantly utilized in text modes to define font height), Bit 7 is the critical switch for vertical line multiplication. Bit 7 is designated as the Double Scan bit (or 200-to-400-line conversion bit).

The Mechanism of Scan-Doubling

Standard VGA monitors were designed to operate at a fixed horizontal scanning frequency of approximately 31.468 kHz. At a standard vertical refresh rate of 70 Hz, the monitor sweeps through roughly 449 total physical scan lines, displaying approximately 400 active visible lines.

Older display standards, such as CGA, natively generated only 200 active scan lines. To make 200-line modes (such as standard Mode 13h, 320×200) compatible with standard 31.5 kHz VGA timings without leaving the bottom half of the screen blank, the hardware must double the vertical output.

When Bit 7 of the Maximum Scan Line Register is set to 1:

  • The CRTC clocking logic divides the row scan counter progression by two.
  • Each horizontal row of pixel data in the frame buffer is scanned and sent to the display twice successively before the memory address advances to the next row.
  • A 200-line buffer is stretched physically over 400 active CRT scan lines.

Unlocking Higher Vertical Resolutions

While Bit 7 defaults to enabled for 200-line modes, clearing Bit 7 to 0 changes the behavior of the video controller entirely:

  1. True 400-Line Modes (Mode X/Tweaked Modes): When Bit 7 is set to 0, the hardware ceases duplicating scan lines. If the vertical timing registers are kept at the 400-scan-line configuration, the video controller reads a new row of video memory on every single horizontal sweep. This transforms a 320×200 display into a 320×400 resolution mode, effectively doubling the addressable vertical resolution without altering the monitor's horizontal or vertical sync frequencies.
  2. Text Mode Raster Control: Bits 0–4 can also be set to values greater than zero in conjunction with graphics manipulation to instruct the hardware to replicate scan lines by arbitrary amounts, defining the physical line height of each displayed line of data.

Through the configuration of Bit 7 and the row counters in Register 09h, the Maximum Scan Line Register provides the bridge between legacy compatibility—duplicating lower-resolution sweeps to fit standard monitor refresh rates—and unlocking doubled, planar vertical resolutions for custom display software.
